## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) `PrimTorch` reduces `> 2,000` ATen ops to `~250` primitives, an **`8.0x` reduction (`87.5%` smaller operator surface)**; (b) `x.add_(y)` lowers to **`%z = aten::add(x, y)`** followed by **`%copy = aten::copy_(x, %z)`**, eliminating in-place aliasing/mutation hazards before fusion.
2. **Exercise 2:** (a) One `[4, 2048, 4096]` `BF16` (`2 B`) tensor is **`67,108,864` bytes (`67.11 MB`)**; (b) `AOTAutograd` + `TorchInductor` fuses **`10` eager kernels (`24` HBM passes = `1.6106 GB`)** into **`2` compiled kernels (`6` HBM passes = `0.4027 GB`)**, achieving a **`4.0x` HBM traffic reduction (`75.0%` bandwidth saved)**.
3. **Exercise 3:** (a) `dynamo.explain(toy_example)` outputs **`Graph Count: 3`**, **`Graph Break Count: 2`**, **`Op Count: 5`**, with break reasons **`builtin: print [...ConstantVariable] False`** and **`generic_jump TensorVariable()`**; (b) guarding `print` with `if not torch._dynamo.is_compiling():` and replacing `if b.sum() < 0:` with `torch.where(b.sum() < 0, -b, b)` (or `torch.cond`) yields **`Graph Count: 1`**, **`Graph Break Count: 0`**, and **`cuda_graphs_compatible = True`**.
4. **Exercise 4:** (a) Across `(256, 512, 768, 1024)`, default `dynamic=None` triggers **`2` compilations (`1` guard failure, `sequence_length <= 256 -> sequence_length <= 1024`)**, whereas `torch._dynamo.mark_dynamic(x, 1)` triggers **`1` compilation (`0` guard failures)**; (b) a changing Python scalar per step hits **`recompile_limit = 8`** (`8` compilations, `8` guard failures) and falls back to eager under `stance="default"`, whereas `stance="fail_on_recompile"` raises an error immediately on step `2` (`1`st guard failure).
5. **Exercise 5:** (a) For `n_elements = 10,000`: `BLOCK_SIZE = 1,024 -> 10` programs, `4` warps (`128` threads, `8.0` elems/thread); `BLOCK_SIZE = 2,048 -> 5` programs, `8` warps (`256` threads, `8.0` elems/thread); `BLOCK_SIZE = 4,096 -> 3` programs, `16` warps (`512` threads, `8.0` elems/thread); (b) register with **`@torch.library.triton_op`**, **`wrap_triton`**, and **`register_autograd(backward, setup_context=setup_context)`**; `TMA` descriptors require **`16-byte` aligned leading strides** and a **contiguous inner dimension (`stride == 1`)**.
6. **Exercise 6:** (a) For `[8192, 8192, 512]` (`128x128x64`): `MT = 64`, `NT = 64`, `TILE_COUNT = 4,096`, `K_tiles = 8`, `grid = 4,096` (`1` tile/program); for `[65536, 65536, 2048]`: `TILE_COUNT = 262,144` capped at **`65,536` programs (`4` tiles/program)**; (b) a single `8192x8192x512` GEMM is **`68.72 GFLOPs`**, and `matmul_kernel_persistent` (`159.352 ms`, `4,312.421`) saves **`15.568 ms` (`8.90%` reduction, `1.10x` speedup)** over `cuBLAS` (`174.920 ms`, `3,928.623`), while 2D tiled `matmul_kernel` (`165.349 ms`, `4,156.033`) saves **`9.571 ms` (`5.47%` reduction, `1.06x` speedup)**.
