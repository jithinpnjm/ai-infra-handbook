## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Modeling `raid0` Round-Robin Striping and Request Parallelism):** `lustre_stripe.py` assigns chunk `k = offset // stripe_size` to OST `k % stripe_count` (`[0, 1, 2, 3, 0, 1, 2, 3]`), giving `[256, 256, 256, 256]` MiB per OST on a `1 GiB` file; a `3 MiB` read at `2.5 MiB` spans chunks `2..5` (`[0, 1, 2, 3]`), while a `512 KiB` read at `0` stays inside chunk `0` (`[0]`).
2. **Exercise 2 (Designing Progressive File Layouts (PFL) and Data-on-MDT):** `lfs setstripe -E 4M -c 1 -E 64M -c 4 -E -1 -c 16 -S 4M /lustre/dir` keeps small files ($\le 4\text{ MiB}$) on 1 OST, medium regions ($4\text{–}64\text{ MiB}$) on 4 OSTs, and large regions ($>64\text{ MiB}$) across 16 OSTs with `4 MiB` stripes.
3. **Exercise 3 (Formatting a Lustre Filesystem and Sizing OSS RAM):** Configure `/etc/modprobe.d/lustre.conf`, format MGS+MDT first (`mkfs.lustre --mdt --mgs --servicenode ...`) and OSTs second (`mkfs.lustre --ost --mgsnode ...`), and size each OST at `400 + 600 + 1.5 * 20 = 1030.0 MB` and the 8-OST OSS at `2 + 8 = 10 GB` baseline RAM.
4. **Exercise 4 (Configuring User, Group, and Project Quotas):** Run `lfs project -p 1 -r -s /lustre/testdir` and `lfs setquota -p 1 -b 200G -B 300G -i 2M -I 3M /lustre` so all files under `/lustre/testdir` share a directory-tree quota regardless of which team member created them.
5. **Exercise 5 (Retiring and Evacuating a Failing OST):** Find the OST device index `N` with `lctl dl`, stop new allocations with `lctl --device N deactivate`, migrate existing files off the OST with `lfs find --ost ... | lfs_migrate`, and unmount in order (`clients -> OSTs -> MDT/MGS`) if offline `ldiskfs` `e2fsck` is required.
6. **Exercise 6 (Diagnosing Metadata vs Data Bottlenecks on Lustre for AI Workloads):** Ticket A (`import torch` across 512 GPUs) is an `MDT` `open`/`stat` storm confirmed by `lctl get_param llite.*.stats` and fixed by packing Python into an Enroot `.sqsh` container; Ticket B (`500 GB` checkpoint at `600 MB/s`) is a `stripe_count=1` bottleneck confirmed by `lfs getstripe` and fixed by setting `lfs setstripe -c -1 -S 4M` or writing sharded `.distcp` checkpoints.
