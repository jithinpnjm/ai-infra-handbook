## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Static vs. Dynamic Routing, Administrative Distance `AD`, and Floating Static Routes):** Static routes fit stub networks and out-of-band management (`O(1)` state, zero control traffic), whereas dynamic protocols (`OSPF`, `IS-IS`, `BGP`) scale and converge automatically across fabrics; **Administrative Distance (`AD`)** selects the most trustworthy protocol source before comparing metrics (`connected 0 < static 1 < eBGP 20 < EIGRP 90 < OSPF 110 < IS-IS 115 < RIP 120 < iBGP 200`), allowing a **floating static route** (`AD 200`) to stay dormant until the primary dynamic route disappears (`select_route_by_admin_distance()`).
2. **Exercise 2 (Distance Vector / Bellman-Ford, Count-to-Infinity, Split Horizon, and `DUAL` Feasibility):** In Bellman-Ford distance-vector routing (`RIP`), a link failure can cause routers to bounce stale distance increments back and forth (**count to infinity** up to `16`); **split horizon** and **poison reverse** stop 2-node loops, while EIGRP's **DUAL** algorithm guarantees loop freedom at every instant by requiring a backup **feasible successor** to have a **Reported Distance (`RD`) strictly less than the current Feasible Distance (`FD`)** (`RD < FD`).
3. **Exercise 3 (Link-State / Dijkstra `SPF`, Partial vs. Incremental `SPF`, and Path-Vector `BGP`):** Link-state protocols (`OSPF`, `IS-IS`) flood Link-State Advertisements (`LSA`s/`LSP`s) so every router in an area holds an identical Link-State Database (`LSDB`) and runs **Dijkstra's SPF** (`run_dijkstra_spf()`), using **partial SPF** (for leaf prefix changes) and **incremental SPF** (for subtree changes) plus area hierarchy to bound CPU/memory; **path-vector (`BGP`)** prevents loops by carrying the explicit sequence of Autonomous Systems (`AS_PATH`) and rejecting any route containing the router's own ASN.
4. **Exercise 4 (Fast Reroute: `LFA`, `P/Q` Space and `rLFA`, `TI-LFA`, and Suurballe's Disjoint Paths):** A neighbor `N` is a **Loop-Free Alternate (`LFA`, RFC 5286)** for destination `D` from source `S` iff `dist(N, D) < dist(N, S) + dist(S, D)` (`check_dual_and_lfa_conditions()`); when a ring has no direct LFA, **Remote LFA (`rLFA`, RFC 7490)** tunnels to a `PQ` node in the intersection of `S`'s **P-space** and `D`'s **Q-space** (and **TI-LFA** uses Segment Routing along the exact post-convergence path), while **Suurballe's algorithm** finds the minimum-cost pair of link-disjoint paths in a two-connected graph.
5. **Exercise 5 (Failure Detection: Polling vs. Event-Driven vs. `BFD`, CAP in Routing, and the Convergence Timeline):** Event-driven carrier-loss detection (`~10 ms`) is fast but sees only local physical link drops, whereas **BFD (`RFC 5880`, UDP `3784`/`4784`, `50–300 ms`)** provides fast end-to-end forwarding-plane polling; total convergence time equals **`detection + origination throttle + propagation/flooding + SPF/best-path compute + FIB hardware installation`** (`compute_convergence_total_ms()`), and transient **micro-loops** occur when routers update their FIBs at different instants during flooding.
6. **Exercise 6 (Route Redistribution Metrics, Hot-Potato vs. Cold-Potato, and Preventing Redistribution Loops):** Because metrics across protocols are incompatible, redistribution must either set a seed metric, translate metrics, or carry an external metric alongside internal cost (`E1` cold-potato vs `E2` hot-potato); two-way redistribution across multiple boundary routers causes **routing feedback loops** unless prevented with **route tags** (`set tag 1001` / `match tag 1001 deny`), strict prefix-lists, and Administrative Distance manipulation.
