## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Playbook Anatomy, Phase Execution Order, and Handler Deduplication, `AUR` Ch. 3):** Using `simulate_play_execution_and_handlers()`, a play executes `pre_tasks -> flush handlers -> roles -> tasks -> flush handlers -> post_tasks -> flush handlers`, and multiple tasks notifying `Restart nginx` within a phase are deduplicated so the handler runs only once at the end of the phase.
2. **Exercise 2 (Core Module Families `package`, `dpkg_selections`, `file`, `copy`, `template`, `sysctl`, `uri`):** Declarative modules compare current state against desired state before mutating; `dpkg_selections` (`selection: hold`) and `state: present` with pinned versions prevent unplanned kernel/driver upgrades on GPU nodes; and `file: state=link` creates symlinks while `uri: return_content=true` verifies HTTP endpoints.
3. **Exercise 3 (Preserving Idempotency and Guarding `command` / `shell` Tasks):** Embedding dynamic timestamps (`{{ ansible_date_time.iso8601 }}`) causes templates to report `changed` and trigger handlers on every run; `evaluate_command_task_guards()` shows how `creates:`, `removes:`, `changed_when: false`, `failed_when:`, and `set -o pipefail` make `command`/`shell` tasks idempotent and safe.
4. **Exercise 4 (Check Mode `--check`, Unified Diffs `--diff`, and `check_mode:` / `diff:` Overrides):** `command`/`shell` tasks without `creates`/`removes` are skipped under `--check` unless `check_mode: false` and `changed_when: false` are set (required for read-only pre-flight probes whose registered output feeds later `when:` clauses), and secret tasks must set `diff: false` and `no_log: true`.
5. **Exercise 5 (Execution Controls: Tags, `serial`, `strategy`, `throttle`, `delegate_to`, `run_once`, and `async`/`poll`):** Using `compute_serial_batches()`, `serial: [1, "10%", "100%"]` with `max_fail_percentage: 5` runs a 1-host canary first and halts on failure; `strategy: linear` runs lockstep per task while `strategy: free` lets hosts advance independently; `throttle: 5` caps per-task concurrency; `delegate_to` runs a task on another host using the current host's variables; and `async: 3600` avoids SSH timeouts.
6. **Exercise 6 (End-to-End Safe GPU Parameter Rollout and `ansible-playbook` Exit Codes):** Section 7's play verifies Slurm `DRAIN` state in `pre_tasks` (`delegate_to` controller), applies `sysctl` and systemd overrides in `tasks`, restarts `nvidia-persistenced` in `handlers`, and verifies `nvidia-smi` GPU count in `post_tasks`; `ansible-playbook` returns `0` (success), `1` (error), `2` (failed hosts), `3` (unreachable hosts), `4` (parse error), `5` (bad options), `99` (interrupted), or `250` (unexpected error).
