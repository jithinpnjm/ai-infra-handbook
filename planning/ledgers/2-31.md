## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The Three Monitoring Questions, `USE` / `RED` / Golden Signals, and Comparing the 10 Monitoring Mechanisms, `ADC` Chapter 11):** Monitor (1) *Is it up?*, (2) *Is it healthy? (`USE`)*, and (3) *Is it doing its job? (collective bandwidth / step time / inference `RED`)*; contrast `SNMP` (`30s–5m` polling, misses microbursts), `syslog`, **`gNMI` streaming telemetry** (`1–10s` `sample` + `on_change`), active probes (`TWAMP` / `blackbox`), `sFlow`/`IPFIX` (`1:1000` flow sampling), **mirror-on-drop**, and **In-Band Flow Analyzer (`IFA` / `INT`)**.
2. **Exercise 2 (Deploying the Open-Source Network Observability Stack: `node_exporter`, `gNMIc`, `snmp_exporter`, `blackbox`, Prometheus, and Loki):** Enable `node_exporter`'s `ethtool`, `infiniband`, `rdma`, `softnet`, and `conntrack` collectors on GPU hosts (`:9100`), subscribe to switch `/interfaces` and `/qos` queues via `gNMIc` (`:9804`), probe host pairs via `blackbox_exporter` (`:9115`), and enrich all metrics with Source-of-Truth (`NetBox`) labels (`role`, `pod`, `rack`, `rail`, `tenant`).
3. **Exercise 3 (AI-Fabric Signals, PromQL Queries, and Detecting Rail Bandwidth Skew and ECMP Imbalance):** Using `evaluate_rail_skew_and_ecmp_balance()`: compute per-rail `max/min` bandwidth skew across a node's 8 NICs (`max by (instance) (rate(...)) / min by (instance) (rate(...)) > 1.5`) and ECMP uplink coefficient of variation (`stddev / avg`), alongside **zero-tolerance lossless queue drops**, **PFC pause rate / watchdog events**, **ECN marks / CNPs**, **`ib_port_xmit_wait_total`**, and **optical DOM `rx_power_dbm < -9` / pre-FEC BER trends**.
4. **Exercise 4 (In-Band Flow Analyzer `IFA` `draft-kumar-ippm-ifa-08` and Mirror-on-Drop, `ADC` Chapter 11):** Using `analyze_ifa_metadata_stack()`: in **IFA**, the **Initiator** (ingress leaf) clones/tags sampled packets with an IFA header, each **Transit** switch (spine/super-spine) pushes its `device_id`, ingress/egress port, queue ID, **nanosecond residence time**, and ECN congestion bit onto the metadata stack, and the **Terminator** (egress leaf) strips and exports the stack via IPFIX—measuring the exact real flow path; **mirror-on-drop** exports packets discarded by the ASIC along with the hardware drop reason.
5. **Exercise 5 (Correlating Switch + Server Telemetry for Straggler Hunts and Corrective Actions):** Join job rank (`rank 112`) -> server hostname -> GPU/NIC (`ens4f0` / `mlx5_3`) -> LLDP leaf port (`leaf4:Ethernet12`) -> spine uplinks to isolate whether a slow step is caused by a degraded optic, ECMP collision, or host throttle, and apply layered corrective actions (from local ECN/AR/SFC to automated node drain or job restart—recognizing that telemetry cannot rescue an under-provisioned fabric, which in the worst case requires evacuating jobs to a higher-capacity site, `ADC` Ch. 11).
6. **Exercise 6 (Operating the Monitoring System: Cardinality Math, Retention Tiers, Watchdog Alerts, and Network SLOs):** Using `estimate_telemetry_cardinality_and_rate(1000, 64, 100, 10.0)`: `1,000` switches × `64` ports × `100` metrics at `10 s` generates **`6.4 million` active series** and **`640,000` samples/s**; control cardinality by never putting per-flow 5-tuples into Prometheus labels, downsample long-term retention (`10s -> 1m -> 5m` in Thanos/Mimir/VictoriaMetrics), run an out-of-band **Watchdog** + `absent()` alert, and track network **SLOs** (`99.99%` probe success, `0` lossless queue drops).
