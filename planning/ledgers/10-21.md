## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (DCGM architecture, watches & `dcgmi diag`):** (a) `dcgm-exporter` (port `9400`) embeds `libdcgm` by default whereas `nvidia-dcgm.service` runs standalone `nv-hostengine` (port `5555`); (b) DCGM multiplexes watches at the fastest requested cadence (`1 s`), with `dcgm-exporter` defaulting to `30,000 ms` (`30 s`) collection and `300,000 ms` (`5 min`) Xid windows; (c) Level 1 (`seconds`, deployment check), Level 2 (`~2 min`, integration/memory), Level 3 (`~15 min`, invasive hardware/stress KGV gate), and Level 4 (`xlong`, extended burn-in).
2. **Exercise 2 (15-code Xid 3-Tier Triage):** Tier 1 = `{45, 63, 92}`, Tier 2 = `{13, 31, 32, 43, 94}`, Tier 3 = `{48, 61, 62, 64, 79, 95}`, Fabric = `{74}`; `Xid 79` is a PCIe bus disconnect (`Tier 3`), `Xid 94` is a contained uncorrectable ECC error (`Tier 2`, restart only the affected app), and `Xid 48`/`95` are uncontained/double-bit ECC errors (`Tier 3`, immediate drain + output invalidation); escalate `Xid 13`/`31` to `Tier 3` if the same GPU repeats the error across unrelated apps.
3. **Exercise 3 (ECC `SBE` rate & thermal correlation):** (a) `42 + 3 = 45` Volatile SBEs, and weekly delta `3 -> 8` is a `+167%` (`2.7x`) increase; (b) at `r = 0.81` (`>= 0.7`, `84.6°C` max), fix cooling/airflow or cap power (`250W`) and re-verify (`1–2` SBE/day), whereas at `r = 0.09` (no thermal correlation), schedule a preventive RMA for progressive silicon degradation.
4. **Exercise 4 (640-bank Row Remapper & MIG `0 MiB` trap):** `630 + 8 + 2 + 0 + 0 = 640` total HBM banks; `Xid 63` is a routine self-healing row remap (`Tier 1`, `IGNORE`), whereas `Xid 64` (`Remapping Failure Occurred: Yes`, `DCGM_FI_DEV_ROW_REMAP_FAILURE == 1`) means the remapper failed or exhausted spare rows (`Tier 3`, drain & RMA); when `MIG Mode: Enabled` has `0` GPU Instances (`GI`) created, the parent device exposes `0 MiB` to CUDA applications until instances are created or MIG is disabled.
5. **Exercise 5 (`Xid 74` NVLink isolation):** First check `nvidia-smi -i 2 -q | grep "MIG Mode"` (`Disabled`, ruling out MIG's intentional P2P block); because `GPU 2` Link 2 accumulated `184,213` CRC and `92,104` replay errors while `GPU 3` Link 2 had `0` errors before going `Down`, the hardware fault is isolated to `GPU 2`'s NVLink transceiver (or baseboard trace).
6. **Exercise 6 (Cluster SLO Error Budget & Safe Node Drain):** (a) `(1 - 0.99) * 730 = 7.3 hours/month` budget, `1.5 + 2.0 + 2.0 + 0.5 = 6.0 hours` used, `1.3 hours` remaining (triggers deployment freeze); (b) daily readiness checks `nvidia-smi -q` responsiveness, `temp <= 82°C`, `power > 50 W` under load, `uncorrected ECC == 0`, and `dcgmi diag -r 1` `PASS`; (c) `kubectl cordon $NODE` -> wait for `dcgmi dmon -e 203 -c 1` == `0%` -> `systemctl stop nvidia-dcgm-exporter nvidia-dcgm` -> `rmmod nvidia_uvm nvidia_drm nvidia_modeset nvidia`.
