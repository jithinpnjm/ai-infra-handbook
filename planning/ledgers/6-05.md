## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (STREAM Triad Memory Bandwidth Saturation):** `triad_bandwidth_gbps(50_000_000, 8, 18.1)` = `66.3 GB/s` (1 thread) and at `14.1 ms` = `85.1 GB/s` (8 threads); the triad saturates DRAM bandwidth by 2–4 threads (`0.083` FLOP/B) whereas `sin*cos` is compute-bound, and omitting the warm-up pass charged initial page faults (`20 GB/s`) to the 1-thread run.
2. **Exercise 2 (NUMA First-Touch and Hybrid MPI + OpenMP Oversubscription):** Serial initialization on Thread 0 faults all physical pages onto Socket 0's RAM under Linux first-touch (fixed by parallel `#pragma omp parallel for schedule(static)` initialization); `check_hybrid_oversubscription(8, 64, 64)` shows `512` total threads on `64` cores (`8.0x` oversubscription), fixed by `export OMP_NUM_THREADS=$SLURM_CPUS_PER_TASK`.
3. **Exercise 3 (Data Races vs. False Sharing):** Unsynchronized `racy++` loses `70–80%` of updates at `-O0` (`6215980` / `3487814`) and intermittently passes at `-O2` because race timing varies; `reduction(+ : var)` is lock-free per thread and much faster than `#pragma omp atomic`, while false sharing occurs when threads write distinct elements inside the same `64`-byte (x86/Arm) or `128`-byte (Apple M-series, `PAD = 16` doubles) cache line.
4. **Exercise 4 (Strict IEEE 754 `-O3` vs. `-ffast-math` Vector Reductions):** Strict `-O3` (`2.71 GFLOP/s`, `2293365.0`, `6.25%` swamping error) vectorizes `x[i]*y[i]` loads/multiplies but keeps additions in a serial dependency chain to preserve IEEE 754 order, whereas `-ffast-math` (`16.29 GFLOP/s`, `2445485.5`, `0.03%` error) reassociates into SIMD partial accumulators, and `y[rep] = dot * 1e-12f` prevents the compiler from hoisting the 20-pass loop.
5. **Exercise 5 (Cross-Language Linking and `-march=native` Fleet Portability):** The GNU single-pass linker resolves symbols left-to-right so `-lm` must follow `*.o`; `-fleading-underscore` / `-fno-underscoring` (or `iso_c_binding`) aligns C/Fortran underscores and `extern "C"` prevents C++ mangling; and `-march=x86-64-v3`, runtime dispatch (`MKL`/`OpenBLAS`), or per-arch modules prevent `SIGILL` crashes across heterogeneous nodes.
6. **Exercise 6 (Commercial Compiler Licensing `FlexLM` and CUDA Driver/Toolkit Operations):** `flexlm_quorum_and_seat_availability()` models the `15-minute` seat lease hold, `>= 50%` server quorum (`2` of `3`), and MAC binding; `libcuda` ships with the host driver while `libcudart` ships with the CUDA Toolkit (prefer OS repo packages over `.run` installers); and `rmmod nvidia; modprobe nvidia; deviceQuery` resets a hung driver.
