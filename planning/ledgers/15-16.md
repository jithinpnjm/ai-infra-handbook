2. **Exercise 2:** (a) Cumulative latencies across the 5 NeMo Guardrails stages are **`45.0 -> 60.0 -> 90.0 -> 190.0 -> 240.0 -> 250.0 ms`** (`+205.0 ms` guardrail overhead = **`5.56x` slowdown**); (b) stable error rate is `2/92 = 2.17%` vs canary `4/20 = 20.00%` (delta `17.83% > 5%`, ratio `9.2x > 2.0x`, and `p95 = 320.0 ms >= 300.0 ms`), so the controller **triggers an immediate rollback to `0%`**, and draining `60` tokens at `20 tok/s` (`3.0 s`) after a `15.0 s` `preStop` sleep takes **`18.0 s <= 120 s` (`zero_dropped_streams = True`)**.
3. **Exercise 3:** (a) `startupProbe` grants **`600 s` (`630 s` with `30 s` initial delay) `>= 240 s`** so startup succeeds, while a `1.2 s` NFS stall **trips the `1 s` readiness probe (`100%` `503` cascade) but survives the `5 s` `/health` readiness probe**; (b) on Replica 0 (`TP=8`), GPU 3 `XID 62` produces utilization vector **`[0, 0, 0, 100, 0, 0, 0, 0]%`** and blackholes **`12.5%` (`1/8`)** of cluster requests, and the circuit breaker transitions **`CLOSED -> OPEN -> OPEN (held by 80% hysteresis at 84% KV) -> CLOSED (at 78% KV)`**.
