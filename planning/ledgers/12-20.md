## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) On `8` GPUs (`800 MB`), `Ring` `ReduceScatter` receives `700.0 MB`/GPU vs `NVLS` `100.0 MB`/GPU (`7.0x` reduction) and `Ring` `AllReduce` transfers `1,400.0 MB` unidirectional in `14` steps (vs `6` tree steps); (b) on `72` GPUs (`720 MB`), `Ring` `ReduceScatter` receives `710.0 MB`/GPU vs `NVLS` `10.0 MB`/GPU (`71.0x` reduction, `142` ring steps vs `14` tree steps); (c) on `32` nodes (`1,024 MB`), `Ring` `ReduceScatter` receives `992.0 MB`/node vs `SHARP` `32.0 MB`/node (`31.0x` reduction), and `Ring` `AllReduce` transfers `1,984.0 MB` per direction (`62` steps) vs `SHARP` `1,024.0 MB` per direction (`10` tree steps, `1.9375x` wire reduction).
2. **Exercise 2:** Serial `Ring` exchange takes $8.0 + 8.0 = \mathbf{16.0\text{ ms}}$, whereas overlapped `NVLS` multicast `AllGather` + in-network `ReduceScatter` takes $\max(8.0, 8.0) = \mathbf{8.0\text{ ms}}$, a **`50.0%` (`1/2`)** wall-time reduction.
3. **Exercise 3:** (a) On `32 x 8 = 256` GPUs (`1,024 MB`), Stage 1 intra-node `NVLS` `ReduceScatter` receives `128.0 MB`/GPU and Stage 2 inter-node `SHARP` injects `1,024.0 MB`/node vs `1,984.0 MB`/node in hierarchical `Ring` (`1.9375x`); (b) on `16 x 72 = 1,152` `NVL72` GPUs (`720 MB`), intra-rack `NVLS` `ReduceScatter` receives `10.0 MB`/GPU, inter-rack `SHARP` sends `720.0 MB`/rack vs `1,350.0 MB`/rack in `Ring` (`1.875x`), using **`16` leaves + `8` spines** at `2 SUs` (`1,152` GPUs) and **`128` leaves + `72` spines** at `16 SUs` (`9,216` GPUs).
4. **Exercise 4:** (a) `Job 103` (`4` trees) is rejected and falls back to `HOST_RING_TREE_FALLBACK` because `32 + 32 = 64/64` trees are in use (`0` available); (b) after releasing `Job 101` (`32` free), `Job 104` (`512.0 MB > 256.0 MB` switch `AN` buffer cap) falls back to `HOST_RING_TREE_FALLBACK`, while `Job 105` (`16` trees, `64.0 MB`) allocates `SHARP_COLLNET` cleanly with **`16` free trees** remaining.
5. **Exercise 5:** Starting `FP32` summation at `Rank 2` (`1.0`) accumulates `1.875 + 10,000,000.0`, which rounds to `10,000,002.0` (`ULP = 1.0` at $10^7$ with `23` mantissa bits) before subtracting `10,000,000.0` to yield **`2.0`** (`0.125` error), whereas the binary `SHARP` `AN` tree cancels `(1e7 + -1e7) = 0.0` and `(1e6 + -1e6) = 0.0` at leaf pairs first to yield the exact, bit-repeatable **`1.875`**.
6. **Exercise 6:** (a) `NVSwitch_NVLS` intra-node + `CollNet_IB_SHARP` inter-node + zero-copy user buffers + `MPI` `HCOLL` `SHARP` with `0` warnings; (b) `NVSwitch_NVLS` intra-node + `RDMA_Ring_Tree` inter-node (`NCCL_SHARP_DISABLE=1` warning); (c) `NVSwitch_NVLS` intra-node + `RDMA_Ring_Tree` inter-node (warning that `spectrum-x-ethernet` lacks switch-resident `SHARP` silicon); (d) `RDMA_Ring_Tree` inter-node (`SHARP` blocked by missing `GPUDirect RDMA`) and internal channel staging (`zero_copy_user_buffer_active=False` due to asymmetric buffer offsets `0` vs `4096`).
