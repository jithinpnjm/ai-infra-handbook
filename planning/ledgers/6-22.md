## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Generating and Validating `dnsmasq.conf` and iPXE Scripts):** `gen_provision.py` validates hostnames, IPv4 subnet membership, 6-octet hex MACs, and uniqueness across all rows, and emits `dhcp-match=set:ipxe,175` so initial PXE/UEFI clients receive `undionly.kpxe`/`ipxe.efi` while chain-loaded iPXE clients receive `http://10.10.0.1:8080/boot.ipxe`.
2. **Exercise 2 (Configuring ISC Kea Client Classes for BIOS PXE, UEFI PXE, and UEFI HTTP Boot):** Match `option[93].hex == 0x0000` (`undionly.kpxe`), `0x0007` (`ipxe.efi`), and `0x0010` (`HTTPClient`, `http://.../shimx64.efi`); setting `boot-file-name` globally without client classes breaks PXE clients that cannot fetch HTTP URLs.
3. **Exercise 3 (Comparing Stateless `RAM-root`, Stateful `Diskful`, `NFS-root`, and Hybrid Node Provisioning):** Hybrid provisioning boots an immutable `rootfs.squashfs` into RAM (`overlayfs`) for zero OS drift while mounting local NVMe for `/tmp`, `/var/log`, and `ENROOT_DATA_PATH`, and injects per-node `/etc/machine-id`, SSH host keys, and `munge.key` at boot.
4. **Exercise 4 (Building, Testing, and Rolling Out a Versioned GPU OS Image in Rings):** Build a versioned `dgx-os-24.04-YYYY-MM-DD` squashfs image with coupled kernel/NVIDIA/MOFED drivers, validate on a canary group (`node_health.sh` + `nccl-tests`), update wave pointers in Git, and roll out drain-free via `scontrol reboot ASAP nextstate=resume`.
5. **Exercise 5 (Applying the `D-T-B-I` Network Boot Triage Method):** (a) `D` (DHCP VLAN/relay/server down), (b) `T` (TFTP boot storm; chain-load iPXE and serve `initrd.img` over HTTP), (c) `B` (Secure Boot rejecting unsigned `ipxe.efi` or wrong architecture), and (d) `I` (`initramfs` missing the Linux kernel driver for the provisioning NIC).
6. **Exercise 6 (Comparing Out-of-the-Box Stacks `ROCKS` and `Parallel Knoppix/PelicanHPC` with Modern Provisioners):** `ROCKS` uses `frontend` mode, `Roll CDs`, and `insert-ethers` (`F1` exit) into MySQL, and `PelicanHPC` runs as a Debian LiveCD using `pelican_setup` (`/home/user/tmp/bhosts`) and `pelican_restart_hpc`, whereas xCAT, Warewulf 4, and BCM manage versioned stateless/hybrid images and API/Git inventories at scale.
