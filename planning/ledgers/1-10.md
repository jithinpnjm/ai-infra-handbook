## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Device Nodes, Major/Minor Numbers, and `mknod` vs `nodev`):** (a) `b` = block device (random-access fixed blocks, cached), `c` = character device (unbuffered byte stream / `ioctl`), `p` = FIFO named pipe, `s` = Unix domain socket; in `8, 1`, `8` is the major number selecting the `sd` SCSI disk driver and `1` is the minor number selecting partition `sda1`; (b) `sudo mknod /tmp/mynull c 1 3` creates a character node pointing to the kernel's `1:3` null driver, and mounting `/tmp` with `nodev` prevents the kernel from honouring any device nodes on `/tmp`.
2. **Exercise 2 (`udev` Event Flow and Operators `==`, `!=`, `=`, `+=`, `:=`):** (a) `==` and `!=` are match conditions, `=` assigns (replacing earlier values), `+=` appends to a list (such as `SYMLINK+=`), and `:=` assigns and locks the value against later rules; (b) after adding `/etc/udev/rules.d/90-lab.rules`, run `sudo udevadm control --reload` and `sudo udevadm trigger` (and verify with `udevadm test`).
3. **Exercise 3 (SCSI 3-Layer Stack, `[host:channel:target:lun]`, and `/dev/sg*`):** (a) `[2:0:0:3]` means host adapter `2`, bus channel `0`, target ID `0`, and logical unit (LUN) `3`; (b) the three SCSI layers are top class drivers (`sd`, `sr`, `st`, `sg`), middle SCSI core, and bottom host-adapter drivers (`ahci`/`libata`, `usb-storage`, `mpt3sas`), while `/dev/sg*` generic nodes (`lsscsi -g`) let user-space tools (`smartctl`, `sg3_utils`, optical burners) send raw SCSI commands directly to hardware.
4. **Exercise 4 (PCIe Link Health in `sysfs` and `lspci -vvv`):** A GPU reporting `current_link_speed = 32.0 GT/s`, `current_link_width = 8`, `max_link_speed = 32.0 GT/s`, `max_link_width = 16` has `width_degraded = True` and `bandwidth_ratio = 0.5` (`50%` of rated bandwidth due to a riser, slot, or BIOS bifurcation issue).
5. **Exercise 5 (`nvidia-smi topo -m` Interconnect Hierarchy and NUMA Affinity):** From fastest to slowest: `NV#` (NVLink lanes) > `PIX` (single PCIe bridge) > `PXB` (multiple PCIe bridges) > `PHB` (PCIe host bridge within one CPU/NUMA node) > `NODE` (across NUMA nodes within a socket) > `SYS` (across the inter-socket SMP link); `numa_node` and `local_cpulist` in `/sys/bus/pci/devices/<BDF>/` identify which CPU cores should drive that GPU/NIC.
6. **Exercise 6 (`procfs` vs `sysfs` and Persistent `sysctl` Tuning):** `sysctl_key_to_proc_sys_path("net.ipv4.ip_forward")` maps to `/proc/sys/net/ipv4/ip_forward`; writes to `/proc/sys` or `/sys` modify in-RAM kernel state only and must be persisted via `/etc/sysctl.d/90-gpu-node.conf` (`sudo sysctl --system`) or `udev` `ATTR{...}=` rules.
