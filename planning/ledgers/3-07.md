## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (WSGI vs. ASGI, `async def` vs. `def`, and Uvicorn Multi-Worker Sizing, `FA` Ch. 1 & `volume-02`):** WSGI is synchronous while ASGI is event-loop-driven (with Starlette providing ASGI routing/middleware and Pydantic providing validation); `async def` runs directly on the event loop (stalling all requests if `time.sleep` or `requests.get` is called) whereas `def` runs in AnyIO's 40-thread pool; and GPU services run one worker per GPU to avoid duplicate VRAM allocations while CPU control-plane APIs run multiple uvicorn workers (`-w N`).
2. **Exercise 2 (Routing, Parameter Validation, and Input/Output Schema Separation, `FA` Ch. 2, 3, 5):** Path parameters match `{param}` in the URL template (`Path(...)`), other scalars/lists default to query parameters (`Query()`), `Header()`/`Cookie()` extract headers/cookies, and Pydantic models parse the JSON body; fixed routes (`/nodes/summary`) must precede `/nodes/{id}`, and separating `NodeIn` (`extra="forbid"`) from `NodeOut` / `TodoItems` (`response_model`) prevents mass assignment and internal field leaks.
3. **Exercise 3 (Dependency Injection `Depends`, Generator Teardown, Lifespan State, and RFC 9457 Errors, `FA` Ch. 3, 6, 7):** A generator dependency (`async def get_db(): ... yield session`) runs setup before the handler and closes the session after the response, while `@asynccontextmanager async def lifespan(app):` initializes shared `app.state.http` and models once per worker; `@app.exception_handler` maps domain errors to RFC 9457 `application/problem+json` bodies tagged with `x-request-id`.
4. **Exercise 4 (Authentication, `HashPassword`, OAuth2/JWT Scopes, and Object-Level Ownership `BOLA`, `FA` Ch. 7):** Using `HashPassword`, `create_access_token()`, `verify_access_token()`, and `EventPlannerRepository`, `/user/signup` stores salted password hashes, `/user/signin` issues signed JWTs with an `expires` claim verified by `Depends(authenticate)`, and `update`/`delete` check `if current.creator != authenticated_user:` to block Broken Object-Level Authorization (`BOLA`).
5. **Exercise 5 (SQL/NoSQL Persistence, `202 Accepted` Job Queues, and SSE Streaming, `FA` Ch. 6):** Partial updates filter out `None`/unset fields (`{k: v for k, v in asdict(patch).items() if v is not None}`), pools obey `workers * pool_size <= max_connections`, and Alembic migrations run in a pre-deploy Job; long jobs enqueue work and return `202 Accepted` (unlike volatile `BackgroundTasks`), while `StreamingResponse` (`text/event-stream`, `X-Accel-Buffering: no`, `await request.is_disconnected()`) streams SSE events (`format_sse_events()`).
6. **Exercise 6 (Testing with `TestClient`/`AsyncClient` `dependency_overrides` and Kubernetes Graceful Shutdown, `FA` Ch. 8 & 9):** `app.dependency_overrides[get_db] = fake_db` swaps dependencies inside a `with TestClient(app) as c:` fixture; in Kubernetes, `livenessProbe` (`/healthz`) stays dependency-free while `readinessProbe` (`/readyz`), `preStop: ["sleep", "5"]`, `--timeout-graceful-shutdown 25`, and `terminationGracePeriodSeconds: 40` drain in-flight connections with zero dropped requests.
