## BCM 11 Administrator Manual Claims
- **Power Control Methods & Operations (Ch. 4):** `powercontrol` supports `apc`, `ipmi0`, `ilo0`, `drac0`, `cimc0`, `rf0`, and `custom` (`custompowerscript <op> <device> [arg]`, `$CMD_MAC`). `PowerOffPDUOutlet = true` cuts PDU outlet after BMC power-off (requires BIOS power-on after AC loss). Default `device power` delay is `1 s` (`-d`), `-p N` batches `N` items with `20 s` (`--parallel-delay`) between batches (`12` racks with `-p 3` start at `0, 20, 40, 60 s`), `PowerThreadPoolSize = 32`, `--retry-delay = 3 s`.
- **BMC Networks, Credentials & Hardware Commands (§3.7, §14.11, App. N):** `bmcnet` defaults to `10.148.0.0/16`, user `bright`, slot `4`, privilege administrator (`racadm ... Privilege 511` on iDRAC). `credentialsoverview --inverse` groups by session-salted SHA-256 fingerprint, outliers first. Commands: `identify`, `bmceventlog`, `bmcreset`, `hardwareinventoryinfo`, `lspci`, `lseeprom`, `accelerators`, `redfishsubscriptions`, `rconsole`, `leakdetection enable|disable`, `leakinfo`, `pduoverview`, `cduoverview`, `powershelfoverview`.
- **BIOS, Firmware & SOL (§14.5.2, §14.5.3, §14.7):** BIOS states: edit $\rightarrow$ `commit` (`Configured`) $\rightarrow$ `bios apply` (`Pending`) $\rightarrow$ reboot (`Live`); `<default>` is ignored. Firmware uses `firmwaremanagemode` (`auto`, `h100`, `b200`, `b300`, `gb200`, `gb200sw`, `gb300`, `gb300sw`, `iLO`, `none`) and requires an AC power cycle (`success: AC power cycle to activate` $\rightarrow$ `success: activated`) on DGX H100 GPU trays. SOL uses `115200` bps on `ttyS0` (`x86_64`) or `ttyAMA0` (`aarch64`).
