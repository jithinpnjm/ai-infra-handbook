## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) `TTFT = 200.9 ms` (`180.5 ms` GPU + `20.4 ms` non-GPU), per-step `ITL = TPOT = 24.0 ms` (`22.0 + 0.5 + 0.5 + 1.0 ms`), and `E2E = 200.9 + 49 * 24.0 = 1,376.9 ms`; (b) the `3,000 ms` outlier skews `mean TTFT` to **`390.0 ms`** while **`p50 = 100.0 ms`**, Goodput is **`30 RPM` (`3.0 RPS`)** at `30%` SLO attainment, and cost per `1,000` requests is **`$1.11` decode (`$5.556/1M` tokens) + `$0.33` prefill = `$1.44`**.
2. **Exercise 2:** (a) Non-GPU stages consume **`78.64%`** (`324.0 ms / 412.0 ms`) of total latency and Python tokenization alone consumes **`77.67%` (`~77.7%`, `320.0 ms`)**; switching to a `16`-thread Rust tokenizer (`1.4 ms`) cuts total span to **`93.4 ms`** (`228.6x` faster tokenization) and raises throughput **`6.5x` (`120 -> 780 RPS`)**; (b) pinned `cudaHostAlloc` (`55–62 GB/s`) is **`4.4x–5.5x` faster** than pageable `malloc` (`10–14 GB/s`), and Nginx `proxy_buffering on` holds `20 ms` SSE chunks until `4 KB` (`~30–40` tokens) accumulates, causing **`600 ms` UI freezes**.
3. **Exercise 3:** (a) The FP16 Roofline ridge point is **`419.04 FLOPs/Byte` (`~419`)** on L40S (`362.05 TFLOPS / 864 GB/s`) and **`295.22 FLOPs/Byte` (dense) / `590.75 FLOPs/Byte` (sparse)** on H100 SXM5 (`3,350 GB/s`); (b) for `h = 4096`, prefill intensity is **`62.06` (`s = 64`, bandwidth-bound)**, **`409.60` (`s = 512`, compute-bound on H100 dense, borderline on L40S)**, and **`1,365.33 FLOPs/Byte` (`s = 4096`, compute-bound)**, whereas single-stream decode (`s = 1`) is **`1.00 FLOP/Byte` (`4096 / 4098 = 0.9995`, deeply memory-bandwidth-bound)**.
4. **Exercise 4:** (a) Streaming `140 GB` of `70B` FP16 weights takes **`41.79 ms` (`23.93 tok/s` / `~24 tok/s`) on H100 SXM5**, **`29.17 ms` (`34.29 tok/s`) on H200 SXM**, and **`17.50 ms` (`57.14 tok/s`) on B200**; (b) on a `2,000 GB/s` A100-80GB, `700 GB/s` of weight traffic equals **`35.0%` MBU** (`50 tok/s` at `2B/param` or `100 tok/s` at `1B/param`) and `1,400 GB/s` equals **`70.0%` MBU**.
5. **Exercise 5:** (a) Llama-3-70B GQA uses **`327,680 bytes/token` (`327.68 KB`)**, **`1.342 GB` per `4K` sequence**, **`85.90 GB` (`85.76 GB`) at `64` sequences**, and **`134.22 GB` (`134.2 GB`) at `100` sequences**; adding `140 GB` weights + `10 GB` workspace gives **`284.2 GB` total VRAM**, requiring **`4x 80 GB` H100 GPUs (`TP = 4`, `320 GB`)**; (b) `64`-head MHA uses `2,621,440 B/tok` (**`8x` larger**, `~687 GB` vs `~86 GB` for `128 x 2048`), and Llama-2-7B (`14 GB` weights, `0.5 MiB/tok`) uses **`32.0 GB` KV cache** for `16 x 4096` (`2.0 GB/seq`), so `24 GB` A10 (`10 GB` free) fits **`4` sequences** while `48 GB` L40S (`34 GB` free) fits **`16` sequences**.
6. **Exercise 6:** (a) On `logits = [4.0, 3.0, 2.0, 1.0, 0.0]`, `temperature = 0.0` selects **`token_id = 0` (`prob = 1.0`)**, `top_k = 3` + `top_p = 0.80` retains the **top `2` tokens (`0.6364 + 0.2341 = 0.8705 >= 0.80`)** and renormalizes to `[0.7311, 0.2689, 0, 0, 0]`, and `repetition_penalty = 2.0` on token `0` halves its logit (`4.0 -> 2.0`) so **`token_id = 1` (`logit = 3.0`) wins**; (b) the five stop conditions are **`eos_token`, `stop_string`, `max_tokens`, `model_length`, and `abort`**, and Chunked Prefill slices `16K` prompts into **`512`-token chunks** interleaved with decode steps to cut P99 ITL from **`4,500 ms` to `22.8 ms`**.
