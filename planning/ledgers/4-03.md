## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Ansible Architecture, Agentless Task Execution `AnsiballZ`, and Push vs. Pull Convergence, `AUR` Ch. 1):** On each task, the control node templates args locally, connects via SSH (`ControlPersist`), streams or uploads an `AnsiballZ` Python payload to `~/.ansible/tmp/`, runs it with remote Python (logging to syslog and returning JSON), and cleans up; unlike pull-based CFEngine/Puppet convergence or stateful Terraform DAGs, Ansible runs tasks procedurally top-to-bottom in a single push pass (with `ansible-pull` for pull mode and `ansible_runner.run()` for Python embedding).
2. **Exercise 2 (Packaging Tiers `ansible-core` vs. `ansible`, Collections, Execution Environments, and Vagrant Testbeds, `AUR` Ch. 1 & 2):** `ansible-core` provides the engine and `ansible.builtin` modules while Collections (`requirements.yml`, FQCN `ansible.builtin.copy`) and Execution Environments (`ansible-builder` / `ansible-navigator`) package reproducible dependencies; `vagrant ssh-config` provides `127.0.0.1:2222` and `.vagrant/machines/default/virtualbox/private_key` for `inventory/vagrant.ini`, and `ansible_local` runs Ansible inside the guest VM itself.
3. **Exercise 3 (`ansible.cfg` Discovery Precedence, SSH Multiplexing, Pipelining, and `become` Sudo Rules, `AUR` Ch. 2):** Using `resolve_ansible_cfg_path()`, Ansible checks `ANSIBLE_CONFIG` > `./ansible.cfg` (ignored if the directory is world-writable) > `~/.ansible.cfg` > `/etc/ansible/ansible.cfg`; `ControlPersist=60s` and `pipelining = True` (requiring `!requiretty`) eliminate SSH round-trips; and command-specific `sudoers` rules fail because Ansible executes random `~/.ansible/tmp/...` script paths.
4. **Exercise 4 (Inventory Basics and Host-Pattern Set Algebra `match_host_pattern`):** Using `match_host_pattern()`, `gpu:login` computes set union, `gpu:&rack1` computes intersection, `gpu:!gpu02` computes exclusion, and `~gpu0[1-4]` matches by regex, while `--limit` restricts execution to a canary subset.
5. **Exercise 5 (Ad-Hoc Commands and Idempotency `simulate_idempotent_file_module`):** `command` executes binaries directly without a shell, `shell` invokes `/bin/sh` for pipes/redirects, and `raw` runs over SSH without remote Python; `simulate_idempotent_file_module()` shows declarative modules (`file`, `package`, `service`) return `changed=True` on the first run and `changed=False` (`ok`) on reruns (and simulate changes without mutating in `--check` mode).
6. **Exercise 6 (Writing, Dry-Running `--check --diff`, and Troubleshooting `site.yml`):** `--syntax-check` validates YAML/play structure, `--check --diff` previews file and state diffs, and a second apply reaching `changed=0` in `PLAY RECAP` confirms idempotency; `-vvvv` and `ANSIBLE_KEEP_REMOTE_FILES=1` diagnose SSH auth, `sudo`, missing Python interpreter, and performance bottlenecks.
