## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) For the `70B` model under `16 * Psi` (`1,120.0 GB` state) on `N_d = 8` GPUs: `Stage 0` (`DDP`) = **`1,120.0 GB` (`1.0x`)**, `Stage 1` = **`385.0 GB` (`2.91x`)**, `Stage 2` = **`262.5 GB` (`4.27x`)**, `Stage 3` = **`140.0 GB` (`8.0x`)**, and on `N_d = 16` GPUs `Stage 3` = **`70.0 GB` (`16.0x`)**; (b) for the `10B` pure-`FP32` model (`160.0 GB`) on `N_d = 8` GPUs: `DDP` = **`160.0 GB`**, `Stage 1` = **`90.0 GB` (`1.78x`)**, `Stage 2` = **`55.0 GB` (`~2.9x` [`2.91x`], leaving `25.0 GB` headroom on `80 GB` GPUs)**, `Stage 3` = **`20.0 GB` (`8.0x`)**, and for the `30B` model (`360.0 GB`) under `ZeRO-2` on `N_d = 16` GPUs: `FP32` weights require **`135.0 GB`** (`120 + 15 GB`, OOM on `80 GB` GPU) whereas `FP16` weights require **`75.0 GB`** (`60 + 15 GB`, or **`78.75 GB`** exact with `3.75 GB` `FP16` gradients + `15 GB` optimizer).
2. **Exercise 2:** (a) For a `70B` `FP16` model (`M = 140.0 GB`) on `N_d = 8` GPUs, `ZeRO Stage 1` and `Stage 2` both transfer **`280.0 GB` asymptotically (`2 * M`)** and **`245.0 GB` exact ring (`2 * 7/8 * 140.0 GB`)** per step, whereas `ZeRO Stage 3` transfers **`420.0 GB` asymptotically (`3 * M`)** and **`367.5 GB` exact ring (`3 * 7/8 * 140.0 GB`, `1.5x` `Stage 1/2`)**; (b) on `64` GPUs (`8 x 8`), enabling `qwZ` alone halves each `AllGather` (`1.0 * M -> 0.5 * M`) to reduce total volume from `420.0 GB` (`3.0 * M`) to **`280.0 GB` (`2.0 * M`)**, enabling full **`ZeRO++` (`qwZ + hpZ + qgZ`)** cuts cross-node InfiniBand traffic by **`4.0x` (`3.0 * M = 420.0 GB -> 0.75 * M = 105.0 GB`)**, and `"fp16": {"enabled": true}` is mandatory because `CUDAQuantizer` dequantizes `INT8` buffers directly to `FP16`.
3. **Exercise 3:** (a) On `8` `80 GB` `A100` GPUs, the `70B` (`12 * Psi = 840.0 GB`) model under `ZeRO-3` requires **`105.0 GB`/GPU** without offload (**`25.0 GB` shortfall**), offloading to CPU over `PCIe Gen4` (`32 GB/s`) slows training by **`21.25x` (`~21x`, `8.5 -> 0.4 tok/s`, `12%` GPU util, `60 GB` GPU / `850 GB` CPU RAM)**, and `NVMe` thrashing (`5–7 GB/s`) slows it by **`85x` (`8.5 -> 0.1 tok/s`, `65%` `%iowait`, `95%` GPU idle)**; (b) Grace-Blackwell's **`900 GB/s` `NVLink-C2C`** is **`28.125x` faster** than `32 GB/s` `PCIe Gen4 x16`, and `SuperOffload` combines `NVLink-C2C`, Speculation-Then-Validation (`STV`), and ARM `SVE` `GraceAdam` (`32` vector / `16` predicate registers) to maintain **`82%` GPU utilization**.
4. **Exercise 4:** (a) By the batch identity `train_batch_size = 4 * 8 * 8` = **`256`**; (b) at `2 bytes/element` (`FP16`), `reduce_bucket_size=5e8`, `allgather_bucket_size=5e8`, and `stage3_prefetch_bucket_size=5e8` each occupy **`1.0 GB`**, `stage3_max_live_parameters=1e9` caps unsharded parameters in `HBM` at **`2.0 GB`**, `stage3_param_persistence_threshold=1e5` (`0.2 MB`) keeps tiny tensors (`<= 100,000` elements) permanently unsharded in `HBM`, and `sub_group_size=1e9` (`2.0 GB`) bounds the parameter count per optimizer update sub-step.
5. **Exercise 5:** (a) Before `all_to_all_seq_to_head` (`P = 4`), each GPU holds shape **`(2, 8192, 32, 128)`** (`(B, S/P, H, d)`); after the `AllToAll` transpose, each GPU holds **`(2, 32768, 8, 128)`** (`(B, S, H/P, d)`); (b) `DeepSpeed-Ulysses` outperforms Ring Attention for moderate sequence-parallel degrees (**`P <= 8`**) on fast intra-node `NVLink` (`1 / P` collective volume and standard FlashAttention without partial-softmax accumulation), and `P` cannot exceed the number of attention/KV heads `H` (`H` must be divisible by `P`).
6. **Exercise 6:** (a) On `64` GPUs with `TP = 4` and `PP = 2`, the data-parallel degree is **`d = 64 / (4 * 2) = 8`**, and Megatron's Distributed Optimizer reduces `fp16/fp16` from `20` to **`6.0 B/param` (`3.33x`)**, `bf16/fp32` from `18` to **`7.5 B/param` (`2.40x`)**, and `fp32/fp32` from `16` to **`9.0 B/param` (`1.78x`)**; (b) `LLaMA-3 8B` (`8` GPUs, `TP=1, PP=1, CP=2`) has **`DP = 4`** and **`32` micro-batches/replica** (`128 / 4`); `GPT-3 175B` (`128` GPUs, `TP=8, PP=16`) has **`DP = 1`** and **`6` layers/stage** (`96 / 16`); and `Mixtral 8x7B` (`64` GPUs, `EP=8, TP=1, PP=4`) has **`8` layers/stage** (`32 / 4`) with `1` expert per GPU in each `8`-GPU EP group.
