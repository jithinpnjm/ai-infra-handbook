## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Anatomy of `terraform.tfstate` and Why State Must Never Live in Git, `TUR` Ch. 3):** State maps HCL addresses to real cloud IDs, tracks metadata/dependencies, caches attributes, and synchronizes teams; `RemoteStateBackend` uses `lineage` (UUID) and monotonically increasing `serial` to prevent cross-state overwrites and stale-plan applies; and storing state in Git fails due to manual pull/push human error, lack of locking, and plaintext secrets.
2. **Exercise 2 (Hardened Remote Backends, Chicken-and-Egg Bootstrapping, and Partial Configuration, `TUR` Ch. 3):** Harden S3 state with `aws_s3_bucket` (`prevent_destroy`), `aws_s3_bucket_versioning`, `aws_s3_bucket_server_side_encryption_configuration`, `aws_s3_bucket_public_access_block`, and `use_lockfile = true` / `aws_dynamodb_table` (`LockID`); bootstrap with local state then `terraform init -migrate-state`; and pass environment-specific backend settings via `-backend-config=backends/prod.hcl`.
3. **Exercise 3 (Distributed State Locking and Stale Saved Plans in CI):** `acquire_lock()` prevents concurrent writers (`-lock-timeout=5m`), `force-unlock <LOCK_ID>` clears crashed locks only after verifying no job is active, and `apply_saved_plan()` rejects a `tfplan` if the remote state's `serial` changed since the plan was computed.
4. **Exercise 4 (State Isolation Layout and Cross-State Data Sharing, `TUR` Ch. 3):** Split state by environment (`prod/`, `stage/`, `mgmt/`, `global/`) and lifecycle layer (`network/`, `storage/`, `k8s-cluster/`, `gpu-pools/`); use provider `data` sources or SSM/Secret Manager for cross-team boundaries and `terraform_remote_state` only when the consumer is trusted to read the producer's entire state file.
5. **Exercise 5 (Zero-Downtime Cross-State Resource Splitting and Disaster Recovery):** `migrate_resource_between_states_declaratively()` imports the resource into target State B (`import {}`) and forgets it from source State A (`removed { lifecycle { destroy = false } }`) with clean plans at each step; lost/corrupted state is restored from S3/GCS object versions or reconstructed via `import` blocks.
6. **Exercise 6 (Drift Detection and Protecting Secrets in State):** Detect drift nightly with `terraform plan -detailed-exitcode` (`-refresh-only`) and either **revert** (`apply`), **adopt** (update `.tf`), or **tolerate** (`ignore_changes = [node_count]`); protect secrets via IAM state isolation, external secret managers (`manage_master_user_password`), ephemeral/write-only attributes, and OpenTofu client-side state encryption.
