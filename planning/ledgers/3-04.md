## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Classes, Inheritance Search, `classscope3.py`, Bound Methods, `__slots__`, and `Vector2d`, `LP` Ch. 26–32 & `FP` Ch. 11):** `object.attr` climbs `self.__dict__` -> `self.__class__` -> `self.__class__.__mro__` whereas `LEGB` inside methods skips `class` scopes (`classscope3.py` prints `nester`'s `X = 2`), and `__slots__` requires every class in the hierarchy to define `__slots__` without repeating slot names or class-level defaults; in `Vector2d` and `PseudoprivateC3`, `__bytes__`/`frombytes` serialize binary `array('d')` payloads, `__format__` adds `'p'` polar coordinates, and `__X` mangles to `_C1__X` and `_C2__X`.
2. **Exercise 2 (Inheritance Patterns, Cooperative `super()` & C3 MRO, Mixins, and Composition, `LP` Ch. 28, 29, 31 & `FP` Ch. 14):** Cooperative `super()` requires universal deployment, a call-chain anchor before `object`, and compatible signatures along the C3 MRO `(D, B, C, A, object)`; `UpperCaseMixin` must precede `collections.UserDict` in `class UpperDict(UpperCaseMixin, collections.UserDict):` so its methods intercept calls first and delegate via `super()`, while composition (`PizzaShop`, `Department`, `RedfishClient`) decouples collaborators via dependency injection.
3. **Exercise 3 (Four Approaches to Interfaces: Duck Typing, Goose Typing `Tombola` ABC, Nominal Typing, and Static Duck Typing `Protocol`, `FP` Ch. 13):** `Tombola(ABC)` enforces `@abstractmethod` (`load`, `pick`) at runtime instantiation and supports virtual subclasses via `.register()` (or `__subclasshook__` on `abc.Sized`), whereas `typing.Protocol` (`SupportsLessThan` in `top()`) checks structural method presence statically (and at runtime with `@runtime_checkable`) without requiring inheritance.
4. **Exercise 4 (Data Class Builders: `namedtuple`, `NamedTuple`, `@dataclass` `HackerClubMember`, and Pydantic, `FP` Ch. 5):** Bare `a: int` creates only an `__annotations__` entry in a plain class, a read-only tuple descriptor in `typing.NamedTuple`, and an `__init__`-assigned instance attribute in `@dataclass`; `HackerClubMember` uses `field(default_factory=list)` for mutable per-instance lists, `ClassVar[set[str]]` for class state `all_handles`, and `__post_init__` to derive and validate unique handles, while Pydantic `BaseModel` (`extra="forbid"`, `SecretStr`) validates and coerces untrusted external inputs at runtime.
5. **Exercise 5 (Type Hints, Generics `LottoBlower[T]`, Variance, `@overload`, and `TypedDict`, `FP` Ch. 8 & 15):** Functions should accept general `Mapping`/`Sequence`/`Iterable` parameters and return concrete `list`/`dict`, and prefer `object` over contagious `Any`; mutable `list[T]` is invariant, read-only `Sequence[T_co]` (`BeverageDispenser[T_co]`) is covariant, write-only `TrashCan[T_contra]` is contravariant, and `Callable[[Arg], Ret]` is contravariant in `Arg` and covariant in `Ret`.
6. **Exercise 6 (Sequence Special Methods and Operator Overloading: `Vector`, `SkipObject`, `Commuter5`, `Version`, `FP` Ch. 12 & 16, `LP` Ch. 30):** `Vector.__getitem__` returns a new `Vector` on `slice` and calls `operator.index(key)` otherwise, `__getattr__` + `__setattr__` expose read-only `v.x, v.y, v.z, v.t` while blocking lowercase single-letter shadowing, and `SkipObject.__iter__` returns a fresh iterator on each call so nested loops yield all 9 pairs; `__add__`, `__mul__`, and `__matmul__` (`@`) return `NotImplemented` on unsupported types so Python dispatches to `__radd__`/`__rmul__`/`__rmatmul__`, while `__iadd__` mutates in place and returns `self`.
