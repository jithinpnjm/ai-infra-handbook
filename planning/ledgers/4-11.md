## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Role Directory Anatomy, `defaults/main.yml` vs. `vars/main.yml`, and File Search Paths, `AUR` Ch. 9):** Public overridable inputs belong in `defaults/main.yml` (lowest precedence, prefixed with `role_`) while `vars/main.yml` holds high-precedence internal constants; `role_file_search_candidates()` checks `./roles/<role>/files/` first before falling back to `./files/` next to the playbook.
2. **Exercise 2 (Role Contract Validation `meta/argument_specs.yml` and Role Dependencies `meta/main.yml`, `AUR` Ch. 9):** Using `validate_role_argument_spec()`, Ansible validates option types, defaults, and `choices` at role entry and generates `ansible-doc -t role` docs; `resolve_role_dependency_order()` runs dependencies before dependents and deduplicates shared dependencies unless `allow_duplicates: true` is set.
3. **Exercise 3 (Invoking Roles `roles:`, `import_role`, `include_role`, `tasks_from` and OS Portability `first_found`):** `roles:` runs between `pre_tasks` and `tasks`, `import_role` is static at parse time, and `include_role` is dynamic at runtime (supporting `loop:` and `tasks_from: validate`); `include_vars` + `first_found` loads OS-specific internal package/path maps from `vars/`.
4. **Exercise 4 (Designing Reusable GPU Infrastructure Roles `kernel_tuning`, `gpu_facts`, `gpu_driver`):** Combining `kernel_tuning_sysctl` with `kernel_tuning_sysctl_extra` via `combine` lets callers override individual sysctls without losing defaults, and `gpu_driver` sets a `gpu_driver_reboot_required` fact rather than triggering surprise reboots inside the role.
5. **Exercise 5 (Sourcing Third-Party Roles and Collections Safely `requirements.yml`, `AUR` Ch. 9 & 15):** Pin exact role and collection versions in `requirements.yml`, install with `ansible-galaxy role/collection install -r requirements.yml`, audit code (since roles run as `root`), mirror in an internal Hub/Artifactory, and test upgrades with Molecule in CI.
6. **Exercise 6 (Building, Testing `ansible-test`, and Publishing an Ansible Collection, `AUR` Ch. 15):** Initialize with `ansible-galaxy collection init acme.gpu`, configure `galaxy.yml` and `meta/runtime.yml`, build with `ansible-galaxy collection build`, test with `ansible-test sanity/units/integration`, and publish to Automation Hub or Galaxy.
