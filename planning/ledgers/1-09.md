## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Parameter Expansion Without Subprocesses):** For `path="/data/run42/model.final.ckpt"`, `${path##*/}` = `"model.final.ckpt"`, `${path%/*}` = `"/data/run42"`, `${path%.*}` = `"/data/run42/model.final"`, `${path##*.}` = `"ckpt"`, and `${#path}` = `28`; `${dir:?dir is empty}` aborts the script immediately if `dir` is unset or empty, preventing `rm -rf $dir/*` from becoming `rm -rf /*`.
2. **Exercise 2 (`"$@"` vs `$@` vs `"$*"` and `shift`):** Given arguments `'abc 123'` and `'qwe'`, `"$@"` expands to two words `["abc 123", "qwe"]`, unquoted `$@` word-splits into three words `["abc", "123", "qwe"]`, and `"$*"` joins them into one word `["abc 123 qwe"]`; `shift` discards `$1` and shifts `$2` into `$1` (decrementing `$#`).
3. **Exercise 3 (`set -euo pipefail` Suppression Traps):** Under `set -e`, a standalone `false` aborts the script, whereas `if false; then`, `false || true`, `! false`, and `f && echo ok` (even when `false` is NOT the last line inside `f()`) all suppress `errexit` and do **not** abort.
4. **Exercise 4 (Subshells vs Current Shell in Loops and Groups):** `( v=2 )` and `printf '1\n2\n3\n' | while read -r n; do count=$((count+n)); done` execute inside child subshells so outer `v` (`1`) and `count` (`0`) remain unchanged; `{ v=2; }` and `while read -r n ... done < <(printf '1\n2\n3\n')` run in the current shell so `v=2` and `count=6` persist.
5. **Exercise 5 (`mktemp` + `trap` Cleanup and `flock` Non-Blocking Locks):** (a) `TMPFILE1=$(mktemp /tmp/im1.XXXXXX)` creates a unique mode-`0600` file, and `trap "rm -f $TMPFILE1; exit 1" INT` must include an explicit `exit` so the script does not continue executing after `SIGINT`; (b) `exec 9>/var/lock/mytool.lock && flock -n 9` acquires a kernel file-descriptor lock that is automatically released even if the process crashes with `SIGKILL`.
6. **Exercise 6 (Exponential Backoff `retry` and Container `exec` Entrypoint):** (a) `retry 5 2` sleeps `2`, `4`, `8`, and `16` seconds (`30` seconds total across `4` retries before failing on attempt `5`); (b) ending the entrypoint with `exec torchrun ... "$@"` replaces the bash process in place so `torchrun` becomes container `PID 1` and receives `SIGTERM` directly with all arguments preserved.
