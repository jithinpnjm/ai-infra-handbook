## 4. Contradictions found and how resolved

- Draft used `kueue.x-k8s.io/v1beta1` and `cohort`: v0.20.5 serves only v1beta2 with `cohortName`. Fixed.
- Draft `withinClusterQueue: Any` is not in the CRD enum. Fixed to `LowerPriority`.
- Draft KAI memory `1Ti`, `512Gi` and CPU `256`: CRD fields are numbers; units are MB and millicores. Fixed.
- Draft training priority 100 is non-preemptible in KAI. Changed to 50.
- Draft quotas 16 + 4 above a 16-GPU pool. Changed to 12 + 4.
- Draft hybrid used `gpu-driver-version=latest` plus Operator device plugin; NVIDIA page requires disabling both GKE features. Fixed. Managed DCGM also needs GKE-managed drivers, so the Operator's exporter plus PodMonitoring replaces it.
- Draft said "regional" cluster but used `--zone`. Now zonal.
- Draft claimed operands are restricted by a node selector in values. Operands follow `nvidia.com/gpu.deploy.*` labels set on GPU nodes. Claim replaced.
- The gem book's KAI example uses `kai.run.ai/v1` Project. Current KAI uses `scheduling.run.ai/v2` Queue. Upstream wins.
- Draft install `kubectl apply -f kai-scheduler-release.yaml` and Kueue v0.9.0 manifest: replaced by Helm installs at pinned versions.
