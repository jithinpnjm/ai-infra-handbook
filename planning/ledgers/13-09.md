## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) Slowdown factor is **`4.0x`** (`8.0 / 2.0` hours), total CPU decode + augmentation time is **`57.3 s`** (`45.2 + 12.1 s` across `120,000` calls), and the open rate is **`15,833.33` (`~15.8K`) opens/sec** (`950,000 / 60 s`, well under the `50,000` ops/sec `MDS` ceiling; CPU decode is ruled out because `prefetch_queue.qsize() == 0` for `80%` of steps while GPU `SM` is `15%`); (b) reducing concurrency from `5` jobs (**`640` GPUs**) to `3` jobs (**`384` GPUs**) after setting `ethtool -G eth0 rx 4096 tx 4096` drops retransmits from `300/sec` to **`0/sec`**, restores `open()` latency from `45.0 ms` to **`2.0 ms`**, and raises GPU `SM` utilization from `15%` to **`88%`**.
2. **Exercise 2:** (a) Data-parallel gradient `AllReduce` bytes scale strictly with model parameter count ($2 \frac{N-1}{N} |\Theta| \text{sizeof(grad)}$) and are independent of micro-batch size $B$; (b) when batch size is doubled (`2.0x`), Run B's `AllReduce` share of iteration time drops from **`50.0%`** (`50 / 100 ms`) to **`33.33%`** (`50 / 150 ms`), proving Run A (`60.0 GB/s` flat) is **`COMMUNICATION_BOUND`** and Run B (`60.0 -> 40.0 GB/s` at `0.5x`) is **`COMPUTE_BOUND`**.
3. **Exercise 3:** (a) The five `100 MiB` CPU-bounce trials average **`0.251 s`** (`0.2512 s`) and **`398 MiB/s` (`398 MB/s`)**, while `gdsio` `-x 0` (`9.6 GB/s`, `1.00 ms`) delivers **`+20.0%` throughput uplift** and **`-20.0%` latency reduction** over `-x 2` (`8.0 GB/s`, `1.25 ms`), meeting the **`>= 20.0%` (`DEPLOY_GDS`)** threshold; (b) on Lustre, `io_offset = 4,096 B` violates **`8 KiB` (`8,192 B`) alignment** and `io_request = 512 KiB` violates the **`>= 1 MiB` (`1,048,576 B`)** minimum size, triggering silent fallback to `POSIX` compatibility mode (`24.5%` `__memcpy_avx2`).
4. **Exercise 4:** (a) Local `NVMe` model load (`3.5 GB/s`) is **`2.33x` faster** than shared storage (`1.5 GB/s`), exceeding the **`> 2.0x`** local caching threshold; (b) staging the `500 GB` checkpoint to `10x` faster local `NVMe` (`10.0 GB/s`) cuts the critical-path stall from `500.0 s` (`1.0 GB/s`) to **`50.0 s`**, saving **`450.0` seconds** (**`9/10` = `90.0%`** of stall time).
5. **Exercise 5:** (a) Repackaging `10,000` files into `100` `.tar` shards (`100` files/shard) cuts `open()` calls by **`100.0x`** and reduces average batch wait from `620.0 ms` to `31.0 ms` (**`95.0%` improvement**); (b) repackaging `1,000,000` files into `1,000` `WebDataset` shards (`1,000` files/shard) cuts `open()` calls by **`1,000.0x`** and reduces the `47.0`-minute per-epoch metadata stall to **`0.047` (`~0.05`) minutes** (`2.82` seconds).
6. **Exercise 6:** (a) `nvme0n1` is **`HEALTHY`** (`52 C < 70 C`, `18% < 95%`), `nvme1n1` is **`CRITICAL_THERMAL_THROTTLE`** (`82 C >= 80 C` critical + `96% >= 95%` endurance wear, throttled to `0.65 GB/s`), and `nvme2n1` is **`CRITICAL_RAID0_FAILURE` / `CRITICAL_MEDIA_ERROR`** (`3` media errors, failed `RAID-0` member destroying scratch stripe); (b) the five `NFS` risks are `soft`-mount `EIO` checkpoint corruption, `32 KB` instead of `1 MiB` `rsize`/`wsize`, missing `noatime`, `ESTALE` (`errno 116`) from server inode replacement, and `32`-node single-server overload; fix with **`-o rw,hard,rsize=1048576,wsize=1048576,noatime,async,actimeo=60,lookupcache=pos`**.
