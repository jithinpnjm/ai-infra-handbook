## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Go Type System, Pointer vs. Value Receivers, Error Wrapping, and `ptr.To`, `NPA` Ch. 7 & `KPG` Ch. 4):** Optional API fields use pointers (`ptr.To` / `ptr.Deref`) to distinguish `nil` (unspecified) from zero values (`0`/`false`), pointer-receiver methods only satisfy interfaces when passed as a pointer (`*T`), and `fmt.Errorf("%w")` pairs with `errors.Is`/`As` and `apierrors.IsNotFound`/`IsConflict`.
2. **Exercise 2 (Concurrency, `context.Context`, `errgroup.WithContext`, and `-race`):** `errgroup.WithContext` + `g.SetLimit(16)` bounds concurrent API calls and cancels the shared `ctx` on the first error, while `go test -race` catches unsynchronized map/struct writes.
3. **Exercise 3 (`apimachinery` Common Types and `runtime.Scheme` / `RESTMapper`, `KPG` Ch. 4 & 5):** `parse_k8s_quantity_milli()` distinguishes `BinarySI` (`1Ki = 1024`) from `DecimalSI` (`1k = 1000`, `2500m = 2.5`), `get_scaled_value_from_int_or_percent()` evaluates `IntOrString` percentages, `runtime.Scheme` maps Go types $\leftrightarrow$ `GVK`, and `DefaultRESTMapper` / `DeferredDiscoveryRESTMapper` translates `GVK <-> GVR`.
4. **Exercise 4 (`client-go` Clients, `QPS`/`Burst`, `RetryOnConflict`, and Server-Side Apply, `KPG` Ch. 6):** Set `cfg.QPS = 50, cfg.Burst = 100` to avoid `5/10` client-side throttling, prefer `Patch` or typed Server-Side `Apply` (`applycorev1.Node(name)` with `FieldManager`) or `retry.RetryOnConflict` over raw `Update`, and use `EvictV1` so drains honor `PodDisruptionBudget`s.
5. **Exercise 5 (Inside `SharedInformerFactory`, `Lister`s `DeepCopy`, `Indexer`s, `workqueue`, and Leader Election, `KPG` Ch. 6):** Event handlers unwrap `cache.DeletedFinalStateUnknown` tombstones and enqueue `"namespace/name"` keys into a rate-limited `WorkQueue` (`Done` + `Forget`), and workers always call `DeepCopy()` before mutating objects returned by a `Lister`.
6. **Exercise 6 (Testing `client-go` Applications `fake.NewSimpleClientset`, `Actions()`, `PrependReactor`, and `envtest`, `KPG` Ch. 7):** `FakeClientsetWithCacheSim` demonstrates `PrependReactor` error injection and `Actions()` verification for fast unit tests, `envtest` runs real `kube-apiserver` + `etcd` binaries for CRD/webhook integration tests, and `CGO_ENABLED=0` builds static binaries for `gcr.io/distroless/static:nonroot`.
