## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (YAML Data Model, Type-Coercion Traps, Block Scalars, and Anchors, `AUR` Ch. 3):** Using `classify_yaml11_unquoted_scalar()` and `apply_yaml_block_chomping()`, YAML 1.1 coerces `NO`->`False`, `1.10`->`1.1`, `010`->`8`, `0x1f`->`31`, `22:30`->`1350`, and `~`->`None` (requiring quotes around versions and file modes like `"0644"`); `|` preserves newlines while `>` folds them (`|-` strips trailing newline, `|+` keeps all); and `&anchor`/`*alias`/`<<` reuse mappings within a single file.
2. **Exercise 2 (Data Serialization Formats and Data Modeling `JSON Schema` & `YANG`, `NPA` Ch. 8):** Reading text-based data off the wire requires decoding bytes to UTF-8 and deserializing into native objects (`json.loads`/`yaml.safe_load`); JSON Schema validates JSON/YAML structure while YANG (RFC 6020/7950 `container`, `list`, `leaf`, `typedef`) models network configuration/state trees serialized on the wire as XML, JSON, or Protobuf.
3. **Exercise 3 (Jinja2 Core: Delimiters, `StrictUndefined`, Filters, Loop `namespace`, and Whitespace Control, `NPA` Ch. 9):** `{{ }}` outputs expressions, `{% %}` runs control statements, and `{# #}` comments; `StrictUndefined` raises an error on missing variables, `trim_blocks`/`lstrip_blocks`/`{%- -%}` eliminate blank lines, `ENV.filters['get_interface_speed']` registers custom Python filter functions, and `namespace(count=0)` carries mutated state out of a `{% for %}` loop.
4. **Exercise 4 (Jinja2 in Ansible: `template`, `validate:`, `default(omit)`, `when:`, `{% raw %}`, `AUR` Ch. 3):** YAML values starting with `"{{ var }}"` must be quoted (so `{` is not parsed as a flow mapping) while `when:` is already a bare Jinja2 expression; `validate: "visudo -cf %s"` checks the rendered temp file before replacing the destination, `default(omit)` drops optional module args, and `{% raw %}` outputs literal `{{ }}` braces.
5. **Exercise 5 (Comparing `Jinja2`, `Helm` Go Templates, `Terraform` `templatefile`, and `Kustomize`):** Ansible uses Jinja2, Helm uses Go `text/template` + Sprig (`{{ .Values.x | quote }}`), Terraform uses HCL `templatefile()`, and Kustomize applies template-free declarative patches over valid YAML manifests; never chain multiple template engines over the same file.
6. **Exercise 6 (Offline Template Rendering, Golden-File Testing, and `SSTI` Security):** Render `.j2` templates offline in `pytest` with `StrictUndefined` against fixture dictionaries, diff against golden files, and validate with `yamllint`/`check-jsonschema`; prevent Server-Side Template Injection (`SSTI`) by never rendering untrusted strings as templates (preserving Ansible's `!unsafe` wrapper), using `yaml.safe_load`, and setting `mode: "0600"`, `no_log: true`, and `diff: false` on secret templates.
