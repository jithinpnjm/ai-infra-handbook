## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) `ROD` wires `GPU i -> Leaf i` (`1`-hop intra-rail, `2`-hop inter-rail via spine, `1/8` rail failure blast radius, no `DPF`), `Rail-Only` removes inter-rail fabric links (`0` network hops inter-rail, routed via internal `900 GB/s` `NVSwitch`), and `RUD` wires all `8` NICs to `1` leaf (or `4+4` to `2` leaves, `1` hop across `4` local servers, requires `DPF`, single-leaf failure isolates all `8` GPUs); (b) across an `8`-rack (`32`-server, `256`-GPU) stripe (`19"x36"x42U` racks, `DGX H100` `8U` `48–60 kW` vs `DGX A100` `6U`), `MoR` has the shortest max cable span (`6` racks) and lower per-compute-rack power/cooling, `ToR` spans `8` racks (more power/cooling per rack, ideal for `RUD` with copper `DAC`/`AEC`), and `EoR` spans `10` racks.
2. **Exercise 2:** (a) On `64 x 400G` switches (`32` down + `32` up) at `1:1`, `1xRow` = `32` servers / `256` GPUs (`8`L/`4`S), `2xRow` = `64` servers / `512` GPUs (`16`L/`8`S), `4xRow` = `128` servers / `1,024` GPUs (`32`L/`16`S), and max `8xRow` = `256` servers / `2,048` GPUs (`64`L/`32`S, reduced `4x` to `8` spines with `256 x 400G` chassis spines); (b) on `144 x 800G` (`Q3400-RD`, `72` down + `72` up, `8` leaves per `576`-GPU SU), `2, 4, 8, 16` SUs scale to `1,152, 2,304, 4,608, 9,216` GPUs with `16, 32, 64, 128` leaves and `8, 18, 36, 72` spines.
3. **Exercise 3:** (a) In a 5-stage Clos, each `64 x 400G` spine in a block reserves `32` ports for Super-Spines and `32` for leaves, so `1 x Block` = `4 x Row` = `1,024` GPUs (`32`L, `32`S, `1,024` super-spine ports); `32K` GPUs require `32` blocks, and `32K`/`64K`/`128K` clusters deploy `8K`/`16K`/`32K` leaf switches; (b) across `32` fixed `64x400G` super-spines (`2,048` ports), oversubscription `1:1..7:1` supports `2, 4, 6, 8, 10, 12, 14` blocks (`8..56` rows) = `2,048, 4,096, 6,144, 8,192, 10,240, 12,288, 14,336` GPUs (`64..448` leaves & spines), whereas a chassis super-spine preserves `1:1` at `2,048`, `8,192`, and `16,384` GPUs (`16` blocks = `64` rows).
4. **Exercise 4:** (a) A `1,500 B` packet in `128 B` cells requires `ceil(1500/128) = 12` cells (`1,536 B` wire, `2.40%` overhead), a `4,100 B` packet in `256 B` cells requires `17` cells (`4,352 B` wire), and `1,024` egress endpoints $\times$ `8` TCs = `8,192` VOQs; (b) 5-stage Clos = `4` hops, Dragonfly `DF`/`DF+` = `3` hops (`8` groups = `8*7/2 = 28` mesh links), `1D`/`2D`/`3D` Torus = `2`/`4`/`6` links per node (`8x8x8` = `512` nodes, `3*(8/2) = 12` max hops); in a `4`-plane (`FP1..FP4`) `800G -> 4x200G` Multi-Planar fabric, a `64x800G` ToR provides `128x200G` downlinks + `32x800G` (`64x400G`) uplinks, retaining `75.0%` (`600 Gbps`) on `1`-plane loss and `50.0%` (`400 Gbps`) on `2`-plane loss.
5. **Exercise 5:** (a) `16 x 400G = 6,400 Gbps` down vs `8 x 400G = 3,200 Gbps` up is `2.0:1` (`200 Gbps`/node, doubling `2 GB` `AllReduce` from `40 ms` to `80 ms`), degrading to `4.0:1` (`1,600 Gbps`, `100 Gbps`/node) when `1` of `2` spines fails; `16 x 800G = 12,800 Gbps` down vs `8 x 400G = 3,200 Gbps` is `4.00:1` normal and `4.57:1` (`7 x 400G = 2,800 Gbps`) on `N-1`; (b) `PortXmitData` shows a `19.9:1` (`~20:1`) static routing skew (`~21.48 GB` on ports `5–6` vs `~1.08 GB` on ports `7–8`; fix with `AR`/`sDLB`), paired `ib_write_bw` (`397.62` vs `201.18 Gbps`) proves a `2:1` cross-rack cut, and `p99` `1.8 ms -> 14.2 ms` (`7.89x`) -> `3.1 ms` proves shared storage/training contention requiring physical Multi-Plane DPU isolation.
6. **Exercise 6:** (a) On a `64`-port switch (`3.0 kW` chassis), `64` optics draw `204.8 W` (`QSFP28` `3.2 W`), `768.0 W` (`QSFP56-DD` `12 W`), or `960.0 W` (`OSFP` `15 W`, `4.69x` `QSFP28`, totaling `3.96 kW` per switch); `4` `DGX H100` (`4 x 13.2 = 52.8 kW`) + `1` `OSFP` switch (`3.96 kW`) = `56.76 kW` IT (`70.95 kW` facility at `PUE 1.25`); (b) Front-to-Back (`F2B`) cools `15 W` front-panel optics first (unlike `B2F` which preheats air through PSUs), a `17.16 kW` rack fits a `20 kW` Rear-Door Heat Exchanger (`RDHx`), a `56.76 kW` rack uses Direct-to-Chip Cold Plates, and a `69.96 kW` (`5`-server) rack uses Cold Plates or Single/Two-Phase Immersion (`~70%` cooling power reduction; Sprayed Liquid reduces total DC energy by `25.8%`).
