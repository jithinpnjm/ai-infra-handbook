## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Evaluating xCAT `hosts.ip` Regex Rules and `policy` Table Authorization):** `eval_xcat_hosts_ip_regex("node15")` strips `node`, captures `15`, and adds `10` to yield `10.0.0.25`; `eval_xcat_policy()` evaluates `policy` rules in ascending priority order so `xadmin` can run `nodels` (priority `2`) and `rpower stat` on `h02-h05` (priority `7`) while destructive `rpower off` commands are denied.
2. **Exercise 2 (Provisioning a 100-Node `statelite` Cluster in xCAT):** Run `copycds`, `mkdef -t node node[1-100]`, `chtab node=compute hosts.ip=...`, `genimage`, populate `litefile` with the 15 writable tmpfs paths, run `add_ssh`/`add_passwd` and `liteimg`, then `makehosts`, `makedhcp`, `makenamed.conf`, `makedns`, `nodeset`, and `rpower node[1-100] boot`.
3. **Exercise 3 (Designing Warewulf 4 Images, Profiles, and `.ww` Overlays):** Import an OCI rootfs with `wwctl image import`, register nodes in `/etc/warewulf/nodes.conf` (`wwctl node add`), inspect template ownership with `wwctl overlay blame n1`, and apply DHCP/TFTP/NFS configs via `wwctl configure --all` (system overlays run once at boot; runtime overlays update periodically).
4. **Exercise 4 (Managing Software Images and Categories in NVIDIA Base Command Manager `cmsh`):** In `cmsh`, clone `default` into `categorytwo`, set `softwareimage imagetwo` (`/cm/images/imagetwo`), move `node099` to `categorytwo`, `commit`, and run `updateprovisioners` so provisioning nodes sync the updated image.
5. **Exercise 5 (Comparing Canonical MAAS and Foreman):** MAAS progresses bare-metal servers through `New -> Commission -> Deploy` using region and rack controllers (`:5240/MAAS`), while Foreman scales DHCP/TFTP/DNS across subnets via `smart-proxies`; disable unattended public repo updates on compute nodes so kernel updates do not break NVIDIA/MOFED drivers.
6. **Exercise 6 (Cluster Manager Selection Matrix for Three Production Scenarios):** Choose NVIDIA BCM for a 512-node DGX H100 SuperPOD (turnkey DCGM/Slurm/K8s and vendor support), Warewulf 4 for a 256-node GitOps/OCI academic cluster, and Confluent when migrating an existing 1,000-node IBM/Lenovo xCAT estate.
