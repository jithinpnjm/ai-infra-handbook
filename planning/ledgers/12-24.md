## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) Observed-to-baseline ratios are `t_typical = 1.58 / 1.55 = 1.0194x` (`+1.94%`), `t_avg = 1.61 / 1.56 = 1.0321x` (`+3.21%`), `p99 = 2.90 / 1.71 = 1.6959x`, and `p99.9 = 5.77 / 1.98 = 2.9141x` (`~2.91x`); looking only at `t_typical`/`t_avg` misses the `2.91x` tail stall that governs synchronous collective barriers; (b) **Gate 2 (`Subnet Management`)** failed (`Physical state: LinkUp` proves Layer 1 is fine, while `State: Initializing` + `Base lid: 0` proves the `SM` has not programmed the port; run `sminfo` first).
2. **Exercise 2:** (a) The `3` `fec_uncorrected_blocks` produce `3` `rx_crc_errors` (dropped frames), forcing `ConnectX` RDMA sequence-gap retransmissions that burst extra traffic into the switch queue and push occupancy above `Kmin`, secondarily inflating `rx_ecn_marked_prio3: 1280`; fix by replacing `DAC-2m` cable `ABC123` on `swp17`; (b) **`leafB-swp17`** (hop `3`, `99.0%` occupancy, `tx_pfc: 9500` upstream with `rx_pfc: 0` from downstream) is the most downstream congested egress port at the head of the pause tree.
3. **Exercise 3:** (a) `Xid 92` is **Tier 1** (precursor high SBE rate `12 -> 31 -> 58 -> 94`), `Xid 45` is **Tier 1** (preemptive driver context cleanup caused by `Xid 92`, not an independent root cause), and `Xid 79` is **Tier 3** (`GPU has fallen off the bus`, immediate node drain); alerting on the accelerating `Xid 92` SBE slope drains the node before `Xid 79` crashes the job; (b) RMA **`GPU2`** (not `GPU3`), because `dcgmi nvlink -e` shows `184,213` CRC and `92,104` replay errors on `GPU2` `Link 2` (`Xid 74`) vs `0` errors on `GPU3` `Link 2` (`GPU3` is a healthy passive victim).
4. **Exercise 4:** (a) `2.3 GB/s` is an **`89.55%` (`~90%`) drop** relative to the `22.0 GB/s` `Gen4 x16` baseline (`2.3 / 22.0 = 10.45%`) and an **`80.83%` (`~80%`) drop** relative to the `12.0 GB/s` `Gen3 x16` baseline; (b) drain GPU workloads, run `echo 1 > /sys/bus/pci/devices/0000:08:00.0/remove && sleep 2 && echo 1 > /sys/bus/pci/rescan`, and verify `LnkSta: Speed 16GT/s, Width x16`, `bandwidthTest >= 20.0 GB/s` (`>= 17.6 GB/s` threshold), and `0` new `PCIE_REPLAY_COUNTER` increments.
