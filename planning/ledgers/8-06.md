# Claim Ledger: 8.6 Users, authentication and security in BCM

## BCM 11 Administrator Manual Claims
- **Users & Groups (§6.1, §6.2):** Stored in BCM's OpenLDAP on the head node. Built-in `cmsupport` user has no password and is used for diagnostics. Default `LowUserId` is `1000` (`500` on SLES), shell `/bin/bash`, home `/home/<name>`, shadow min `0`, max `999999`, warn `7`, expire `2038/1/1`. Committed users with empty passwords cannot log in until `set password` + `commit`. `remove -d` deletes the home directory.
- **Passwords & SSH (§2.3.1, §2.3.2):** `cm-change-passwd` updates head node root, software image root, node-installer root, and MySQL root (not LDAP root). SSH is passwordless from head to regular nodes, and requires a password for root from regular nodes to the head node.
- **Certificates, Profiles & Tokens (§2.3.3, §6.5):** `CMDaemon` authenticates X.509 certificates on TCP `8081`. Human profiles: `admin`, `readonly`, `portal`; nonuser profiles (`power`, `node`, `bootstrap`, `cmhealth`, `cmpam`, `litenode`, `monitoringpush`, `mqtt`, `prs`, `autonomous-hardware-recovery`, `autonomous-job-recovery`) must not be modified. `cmsh` certificate lookup order: `-i`/`-k` $\rightarrow$ `~/.cm/admin.{pem,key}` $\rightarrow$ `~/.cm/cert.{pem,key}`.
- **External LDAP, Keycloak & Audit (§6.3, §6.4, §6.5.4):** External LDAP uses `/etc/nslcd.conf` (RHEL 8) or `/etc/sssd/sssd.conf` (RHEL 9) + `/etc/openldap/ldap.conf`, port `636`, or OpenLDAP `syncrepl` (`DD:HH:MM:SS`, `rid=2`). Keycloak (`cm-setup-keycloak.py`, BCM `11.34+`) requires Ubuntu `24.04`/`26.04` on head node and free ports `9443` and `9999`. Audit directives: `CMDaemonAudit`, `CMDaemonAuditorFile`, `DisableAuditorForProfiles`.
