## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (GCP AI Landing Zone and Multi-NIC GPU VPC Networking):** `google_compute_network` (`mtu = 8896`), `google_compute_subnetwork` (`private_ip_google_access = true`, `pods` `/14` and `services` `/20`), `google_compute_router_nat`, and IAP firewall (`35.235.240.0/20`) provide a private landing zone, while `generate_multi_nic_gpu_subnets()` provisions dedicated GPU-rail VPCs (1 per GPU NIC) for GPUDirect-TCPX/RDMA.
2. **Exercise 2 (Provisioning GCP GPU VMs, Capacity Models, and Compact Placement):** GPU VMs require `scheduling { on_host_maintenance = "TERMINATE" }` and `enable_secure_boot = false` (unless DKMS modules are signed); `google_compute_resource_policy` (`collocation = "COLLOCATED"`) minimizes inter-node hop latency; and capacity spans On-Demand, `google_compute_reservation`, Dynamic Workload Scheduler (`DWS`), and `SPOT`.
3. **Exercise 3 (GKE Private Clusters, GPU Node Pools, Surge vs. Unavailable Upgrades, and Workload Identity):** Using `validate_gcp_gpu_node_pool()`, set `remove_default_node_pool = true`, `datapath_provider = "ADVANCED_DATAPATH"`, `auto_upgrade = false`, `max_surge = 0` + `max_unavailable = 1`, `nvidia.com/gpu:NO_SCHEDULE` taints, and `SPECIFIC_RESERVATION` affinity; Workload Identity binds `serviceAccount:<proj>.svc.id.goog[ns/ksa]` to a Google SA with `roles/storage.objectUser`.
4. **Exercise 4 (CMEK-Encrypted Checkpoint Storage and Spend Guardrails):** `google_kms_crypto_key` (`rotation_period = "7776000s"`) encrypts `google_storage_bucket` (`versioning`, `uniform_bucket_level_access`, `public_access_prevention = "enforced"`, `prevent_destroy = true`), and `google_billing_budget` alerts on 50% and 90% spend thresholds via Pub/Sub.
5. **Exercise 5 (Nebius AI Cloud `nebius_compute_v1_gpu_cluster` InfiniBand Fabrics vs. GCP):** `validate_nebius_gpu_fabric_membership()` verifies that all `nebius_compute_v1_instance` nodes (`platform = "gpu-h100-sxm"`, `preset = "8gpu-128vcpu-1600gb"`) join the same `nebius_compute_v1_gpu_cluster` InfiniBand fabric ID (`infiniband_fabric = "fabric-3"`), paired with shared filesystems and Managed K8s / Soperator Slurm.
6. **Exercise 6 (Provider-Agnostic Multi-Cloud GPU Pool Interface and Post-Apply Verification):** Expose a common `modules/gpu-pool` input/output contract backed by provider-specific GCP and Nebius submodules, and verify `nvidia-smi`, jumbo MTU (`ping -M do`), RDMA link state (`ibstat`), multi-node `all_reduce_perf` bandwidth, and `fio`/GCS storage throughput before scheduling jobs.
