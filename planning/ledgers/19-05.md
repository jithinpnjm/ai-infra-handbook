## 4. Contradictions found and how resolved

- Earlier draft: "-c 1 compares the reduced output". README: `-c` is the number of checking iterations, default 1. Corrected.
- Earlier draft: `-R` is "persistent buffer registration". README: 1 is local and 2 is symmetric registration. Corrected.
- Earlier draft: busbw 361.36 GB/s for 64 GPUs on 400G rails treated as 90 percent per rail by dividing by 8. One 50 GB/s NIC cannot give that under the simple reading, so the row is treated as arithmetic practice and replaced.
- Earlier draft: "NCCL_NET=IB so NCCL fails fast". The page only says it forces a network. Relabelled as expectation.
- Earlier draft: 64 percent of interruptions were GPU faults. Table 4-4 as printed does not sum to that figure with the categories I can name. Removed.
- Earlier draft cited 390 Gbps from Volume 07. The only source found is the NCCL diagnostics example median 391.5 Gbit/s. Reworded as an example.
- Row 71.05 became 71.04: unrounded algbw times 1.75.
