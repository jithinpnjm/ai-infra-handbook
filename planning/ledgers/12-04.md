## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) Wire frame is `64` B, Dst MAC `01:80:C2:00:00:01`, Src MAC `10:0e:7e:b7:a7:1b`, `EtherType 0x8808`, opcode `0x0101`, Class Enable Vector `0x0008` (`1 << 3`), and `16`-octet `Time` field; (b) `65,535 * 512 = 33,553,920` bit-times = `335.5392 µs` (`100G`), `167.7696 µs` (`200G`), `83.8848 µs` (`400G`), and `41.9424 µs` (`800G`), while an explicit `XON` frame carries `0` quanta (`0.0 µs`).
2. **Exercise 2:** (a) At `400 Gbps` (`50 B/ns`) with `18,064` B serialization (`2 * 9,000 + 64`), the `2 m` DAC (`620 ns` total delay) needs `31,000 + 18,064 = 49,064` B headroom, while the `500 m` fiber (`5,600 ns` total delay) needs `280,000 + 18,064 = 298,064` B (`+249,000` B delta); (b) in `mlnx_qos -i swp12`, headroom is `65,536 - 49,152 = 16,384` B (`25.0%`) and hysteresis is `49,152 - 32,768 = 16,384` B (`25.0%`); `XOFF = 65,536` B leaves `0` headroom (tail drops), and `XON = 49,152` B leaves `0` hysteresis (rapid pause/unpause oscillation).
3. **Exercise 3:** (a) `100 KB -> 0.0` (`GREEN_ZONE_FREE_FLOW`), `487.5 KB -> 0.25` (`YELLOW_ZONE_PROBABILISTIC_ECN`), `825 KB -> 0.50` (`YELLOW_ZONE_PROBABILISTIC_ECN`), and `1,600 KB -> 1.0` (`RED_ZONE_100PCT_ECN_MARKING`); (b) setting `K_max = 55,000` B above `XOFF = 49,152` B violates `K_max < XOFF`, causing hop-by-hop PFC pauses to fire before WRED ECN marking reaches `100%`.
4. **Exercise 4:** (a) At $\alpha = 1.0$, $R_c = 400 \cdot (1 - 0.5) = 200.0\text{ Gbps}$ ($R_t = 400.0\text{ Gbps}$, $\alpha = 1.0$); at $\alpha = 0.5$, $R_c = 300.0\text{ Gbps}$ ($R_t = 400.0\text{ Gbps}$, $\alpha = 0.53125$); (b) Fast Recovery (`step 1`) gives $R_t = 300.0, R_c = 250.0\text{ Gbps}$; Additive Increase (`step 6`) gives $R_t = 310.0, R_c = 280.0\text{ Gbps}$; Hyper-Additive Increase (`step 9`, $i = 2$) gives $R_t = 390.0, R_c = 335.0\text{ Gbps}$.
5. **Exercise 5:** (a) PFC Watchdog detects a storm at `150 ms >= 100 ms`, in `Drop` mode flushes queued packets, drops new packets for that queue, and discards incoming pause frames so `SpineA` never pauses `LeafA`/`LeafB` (whereas `Forward` mode ignores PFC and forwards packets), and restores lossless Ethernet after `250 ms >= 200 ms` quiet time; (b) `SFC` (`802.1Qdw`) trims the payload and reverses IP headers at the congested switch to signal the specific flow directly to the source/leaf, while `CSIG` (`draft-ravi-ippm-csig-01`) inserts an `L2.5` tag (`Signal Type`, `Signal Value`, `Locator Metadata` with `capacity`, `stage`, `device ID`, `link direction`) reflected by the receiver to guide sender rate and path selection.
6. **Exercise 6:** (a) `swp3` (`rx_pfc=41,823`, `tx_pfc=41,810`, `98%` occupancy) is a middle relay hop, while `swp7` (`tx_pfc=0`, `rx_ecn_marked=2,200`) is the downstream receiver-facing port where the fix belongs; (b) `412,880` marks + `409,500` CNPs (`99.18%`) at `98 Gbps` is a weak `RP` response or hard destination capacity bottleneck, whereas `100 -> 12 -> 95 -> 11 -> 96 Gbps` is synchronized sender rate oscillation; (c) `Lab 03` (`47,829` ECN marks, `412` PFC pauses, `89.2 + 87.1 = 176.3 Gbps`) shows healthy bounded contention, whereas `Lab 04` (`392 -> 156 Gbps`, `24` `RETRY_EXC_ERR`s) is a Layer 3 RoCE device/GID selection mismatch (`mlx5_1` vs `mlx5_0`).
