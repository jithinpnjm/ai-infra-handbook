## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (INI vs. YAML Inventories, Host Aliases `127.0.0.1:2222` Collision, Behavioral Connection Variables, and Ranges, `AUR` Ch. 4):** Writing `127.0.0.1:2222` and `127.0.0.1:2200` without aliases overwrites the single `127.0.0.1` host key in Ansible (requiring distinct aliases `vagrant1`, `vagrant2` with `ansible_host=127.0.0.1`); `expand_inventory_range()` expands zero-padded numeric (`gpu[001:032]`) and alphabetic (`web-[a:t]`) ranges; and `ansible_shell_type` adapts command wrappers for `csh`/`fish` while implicit `localhost` uses `ansible_connection=local` outside `all`.
2. **Exercise 2 (Host Patterns, Subscripts `gpu[0:2]`, `@retry.txt`, and Play Execution Order):** `--limit` intersects with the play's `hosts:` pattern, `gpu:&rack_r01` selects the intersection, `gpu:!gpu_a100` excludes a subgroup, `gpu[0:2]` slices the first three hosts, `@failed_hosts.txt` reads targets from a file, and `order: shuffle` randomizes execution order across hosts.
3. **Exercise 3 (`group_vars/` and `host_vars/` Layouts, Variable Precedence, and Dictionary Replacement vs. `combine`, `AUR` Ch. 4):** Using `resolve_variable_precedence()`, `group_vars/<group>/` can be a directory merging `main.yml` and `vault.yml`; role `defaults/` has the lowest precedence while role `vars/` ranks above all inventory `group_vars/` and `host_vars/` (and `-e` always wins); and dictionaries replace rather than merge across layers unless `combine(recursive=True)` is used.
4. **Exercise 4 (Runtime Grouping `group_by` and `add_host`, and `meta: refresh_inventory`, `AUR` Ch. 4):** `group_by` partitions existing hosts into in-memory groups based on gathered facts (`gpu_model`, `distribution`), `add_host` injects newly provisioned VMs into the in-memory inventory for subsequent plays, and `meta: refresh_inventory` re-queries dynamic inventory sources mid-run.
5. **Exercise 5 (Dynamic Inventory Plugins and Custom Scripts `vagrant.py` / `slurm_inventory.py`, `AUR` Ch. 4):** Cloud/NetBox inventory plugins use `filters`, `keyed_groups`, `groups`, `compose`, and `cache`, while `parse_vagrant_machine_readable_inventory()` models `--list` returning `"_meta": {"hostvars": {...}}` so Ansible skips thousands of per-host `--host <name>` subprocess invocations.
6. **Exercise 6 (Four-Axis GPU Cluster Inventory Design and CI Inventory Validation):** Organize groups along four orthogonal axes (Role, Hardware trait, Location/topology, Lifecycle), address BMCs via `bmc_address` + `delegate_to: localhost` (or a `[bmc]` group with `ansible_connection: local`), and run a pre-flight `assert` play in CI verifying that `ansible_host`, `rack`, `bmc_address`, and `gpu_count` are defined on every GPU node.
