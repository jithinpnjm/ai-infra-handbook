## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** Rebooting `500` nodes into a new kernel without GPU Operator coordination caused the new kernel to reject the old pre-compiled `nvidia.ko` driver on `400` nodes (`80%`); prevent this via the `6` Safe Eviction Steps (`Cordon -> Drain -> Verify Idle -> Upgrade -> Validate -> Uncordon`) and `3` Canary Stages (`1` Vanguard node `24h` -> `1` Rack -> Global `>= 90%` capacity online).
2. **Exercise 2:** The FinOps Reaper terminates pods with `DCGM_FI_PROF_SM_ACTIVE < 5%` for `>= 4 hours`; refute the `$5M` request by showing `98%` K8s allocation hides `12%` `SM_ACTIVE` and partitioning staging GPUs into `7 × 1g.10gb` MIG slices; cut the `$500K/mo` AWS bill in half using `1-Year` RIs (`40–50%` off) for baseline inference, Spot (`70%` off with `15-min` S3 checkpoints + `2-min` warning handler) for batch training, and `10:1` time-slicing (`80` devs on `1` `8`-GPU node) for dev/staging.
3. **Exercise 3:** (a) `2:00 PM` `40%` slowdown is `85°C` `HW_SLOWDOWN` (`1,500 -> 500 MHz`) in `DCGM_FI_DEV_CLOCK_THROTTLE_REASONS` -> fix rack HVAC/fans; (b) `100%` util with `5%` (`< 10%`) `TENSOR_ACTIVE` is unoptimized FP32 / tiny kernels -> enable AMP (`BF16`/`FP16`) & operator fusion; (c) saturated `DCGM_FI_PROF_PCIE_RX_BYTES` is unpinned host-to-device copy -> enable `pin_memory=True` / GDS; (d) `200 ms` `p99` Triton breach is fixed by raising `Instance Group` count in `config.pbtxt` (if `nv_inference_queue_duration_us` spikes) and deploying TensorRT-LLM `PagedAttention` + `INT8` (if `DCGM_FI_DEV_MEM_COPY_UTIL` is `~100%`).
4. **Exercise 4:** The `3` layers are `Layer 1 Optical` (`perfquery` `SymbolErrorCounter`/`LinkDownedCounter`, switch FEC/CRC), `Layer 2 PFC Storms` (`ethtool -S` `rx_prio<N>_pause`), and `Layer 3 Routing` (`OpenSM` heavy sweeps/flapping ports); isolate `Node 84` via `/sys/class/infiniband/<dev>/ports/<port>/hw_counters/{packet_seq_err,out_of_sequence,implied_nak_seq_err,local_ack_timeout_err}`.
5. **Exercise 5:** Isolate **Compute** via `MIG` (`7 × 1g.10gb`) + Node Taints, **Network** via Default-Deny `NetworkPolicies` + `SR-IOV` VFs for RDMA, and **Storage** via `Weka`/`Lustre` IOPS/Bandwidth QoS + subdirectory `chroot`; `IRSA` binds a prefix-scoped IAM role via OIDC to `serviceAccountName: medical-training-sa` instead of the EC2 node; and the `4` Thanos tiers are `Scraping Agents -> Thanos Receive -> S3 Object Storage -> Thanos Querier + 5m Recording Rules`.
6. **Exercise 6:** `10 PB` (`80 × 10^15` bits) at `10 Gbps` takes `8,000,000 s ≈ 92 days`; **S3 Object Lock (`WORM` Compliance Mode)** prevents even `root` from overwriting/deleting `50 TB` checkpoints for `30 days` (anti-ransomware), while **hourly Copy-on-Write (`CoW`) storage snapshots** revert a `1 PB` corrupted directory in `1` API call (`<= 60 min` loss); the `XID 48` runbook cordons `node-worker-42`, checks `dmesg -T | grep NVRM`, drains and resets/reboots for row remapping, and opens a Hardware RMA Jira if `XID 48` recurs.
