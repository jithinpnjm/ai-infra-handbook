## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The Kubernetes IP-per-Pod Network Model and Building a Pod Network by Hand, `NK` Ch. 3 & `PK` Ch. 5):** Every Pod gets a unique IP and communicates with all Pods and local node agents without NAT; `ip netns add`, `ip link add ... type veth`, `ip link add cni0 type bridge`, default route via `cni0`, `ip_forward=1`, and `POSTROUTING MASQUERADE` reproduce single-node bridge CNI networking.
2. **Exercise 2 (The CNI Specification: `.conflist` Chaining, `ADD`/`DEL`/`CHECK`/`VERSION`, and IPAM Plugins, `NK` Ch. 4):** The runtime executes `/opt/cni/bin/*` with `CNI_COMMAND`, `CNI_CONTAINERID`, `CNI_NETNS`, `CNI_IFNAME`, and the `.conflist` JSON on `stdin`, chaining `calico`/`bridge` -> `portmap` -> `bandwidth` via `prevResult`; `CNIHostLocalIPAM` models per-node and cluster-wide (`whereabouts`) IP allocation, exclusions, and `DEL` cleanup.
3. **Exercise 3 (Comparing CNI Implementation Families and Subnet Sizing, `NK` Ch. 6):** `compute_subnet_prefix_for_nodes()` computes $S = 32 - \lceil \log_2(N + 4) \rceil$ (`/24` for 250 nodes, `/23` for 500 nodes); Overlay CNIs encapsulate over any L3 underlay, Routed CNIs distribute `/24` or `/32` routes via BGP, and VPC-Native CNIs assign cloud ENI/alias IPs directly to Pods.
4. **Exercise 4 (MTU Math and Diagnosing Blackholed Jumbo/TLS Packets, `PK` Ch. 5):** `compute_pod_mtu_and_df_ping()` subtracts encapsulation overhead (`20`B IPIP, `50`B VXLAN/Geneve, `60`B WireGuard) from the underlay MTU and checks `icmp_payload + 28 <= pod_mtu` (`1422`B max payload for `1450`B VXLAN MTU).
5. **Exercise 5 (Multi-Network Pods for GPU Collectives: `Multus`, `macvlan`, `SR-IOV`, `RDMA`, and Rail Alignment):** `plan_multus_pod_interfaces()` attaches `eth0` via the primary CNI and `net1..netN` in deterministic `k8s.v1.cni.cncf.io/networks` order so each secondary RDMA interface (`macvlan` + RDMA shared device plugin or `SR-IOV` VF) aligns 1:1 with its PCIe-peer GPU rail.
6. **Exercise 6 (Node-Level Pod Network Inspection):** Use `crictl inspectp` / `lsns -t net`, `nsenter --net=...`, `/sys/class/net/eth0/iflink` <-> host `ifindex`, `ip route`, `bridge fdb`, `tcpdump`, `calicoctl node status`, and `cilium status` / `hubble observe` to isolate CNI, MTU, and routing failures.
