## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Application vs. Infrastructure CI/CD, Change Management Theater, and `WISB == WIRI`, `NPA` Ch. 13):** Infrastructure CI/CD mutates stateful, high-blast-radius systems with irreversible failure modes and high-privilege credentials; placing humans *above* an automated 5-stage pipeline (peer review, `validate_yaml.py`/`tox` build automation, 3-layer NAPALM/Batfish/ThousandEyes validation, virtual staging topologies, and Canary/Blue-Green rollouts with `<bgp operation="replace">`) replaces manual CAB theater and guarantees `WISB == WIRI`.
2. **Exercise 2 (Pull Requests as Control Plane `plan -out=tfplan`, Atlantis Locking, and Self-Hosted CI/CD, `AUR` Ch. 22):** Saving `terraform plan -out=tfplan` and applying that exact file prevents unreviewed changes between plan and apply while Atlantis locks workspaces across concurrent PRs; `AUR` Chapter 22 provisions `Nexus 3`, `Gitea`, `SonarQube`, and `Jenkins` configured via `JCasC` (`jenkins.yaml`), `Job DSL` (`jobs.groovy.j2`), Molecule `Jenkinsfile` stages, and `ansibleTower` (`jobTemplate: '1234'`).
3. **Exercise 3 (Passwordless OIDC Federation, Separate Plan/Apply Roles, and State Secret Hygiene):** Using `authorize_oidc_token_claims()`, short-lived OIDC JWTs exchange for temporary cloud credentials where the read-only `plan` role allows PRs from `org/infra` while the write `apply` role requires `ref == "refs/heads/main"` and a protected `environment` (`staging`/`prod`), and `terraform.tfstate` is encrypted and access-controlled because data-source/resource secrets land in state.
4. **Exercise 4 (Policy as Code `OPA`/`Rego`/`Conftest` and Break-Glass Overrides):** Using `evaluate_terraform_plan_policies()`, `terraform show -json tfplan` is checked against Rego `deny` rules blocking creation of `>16` restricted `p5.48xlarge`/`p4d.24xlarge` instances unless `Override-Capacity` is present and blocking deletion of resources tagged `Mission-Critical == "true"`.
5. **Exercise 5 (Golden Image Pipelines `Packer` + `Ansible` and Staged Fleet Rollouts):** Packer builds, hardens, scans, and boot-tests (`nvidia-smi`, DCGM, NCCL) an immutable GPU image ID + SBOM; `simulate_staged_fleet_rollout()` drains nodes, validates a 1–2 node canary, and rolls out in batches (`serial: 5`, `max_fail_percentage: 10`), halting immediately on canary or batch threshold failure.
6. **Exercise 6 (Scheduled Drift Detection `-detailed-exitcode`, Auto-Heal vs. Alert-Only, and Pipeline Security):** Using `classify_terraform_detailed_exitcode()`, exit code `2` signals drift (auto-healed for stateless Kubernetes/config objects via Argo CD `selfHeal`, alerted-only for stateful resources); ephemeral runners, `cancel-in-progress: false`, action SHA pinning, `CODEOWNERS` on `.github/`, and avoiding `pull_request_target` secure the pipeline.
