## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The Four HCL Looping Constructs and `count` vs. `for_each`, `TUR` Ch. 5):** HCL provides `count` (index-based resources/modules), `for_each` (key-based resources/modules/`dynamic` blocks), `for` expressions (list/map value transformations), and `%{ for ... }` string directives; `simulate_count_vs_for_each_removal()` shows removing `"trinity"` from `["neo", "trinity", "morpheus"]` shifts `"morpheus"` under `count` (`[2] -> [1]`) whereas `for_each` destroys only `["trinity"]`, and `moved` blocks migrate `[0..2]` to `["key"]` safely.
2. **Exercise 2 (Reshaping Data with `for` Expressions, `...` Grouping, `setproduct`, and `merge([for ...])`):** `flatten_team_namespaces()` flattens a nested `(team, namespaces)` hierarchy into `"team/ns"` keys via `merge([for ... : { for ... }]...)`, while `p.region => p.name...` groups multiple values sharing a key into a list.
3. **Exercise 3 (`dynamic` Blocks `ingress`/`tag` vs. Provider `default_tags`, `TUR` Ch. 5):** `dynamic` blocks generate repeated nested stanzas inside a resource (`ingress`, `tag`, `guest_accelerator`, `taint`), while `provider "aws" { default_tags { tags = ... } }` applies baseline tags to all AWS resources automatically without repeating `tag` blocks.
4. **Exercise 4 (Conditionals in HCL and `one(concat(...))`, `TUR` Ch. 5):** Use `count = var.enabled ? 1 : 0` for boolean toggles, filtered `for_each` maps for per-key conditionals, and `evaluate_one_concat_conditional()` (`one(concat(full[*].policy_arn, ro[*].policy_arn))`) to extract outputs from mutually exclusive `count` resources without `[0]` index-out-of-range errors.
5. **Exercise 5 (The `lifecycle` Block and Zero-Downtime Rolling Patterns, `TUR` Ch. 5):** `create_before_destroy`, `prevent_destroy`, `ignore_changes`, `replace_triggered_by`, and `precondition`/`postcondition` govern resource lifecycles; for fleet updates, native ASG `instance_refresh` (`strategy = "Rolling"`) or GKE `update_policy` beats replacing the entire ASG via `create_before_destroy`.
6. **Exercise 6 (Diagnosing Terraform Sharp Edges):** Derive `for_each` keys from static inputs (never `(known after apply)` attributes), break security-group cycles with standalone `aws_vpc_security_group_ingress_rule` resources, handle IAM eventual consistency with `depends_on` / `time_sleep`, avoid `depends_on` on `module` blocks, and replace `timestamp()`/`uuid()` with `time_static`/`random_uuid`.
