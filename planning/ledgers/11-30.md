## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** The `4` layers are `1. Host Driver` (`nvidia-smi`), `2. Container GPU Passthrough` (`docker run --rm --gpus all ... nvidia-smi`), `3. Persistent Block Storage` (`/data/mlops` mounted by `UUID=` in `/etc/fstab`), and `4. UFW Firewall` (`ufw allow OpenSSH` before `ufw enable`); fix `capabilities: [[gpu]]` via `sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker`; check `blkid` is empty to avoid overwriting an existing filesystem; and test from a **new** SSH session and across `sudo reboot` to prevent self-lockout and prove boot persistence.
2. **Exercise 2:** `gpu-node-07` (`8/8`) has `8` schedulable GPUs whereas `gpu-node-11` (`8/0`) has lost device-plugin/driver allocatable state; match host `Bus-Id` (`00000000:1B:00.0`) and `UUID` (`GPU-3a1e9f2b-...`) inside `kubectl logs gpu-node-validation` (`GPU_NODE_VALIDATED`); requesting `nvidia.com/gpu: 99` emits `Warning FailedScheduling: 0/3 nodes are available: 1 Insufficient nvidia.com/gpu`.
3. **Exercise 3:** `1. Helm -> Operator` (`helm status` deployed), `2. Operator -> ClusterPolicy/Operands` (`clusterpolicy ready`, DaemonSets `DESIRED 3 / READY 3 / AVAILABLE 3`), `3. Plugin -> Node Allocatable` (`ALLOCATABLE: 4` + GFD labels), and `4. Toolkit -> Workload` (`GPU_OPERATOR_VALIDATED`); `helm status: deployed` only proves manifests were submitted to `kube-apiserver`, not that `nvidia.ko` loaded on the nodes.
4. **Exercise 4:** The `4` VPA modes are `Off`, `Auto`, `Recreate`, and `Initial`; HPA and VPA conflict when VPA (`Auto`) resizes CPU/memory `requests` and alters HPA's `averageUtilization` denominator; `my-llama-deployment-scaler` scales out when `sum(rate(http_requests_total[1m])) > 10` or `avg(DCGM_FI_DEV_GPU_UTIL{pod=~"my-llama-.*"}[30s]) > 70`.
5. **Exercise 5:** At `14:34:03Z` (`33.662142ms`), Karpenter detects `my-llama-job-plgb5` Pending (`2 Insufficient nvidia.com/gpu`), creates `NodeClaim` `eks-gpu-np-gkx7t` (`g6`, `AL2023`), brings `ip-10-0-32-176` (`15890m` CPU, `60398040Ki` RAM, `nvidia.com/gpu: 1`, `234` pods) Ready by `14:36:01Z`, and after job completion taints the empty node `karpenter.sh/disrupted:NoSchedule` at `14:50:18Z` and deletes it at `14:54:03Z`.
6. **Exercise 6:** `aws-load-balancer-nlb-target-type: ip` routes NLB traffic straight to Pod IPs (skipping the `NodePort` hop); `kube-proxy` `IPVS` uses an `O(1)` in-memory hash table; `NodeLocal DNSCache` caches DNS per node without `iptables` DNAT/conntrack; `Cluster` placement groups (`--strategy cluster` / `COMPACT`) pack GPU nodes closely for RDMA (`EFA`/`GPUDirect`/`InfiniBand`); and `NetworkPolicies` restrict `rag-app`/`my-llama-finetuned` to `TCP/80` from `chatbot-ui` and `qdrant` to `TCP/6333` from `rag-app`.
