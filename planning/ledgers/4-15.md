## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Choosing Extension Points and Writing an Idempotent Python Module, `AUR` Ch. 19):** Use a Role to compose existing modules, a Module (running on the target) to wrap CLIs/APIs idempotently with `AnsibleModule(..., supports_check_mode=True)`, `module.run_command([...])`, `add_file_common_args=True`, and `exit_json`/`fail_json`, and a Plugin (running on the controller) for Jinja filters, lookups, or inventory; non-Python modules use `# WANT_JSON` and direct interpreter shebangs (`#!/bin/bash` rather than `#!/usr/bin/env bash`).
2. **Exercise 2 (Writing Filter, Test, Lookup, Inventory, and Action Plugins):** `slurm_hostlist()` and `slurm_expand_hostlist()` fold and expand Slurm host ranges (`gpu[001-003,005]`) in `FilterModule`; `LookupBase` returns a `list` on the controller; `BaseInventoryPlugin` (`Constructable`, `Cacheable`) parses dynamic inventories; and `ActionBase` pre-processes arguments/files on the controller before invoking target modules.
3. **Exercise 3 (Building and Running Execution Environments `ansible-builder` & `ansible-navigator`, `AUR` Ch. 23):** `execution-environment.yml` (v3) combines `ansible-core`, `requirements.yml` collections, `requirements.txt` pip libraries, and `bindep.txt` system packages into an OCI container image built with `ansible-builder build` and executed locally or in CI/AAP with `ansible-navigator run --eei <image> -m stdout`.
4. **Exercise 4 (AWX / AAP 2 Architecture, Core Objects, RBAC, and DR `SECRET_KEY`, `AUR` Ch. 23):** AWX/AAP separates the Web/API Controller + PostgreSQL from Automation Mesh Execution Nodes running EE containers; Credentials encrypt SSH/Vault secrets so operators can launch Job/Workflow Templates and Surveys under RBAC without seeing secrets; and DR requires backing up both PostgreSQL and `/etc/tower/SECRET_KEY`.
5. **Exercise 5 (Managing AWX/AAP as Code `awx.awx` and Event-Driven Ansible `EDA` Rulebooks, `AUR` Ch. 23):** Configure organizations, inventories, credentials, projects, and job templates declaratively via `awx.awx` modules and trigger launches from CI via `/api/controller/v2/job_templates/<id>/launch/`; EDA rulebooks match Alertmanager/Kafka events (`GPUXid79`) to launch remediation templates guarded by deduplication, cooldowns, and concurrency limits.
6. **Exercise 6 (Ansible Architectural Best Practices and the `CALMS` Framework, `AUR` Ch. 24):** Combine high modularity and composability (Terraform for provisioning + Ansible for configuration), push complex logic from YAML into tested Python modules, decouple inventories from projects and roles from collections, make releases a "one-bit decision" over pre-built artifacts, and measure DevOps maturity across Culture, Automation, Lean, Measurement, and Sharing (`CALMS`).
