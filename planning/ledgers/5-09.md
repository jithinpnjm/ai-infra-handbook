## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Designing a Production `KubeletConfiguration` for Dual-Socket 8-GPU Nodes):** Configure `cgroupDriver: systemd`, `protectKernelDefaults: true`, `seccompDefault: true`, `serializeImagePulls: false` (`maxParallelImagePulls: 3`), `reservedSystemCPUs: "0-3"`, `kubeReserved` / `systemReserved`, and `evictionSoft` (`4Gi`/`2m`) + `evictionHard` (`2Gi`) so user workloads never starve `kubelet`/`containerd` or trigger surprise kernel OOM kills.
2. **Exercise 2 (The Cgroup v2 Hierarchy `kubepods.slice`, QoS Placement, and `Node Allocatable`):** `Guaranteed` pods sit directly under `kubepods.slice`, `Burstable` under `kubepods-burstable.slice`, and `BestEffort` under `kubepods-besteffort.slice`; `kubepods.slice` enforces `Allocatable = Capacity - kubeReserved - systemReserved - evictionHard`.
3. **Exercise 3 (CPU Manager `static` + `full-pcpus-only`, Memory Manager `Static`, and Topology Manager):** `evaluate_cpu_manager_static()` grants exclusive physical cores to `Guaranteed` integer-CPU pods (requiring even vCPU counts under `full-pcpus-only: "true"`), while `evaluate_topology_manager()` enforces `single-numa-node` alignment on 1–4 GPU inference pools and `best-effort`/`restricted` on 8-GPU training pools.
4. **Exercise 4 (Device Manager, Pod Resources API, and Dynamic Resource Allocation `DRA`):** Device plugins register over gRPC (`ListAndWatch`, `GetPreferredAllocation`, `Allocate`), `kubelet` checkpoints allocations in `kubelet_internal_checkpoint` and exposes them on `/var/lib/kubelet/pod-resources/kubelet.sock` for `dcgm-exporter`, and `DRA` (`ResourceClaim`, `ResourceSlice`) enables structured topology-aware device claims.
5. **Exercise 5 (Node-Pressure Eviction Signals, Victim Ranking, and the Three Kill Mechanisms):** `rank_memory_eviction_victims()` evicts pods exceeding their memory request (`BestEffort` and over-request `Burstable`) ordered by lowest priority and largest byte excess before touching in-request or `Guaranteed` pods; unlike API-initiated eviction (`kubectl drain`), node-pressure eviction does not respect `PodDisruptionBudget`s.
6. **Exercise 6 (Graceful Node Shutdown, Static Pods, and Kubelet API Security):** `shutdownGracePeriod` uses a systemd inhibitor lock to terminate regular pods before critical pods on reboot; Static Pods run from `/etc/kubernetes/manifests` with read-only mirror pods in `kube-apiserver`; and `:10250` must disable anonymous/10255 access and restrict `nodes/proxy` RBAC while `NodeRestriction` confines each `kubelet` to its own `Node`/`Pod` objects.
