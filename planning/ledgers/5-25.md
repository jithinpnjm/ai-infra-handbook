## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The Layered Diagnostic Method and `kubectl` Power Diagnostics, `KUR` Ch. 4):** Capture volatile evidence (`logs --previous`, `py-spy`, `dmesg`, `nvidia-bug-report.sh`) before restarting; use `kubectl debug` with `--target` (ephemeral container in live Pod), `--copy-to` (clone crashing Pod with overridden entrypoint), or `node/<n>` (host `/host` chroot).
2. **Exercise 2 (Container Runtime and Namespace Inspection from the Node):** Map Pod/Container to host PID via `crictl inspect <id> | jq '.info.pid'`, run host binaries inside the Pod's network namespace via `sudo nsenter -t $PID -n tcpdump/ss/ip` (avoiding `-m`/`-a` on untrusted containers), and inspect `/proc/$PID/stack` and `/sys/fs/cgroup/.../memory.events`.
3. **Exercise 3 (4-Hop Pod Network Bisection and Packet Capture):** `diagnose_pod_connectivity_bisection()` tests (1) Same-Node PodIP, (2) Cross-Node PodIP, (3) Service ClusterIP, and (4) Service DNS name in sequence to isolate failures to Layer 1 (App/local veth), Layer 2 (Cross-node CNI/underlay/MTU), Layer 3 (`EndpointSlice`/`kube-proxy`/`conntrack`), or Layer 4 (CoreDNS/port 53).
4. **Exercise 4 (Exit Code Triage, `CONSTRAINT_MEMCG` vs. `CONSTRAINT_NONE`, and Hung `Terminating` Pods):** `classify_container_exit_code()` maps `137` (`128+9` `SIGKILL`/OOM including `/dev/shm` tmpfs), `139` (`128+11` `SIGSEGV`), `143` (`128+15` `SIGTERM`), `126`, and `127`; `CONSTRAINT_MEMCG` indicates container cgroup limit OOM whereas `CONSTRAINT_NONE` indicates host RAM exhaustion; and `D`-state processes (`ps -eo pid,stat,wchan`) block `SIGKILL` on hung NFS/Lustre mounts.
5. **Exercise 5 (GPU, PCIe, NVLink, and Distributed `NCCL` Hang Playbooks):** `triage_gpu_node_symptoms()` flags `Xid 79` (GPU fallen off bus), PCIe link downtraining (`LnkSta` width `< x16`), and NCCL spin-waits (`>90%` GPU util with `<5%` Tensor Core activity), while `py-spy dump`, `gdb -p $PID -batch -ex 'thread apply all bt'`, and `TORCH_NCCL_TRACE_BUFFER_SIZE` isolate hung ranks.
6. **Exercise 6 (Incident Evidence Preservation, Blameless Post-Mortems, and Game-Day Chaos Drills):** Preserve `nvidia-bug-report.sh`, `kubectl cluster-info dump`, `dmesg -T`, and pcaps before remediation, conduct blameless post-mortems focused on systemic `Prevent`/`Detect`/`Mitigate` automation, and validate playbooks via Game-Day fault injection.
