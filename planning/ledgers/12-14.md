## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) `192.168.1.20 -> 192.168.2.10, Proto 17, UDP 1024 -> 4791` packs to `C0A80114C0A8020A11040012B7` with `CRC32 = 0x8BDA7C2D` (`2,346,351,661`), yielding `mod 5 = 1` and `mod 8 = 5` (while `10 mod 5 = 0` and `11 mod 5 = 1`); (b) in the `8`-bucket resilient table `(0, 1, 2, 3, 4, 0, 1, 2)`, `hash_key = 10` maps to `Bucket 2 -> interface_2`, failing `interface_2` remaps only `buckets (2, 7)` (`25%` churn vs `75%` raw modulo churn), and `Flows (50, 100, 50, 100 Gbps)` on `2 × 200G` links load `(100G = 50%, 200G = 100%)` under `SLB` vs `(150G = 75%, 150G = 75%)` under `DLB`.
2. **Exercise 2:** (a) `DLB` maps local port load and queue depth to quality bands `0..7`, reassigns flowlets (`SpineB -> SpineA`) when pauses exceed the inactivity timer, reactively rebalances (`SpineA -> SpineC`) on link degradation, and remains blind to downstream `Link X` (`SpineA -> LeafD`) collisions; (b) `Tomahawk 5` `GLB` combines `draft-wang-idr-next-next-hop-nodes` (`Characteristic Code = 2`, `32-bit` Next-hop and Next-next-hop BGP IDs, simple 3-stage vs compound 5-stage profiles) with `20 ms` `PFE` heartbeats to steer via `SpineB -> Link Y`, while `sDLB` uses `TCAM ACLs` on `UDP 4791` `BTH` RDMA `Write` opcodes (`0x06..0x0B`) so `3 × 1,500 B` datagrams (`A, B, C`) arriving out of order (`B` at `T1`, `C` at `T2`, `A` at `T3` at `192.168.1.1`) are reassembled in hardware on `ConnectX-6/7` and `BlueField` NICs.
3. **Exercise 3:** (a) `spine1` (`0c:59:9c:f1:00:32`, `fe80::e59:9cff:fef1:32`, `AS 65001`, ID `172.16.7.101`) and `leaf1` (`0c:59:9c:22:5d:d7`, `fe80::e59:9cff:fe22:5dd7`) exchange ICMPv6 `NS`/`NA`/`RS`/`RA`, open `TCP 52659 -> 179`, negotiate `Frame 22` (`189 B` / `1,512 b` `OPEN`, `Len 81`, `Hold 90 s`, `Opt Params 52`, `Capability Code 5` `Len 6` with `AFI=1, SAFI=1, NH_AFI=2`), and advertise `172.16.7.181/32` in `Frame 28` (`358 B` / `2,864 b` `UPDATE`, `Len 82`, `Path Attr 46`, `MP_REACH_NLRI` `Type 14` `Len 42`); (b) shared spine `ASN 65001` rejects the valley trombone `leaf1 (65101) -> spine1 -> leaf2 (65102) -> spine2 -> leaf3 (65103)` permitted by distinct spine ASNs `65001..65004`, while `ADD-PATH` advertises both `NH1` (`border-leaf1 65501`) and `NH2` (`border-leaf2 65502`) for `10.10.108.0/24` from `spine2` (`65001`) to `leaf2` (`65102`).
4. **Exercise 4:** (a) `spine1..4` (`400G, 800G, 100G, 400G = 1,700G`) use BGP Link Bandwidth Extended Community to program `WCMP` weights `20%/45%/15%/20%` (`13, 28, 10, 13` of `64` buckets, plus dynamic `WPS` in 5-stage Clos), and a spine withdraws `10.10.101.0/24` when active downlink peers drop from `4` to `3`; (b) `BGP DPF` (`draft-wang-idr-dpf`) prunes uncolored `10.10.1.4/32` from `leaf4` into active `black` (`spine1`) and backup `gray` (`spine2`) on `leaf1`, allocates `3 × 400G = 1.2 Tbps`/leaf on `black` for `128 × GPU-id 0` in `RUD`, and maps traffic via `FBF`, on-box probe agents, central controller (`CPCE`), or `EVPN-VXLAN` `MAC-VRF`/`RT5`.
5. **Exercise 5:** (a) `RIFT` (`RFC 9692`, `>= 1,000` switches) combines northbound link-state flooding with southbound distance-vector default routes, UDP `"hello"` + `IPv6 ND`, automatic disaggregation on failure, and `K-store` global link metadata across canonical (`7 × 8`) and **DragonFly Sparse** (`Group A/B/C` Leaf-Spine Clos interconnected at `T2` `ToF` spines `SA1/2, SB1/2, SC1/2`) topologies; (b) `IS-IS` (`2,500` switches) elects a single spine (`spine2`) for prefix flooding across `32`/`64` spines (`draft-white-lsr-distoptflood`) and uses `RFC 9350` (`FAD`) + `RFC 9502` (`IPv4 Algorithm Prefix Reachability TLV` with `MTID`) to isolate `Flex Algo 128` (`spine1/2` Storage), `129` (`spine3/4` Inference), and `130` (`spine5/6` Training) as summarized in `Table 8-1`.
