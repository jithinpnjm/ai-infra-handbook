## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Cluster Network Planning and Linux Node Preparation):** `validate_node_preflight_and_cidrs()` verifies that `node_cidr` (`10.0.0.0/24`), `podSubnet` (`10.244.0.0/16`), and `serviceSubnet` (`10.96.0.0/12`) do not overlap, CNI pool matches `podSubnet`, swap is disabled (`swapoff -a`), `overlay`/`br_netfilter` and bridge/IP-forwarding sysctls are enabled, and `kubelet` + `containerd` both use the `systemd` cgroup driver.
2. **Exercise 2 (Inside `kubeadm init`: The 11 Phases and Artifacts):** `KUBEADM_INIT_PHASES` runs `preflight -> certs (/etc/kubernetes/pki) -> kubeconfig (/etc/kubernetes/*.conf) -> kubelet-start -> control-plane (/etc/kubernetes/manifests) -> etcd -> upload-config -> upload-certs -> mark-control-plane -> bootstrap-token -> addon (CoreDNS + kube-proxy)`.
3. **Exercise 3 (Installing the CNI and Secure Worker TLS Bootstrapping `kubeadm join`):** Nodes stay `NotReady` (`cni config uninitialized`) and `coredns` stays `Pending` until Calico/Cilium populates `/etc/cni/net.d`; `verify_kubeadm_join_credentials()` checks `--token` (`[a-z0-9]{6}.[a-z0-9]{16}`) and `--discovery-token-ca-cert-hash sha256:<hex>` before TLS CSR bootstrapping writes `/etc/kubernetes/kubelet.conf`.
4. **Exercise 4 (High-Availability Control Plane `kube-vip`, `--control-plane`, `--upload-certs`):** `kube-vip` provides a leader-elected ARP/BGP VIP (`10.0.0.100`) as a static pod on `cp1..3`, while `kubeadm init --upload-certs` stores encrypted PKI keys for 2 hours so `cp2` and `cp3` can join via `kubeadm join --control-plane --certificate-key <key>`.
5. **Exercise 5 (Adding a Bare-Metal GPU Worker Node and Everyday `kubectl` Power Workflows, `KUR` Ch. 4):** Install the host NVIDIA driver + `nvidia-ctk runtime configure --runtime=containerd`, join the node, taint `nvidia.com/gpu=present:NoSchedule`, and deploy `nvidia-device-plugin`; use `kubectl config set-context`/`use-context`, `kubectl apply view-last-applied`/`edit-last-applied`/`set-last-applied`, `kubectl attach`, and `kubectl completion bash`.
6. **Exercise 6 (Comparing Deployment Models `PK` Ch. 1–2 and Troubleshooting `kubeadm`):** Balance Managed Services, Prebuilt Installers (`Kubespray`, `RKE2`, `Cluster API`, `BCM`), and `kubeadm` + Packer/Ansible; fix `kubelet` crash-loops via `journalctl -u kubelet`, fix Ubuntu `127.0.0.53` CoreDNS loops via `resolvConf: /run/systemd/resolve/resolv.conf`, and wipe `/etc/cni/net.d` + `iptables` after `kubeadm reset -f`.
