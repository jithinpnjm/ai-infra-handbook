## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Automated Node Health Gating with Stub Binaries):** `node_health_lab.py` runs `node_health.sh` against mock binaries (`7` GPUs, `Xid 79`, `14462 MB` `/tmp`, `/scratch` unmounted, `1` IB port down) and verifies that `node_health.sh` concatenates all failures into a 200-char `Reason` string and exits `1`.
2. **Exercise 2 (Designing `Prolog` vs `Epilog` vs `HealthCheckProgram` Boundaries):** Create `/tmp/slurm-$SLURM_JOB_ID` in `Prolog` (fast pre-job setup), clean `/tmp/slurm-$SLURM_JOB_ID` and scan post-job `dmesg` `Xid`s in `Epilog` (post-job cleanup/gating), check `/scratch` mounts every 5 minutes in `HealthCheckProgram` (`ANY,CYCLE`), and run 2-minute DCGM level-2 diagnostics only between jobs or on idle nodes so job start times are not penalized.
3. **Exercise 3 (Decoding `Xid` Hardware Errors and PCIe/NVLink Degradation):** `Xid 48` = HBM double-bit ECC, `Xid 63` = row-remapping event, `Xid 74` = NVLink fault, `Xid 79` = GPU fallen off PCIe bus, `HW Power Brake Slowdown` = PSU/power brake trip, and `Speed 16GT/s (downgraded), Width x8` = PCIe link downtraining; drain node, reset/reseat/RMA hardware, and verify before `State=resume`.
4. **Exercise 4 (Diagnosing "When Metrics Lie" — `100%` GPU Utilization with Zero Progress):** Active `NCCL` polling kernels peg SM occupancy at `100%` while draws drop to ~`120-180 W` (instead of `600-700 W`); processes stuck in kernel `D` state past `UnkillableStepTimeout` trigger `UnkillableStepProgram` and automatic node drain.
5. **Exercise 5 (Analyzing `sdiag` RPC Storms and `sacctmgr` Database Health):** `sdiag` `Remote Procedure Call statistics by user` exposes UID `25002` (`user1`) flooding `slurmctld`; `SchedulerParameters=max_rpc_cnt,defer,batch_sched_delay` protects the scheduler thread, and `sacctmgr show problem` / `show runawayjobs` reconcile database inconsistencies.
6. **Exercise 6 (Managing Maintenance Windows with `scontrol` Reservations and Rolling Reboots):** Create a maintenance reservation with `Flags=MAINT,IGNORE_JOBS`, roll reboots with `scontrol reboot ASAP nextstate=resume`, and delete the reservation with `scontrol delete reservationname=...` when complete.
