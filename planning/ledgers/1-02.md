## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Redirection Order):** (a) `cmd > out.txt 2>&1` sends both `fd1_stdout` and `fd2_stderr` to `out.txt`; (b) `cmd 2>&1 > out.txt` sends `fd1_stdout` to `out.txt` while `fd2_stderr` stays on the `terminal`; (c) `3>&1 1>&2 2>&3` swaps `stdout` and `stderr` so `stderr` flows down the pipe into `grep`.
2. **Exercise 2 (Exit Statuses):** (a) `126` = command found but not executable; (b) `127` = command not found in `PATH`; (c) `130` = `128 + 2` (`SIGINT`, Ctrl-C); (d) `137` = `128 + 9` (`SIGKILL`, typically kernel OOM killer / `OOMKilled`); (e) `143` = `128 + 15` (`SIGTERM`).
3. **Exercise 3 (Pipeline Exit Status):** (a) Without `pipefail`, `$?` is `0` (the exit status of the last stage `tee`); (b) with `set -o pipefail`, `$?` is `2` (the non-zero exit status of `python3 shard_data.py`); (c) `${PIPESTATUS[@]}` holds `2 0`.
4. **Exercise 4 (Bash Startup Files):** (a) Interactive login shell reads `/etc/profile` and `~/.bash_profile` (ignoring `~/.bash_login` and `~/.profile`); (b) interactive non-login shell reads `~/.bashrc`; (c) non-interactive `ssh gpu01 'nvidia-smi'` reads no startup files by default; deleting `~/.bash_profile` and `~/.bash_login` makes a login shell fall back to `~/.profile`.
5. **Exercise 5 (Command Resolution Precedence):** `ll` resolves first as `alias:ll`; `cd` resolves as `builtin:cd`; `python3` resolves to `/home/alice/bin/python3` (first match in `PATH`); and `nosuchcmd` fails with exit code `127` (`ENOENT_127`).
6. **Exercise 6 (Kernel `errno` Diagnosis):** (a) `ENOENT` caused by a missing `#!` interpreter or Windows `CRLF` (`^M`) in the shebang line (`file run.sh`, `cat -A run.sh`); (b) `ENOTDIR` because `a` is a regular file rather than a directory (`file a`, `ls -ld a`); (c) `ENOSPC` caused by inode exhaustion (`df -i`); (d) `E2BIG` because glob expansion exceeded `getconf ARG_MAX` (fix with `find . -name '*.tmp' -delete` or `xargs -0`).
