## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (L4 vs. L7 Load Balancing, `Ingress` Mechanics `KUR` Ch. 8, and Dedicated Edge Node Pools `PK` Ch. 6):** L4 `Service type: LoadBalancer` balances per TCP connection (1 external LB per Service), whereas L7 `Ingress`/`Gateway` shares 1 external entry point across many Services by Host/path/header; `Ingress` forwards matched paths unmodified unless rewritten, prevents multi-team host collisions via OPA or Contour `HTTPProxy` root `includes`, and runs cleanly on dedicated edge nodes with `hostNetwork: true` + `dnsPolicy: ClusterFirstWithHostNet` + `externalTrafficPolicy: Local`.
2. **Exercise 2 (The Kubernetes Gateway API: `GatewayClass`, `Gateway`, `HTTPRoute`, `ReferenceGrant`):** `evaluate_httproute_and_reference_grant()` enforces `Exact > PathPrefix` precedence, matches headers (`x-model: llama-70b`) and weighted `backendRefs` (`95/5`), and requires a `ReferenceGrant` in the target namespace for cross-namespace backend references (`ResolvedRefs=True`).
3. **Exercise 3 (Automated TLS Lifecycle with `cert-manager`):** `cert-manager` watches `Ingress`/`Gateway` annotations or `Certificate` CRs and solves ACME `HTTP-01` (inbound port 80, no wildcards) or `DNS-01` (DNS TXT record via API, supports wildcards and private VPC clusters) to populate `kubernetes.io/tls` Secrets and renew at 2/3 of lifetime.
4. **Exercise 4 (Bare-Metal Load Balancing vs. Cloud Container-Native LBs `NEG`/`ALB` IP Mode, `NK` Ch. 6):** MetalLB provides `LoadBalancer` VIPs on bare metal via L2 ARP/NDP or BGP ECMP, while GKE `NEG`s and AWS ALB `target-type: ip` program cloud L7 load balancers with direct Pod IPs (skipping `NodePort` and `kube-proxy` hops).
5. **Exercise 5 (Tuning the L7 Edge for Streaming LLM Inference):** `validate_llm_streaming_gateway_config()` checks `proxy_buffering == "off"` (for real-time SSE tokens), `proxy_read_timeout >= 300s` (plus outer cloud LB idle timeout + SSE heartbeats), `proxy_body_size >= 32m` (for long/multimodal prompts), and `numRetries == 0` on non-idempotent generation `POST`s.
6. **Exercise 6 (KV-Cache and Queue-Aware Routing `InferencePool` and Debugging Edge Status Codes):** `pick_llm_inference_endpoint()` scores replicas by prefix-cache hit bonus minus queue depth and KV-cache utilization; HTTP `404` = unmatched route, `413` = body too large, `429` = rate limit, `502` = upstream reset/protocol mismatch, `503` = zero ready endpoints or circuit breaker, and `504` = upstream timeout.
