## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (`try`/`except`/`else`/`finally` Mechanics, `except Exc as var` Unbinding, `raise ... from`, and `sys.exception()`, `LP` Ch. 33, 34, 36):** Using `trace_try_except_else_finally()`, `else:` runs only when `try:` raises no exception while `finally:` runs unconditionally; Python automatically executes `del var` on exiting `except Exc as var:` so `var.__traceback__` frame references do not form a reference cycle; and bare `except:` swallows `SystemExit` (`sys.exit(62)`) and `KeyboardInterrupt` and masks typos like `NameError` (`myditctionary`).
2. **Exercise 2 (Exception Hierarchies `NumErr`, Custom State `FormatError`, `ExceptionGroup`/`except*`, and Context Managers `LookingGlass`, `LP` Ch. 35 & `FP` Ch. 18):** Inheriting library exceptions from a category superclass (`NumErr -> Divzero, Oflow, Uflow`) lets `except NumErr:` catch future subclasses and `FormatError(line, file)` carry structured state; `split_exception_group_demo()` shows `except*` running multiple handlers on a single `ExceptionGroup`; and in `safe_looking_glass()`, `@contextlib.contextmanager` must wrap `yield` in `try ... finally:` because exceptions in the `with` block are thrown into the generator at `yield`.
3. **Exercise 3 (Files, `pathlib`, Atomic Writes `mkstemp` + `fsync` + `os.replace`, and `flock`):** `atomic_write` creates a temp file in `dir=path.parent` (same filesystem mount), calls `f.flush()` + `os.fsync(f.fileno())` to persist data to media before `os.replace(tmp, path)` atomically renames the directory entry, and `fsync`s the parent directory fd; `open(path, "x")` prevents TOCTOU creation races while `fcntl.flock(fd, fcntl.LOCK_EX | fcntl.LOCK_NB)` prevents overlapping cron runs.
4. **Exercise 4 (Unicode Text vs. Bytes, `'AÄBèC'`, `NFC`/`casefold`/`shave_marks_latin`, and `struct`, `LP` Ch. 37 & `FP` Ch. 4):** Using `inspect_unicode_and_struct()`, `'AÄBèC'` has 5 code points, 7 UTF-8 bytes (2 bytes each for `'Ä'` and `'è'`), and 5 Latin-1 bytes, while `struct.pack('>i4sh', 7, b'code', 8)` packs big-endian binary structures; `unicodedata.normalize('NFC', s)` makes `'caf\u00e9' == 'cafe\u0301'`, `shave_marks_latin()` strips combining marks only after ASCII letters, `errors="surrogateescape"` round-trips undecodable filenames, and `r'\d+'` matches Unicode digits while `rb'\d+'` matches only ASCII `0..9`.
5. **Exercise 5 (Serialization Formats `json`, `yaml.safe_load`, `tomllib`, `csv`, and Structured Logging):** `yaml.safe_load()` and `tarfile` `filter="data"` prevent arbitrary code execution and path traversal on untrusted inputs, CSV requires `newline=""` (and `encoding="utf-8-sig"` for BOMs), timestamps use UTC (`datetime.now(timezone.utc)`) while durations use `time.monotonic()`, and `logging` handlers are configured once in the application entry point (`sys.stderr`, `%s` lazy formatting) while libraries attach `NullHandler()`.
6. **Exercise 6 (Safe Subprocess Execution, Pipe Deadlocks, Process Groups `killpg`, and Signals `SIGTERM`):** Passing an argument list to `subprocess.run(..., capture_output=True, text=True, check=True, timeout=30)` invokes `execve` without a shell (preventing command injection), `p.communicate()` prevents stdout/stderr pipe-buffer deadlocks, `start_new_session=True` + `os.killpg` kills the entire child process tree on timeout, and setting a `threading.Event` inside a `SIGTERM`/`SIGINT` handler lets operational scripts finish in-flight work and return standard exit codes (`0`, `1`, `2`, `130`).
