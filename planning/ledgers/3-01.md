## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (CPython Execution Model, `-i`, `import` + `reload` vs. `exec`, and `__main__` Exit Codes, `LP` Chapter 3):** CPython compiles `.py` source into stack-VM bytecode (`.pyc` in `__pycache__`) executed by the PVM; `python3 -i script.py` drops into the interactive REPL in `script`'s namespace after execution; `import mod` runs once in an isolated module namespace (requiring `importlib.reload(mod)` to re-run), whereas `exec(open('script1.py').read())` executes unconditionally in the caller's namespace (overwriting local variables like `x = 999`); and `if __name__ == "__main__": raise SystemExit(main())` returns a `0`/non-zero exit code to systemd/CI.
2. **Exercise 2 (Objects, Names as References, Mutability, Shallow vs. Deep Copy, and `is` vs. `==`, `FP` Chapter 6):** Every Python object has an `id()`, `type()`, and value, and assignment binds a name to an object without copying; using `demonstrate_shallow_vs_deep_copy()`, a shallow copy (`d.copy()`) duplicates the outer container while still sharing nested mutable lists, whereas `copy.deepcopy(d)` recursively copies nested objects; always use `==` for value equality and `is` only for singletons (`is None`).
3. **Exercise 3 (Numbers, Operator Precedence, and Floor Division `//` vs. Truncation `math.trunc`, `LP` Chapter 5):** Using `compare_floor_vs_trunc()`, `/` performs true float division (`5 / -2 == -2.5`), `//` and `math.floor()` perform **floor division toward $-\infty$ (`5 // -2 == -3`)**, and `math.trunc()` / `int()` perform **truncation toward zero (`int(5 / -2) == -2`)**; use `math.isclose()` for IEEE 754 floats, `Decimal` (from strings) for billing, and `round()` (round-half-to-even).
4. **Exercise 4 (Strings vs. Bytes, f-Strings, `string.Template`, and `str.maketrans`/`str.translate`, `LP` Chapter 7):** `str` is immutable Unicode code points (`encode('utf-8')` -> `bytes`) and `bytes` is raw `0..255` octets (`decode('utf-8')` -> `str`); using `sanitize_and_render_host_template()`, `str.maketrans(':-', '__', ' ()')` + `.translate()` maps and deletes characters in a single pass, while `string.Template('$host has ${gpus} GPUs').substitute(...)` / `.safe_substitute(...)` provides safe `$`-placeholder substitution without executing inline code.
5. **Exercise 5 (Collections Complexity, Aliasing Traps, `print()` Stream Redirection, `match`, and `for ... else`):** `x in set`/`dict` is `O(1)` average versus `O(n)` for `list`; `[[0]*3]*3` aliases the same inner list 3 times (use `[[0]*3 for _ in range(3)]`); `print(..., sep=..., end=..., file=..., flush=...)` redirects per-call output via `file=sys.stderr` without mutating `sys.stdout`; `match` destructures dicts/sequences; and `for ... else` runs the `else` block only when the loop completes **without** hitting `break` (ideal for bounded retry loops).
6. **Exercise 6 (Function Parameter/Call Ordering Rules, the Mutable Default Trap, and `LEGB` Closures, `LP` Chapter 18):** Formal parameters must appear in strict order `(pos_only, /, normal, *args, kw_only, **kwargs)`; because default arguments are evaluated **once at `def` time**, a mutable default (`nodes=[]`) leaks state across requests—always use `nodes=None` (`add_node_safe()`); name lookup follows **LEGB** (*Local, Enclosing, Global, Built-in*), where `make_nonlocal_counter()` uses `nonlocal` to rebind state in an enclosing function scope.
