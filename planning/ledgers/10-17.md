## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (3-way stream overlap model & hardware limits):** (a) Overlapped with pinned memory + `cudaMallocAsync` runs in `18.16 ms` (`1.98x` speedup vs `36.0 ms` serial); (b) pageable memory degrades to `32.16 ms`; (c) blocking `cudaMalloc` degrades to `36.0 ms`; two streams contending on a 100%-saturated resource get `50.0%` each, and the hardware limit on concurrent resident grids is `128`.
2. **Exercise 2 (`cudaMemPoolAttrReleaseThreshold` & LLM scratch buffers):** `prop.totalGlobalMem / 2 = 96 GiB` (`103,079,215,104` B) on a `192 GiB` GPU; `16 MB = 16,777,216` bytes; `512 -> 1,024` tokens is a `2.0x` scratch growth factor; enabled in PyTorch via `PYTORCH_ALLOC_CONF=backend:cudaMallocAsync`.
3. **Exercise 3 (`cudaStreamLegacy`, `PTDS`, `cudaStreamNonBlocking` & `cudaLaunchHostFunc`):** `stream 0` (`cudaStreamLegacy`) acts as a bidirectional global barrier with all blocking streams; `PTDS` is enabled via `nvcc --default-stream per-thread` or `#define CUDA_API_PER_THREAD_DEFAULT_STREAM 1`; calling `cudaMemcpy` inside a `cudaLaunchHostFunc` callback deadlocks because the callback runs on an internal CUDA runtime thread that the stream is waiting on.
4. **Exercise 4 (`warp_specialized_two_pipelines`):** (a) `2 * 3 * 1,024 * 4 = 24,576 B` (`24.0 KiB`); (b) `32` lanes * `4` floats (`float4` = `16 B`/lane) = `128` floats (`512 B`, four `128B` coalesced sectors) per unrolled warp copy; (c) `pipe_lc` (depth `2`) coordinates `warp 0` (loader) -> `warp 1` (compute), and `pipe_cs` (depth `2`) coordinates `warp 1` (compute) -> `warp 2` (storer).
5. **Exercise 5 (`launch_warp_specialized_cluster_pipeline_multistream`):** (a) `shmemBytes = 3 * 16,384 * 4 = 196,608 B` (`192.0 KiB`); (b) `blocksPerGrid = 132 * 4 = 528` blocks and `rows_per_block = 128 // 4 = 32` rows/CTA; (c) even though full-grid cooperative cluster kernels serialize on the SMs, `NUM_STREAMS = 2` overlaps Stream 1's `cudaMallocAsync` and `cudaMemcpyAsync` (H2D) and Stream 0's `cudaMemcpyAsync` (D2H) and `cudaFreeAsync` behind active kernel execution.
6. **Exercise 6 (`PDL` + `__cluster_dims__(2,1,1)`):** (a) Without `PDL`: `1.6 + 0.4 + 2.0 = 4.0 ms`; with `PDL`: `1.6 + max(0.4, 2.0) = 3.6 ms` (saving `0.4 ms`); (b) `2 * 128 * 128 * 4 = 131,072 B` (`128.0 KiB`) static SMEM; (c) primary calls `cudaTriggerProgrammaticLaunchCompletion()`, secondary calls `cudaGridDependencySynchronize()`, and host sets `cudaLaunchAttributeProgrammaticStreamSerialization` on `cudaLaunchKernelExC`.
