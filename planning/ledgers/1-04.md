## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (`uniq -c` vs `sort | uniq -c`):** (a) `uniq -c` alone outputs `[(1, "alice"), (1, "bob"), (2, "alice"), (1, "bob")]` because it only collapses adjacent duplicates; (b) `sort | uniq -c` outputs `[(3, "alice"), (2, "bob")]`.
2. **Exercise 2 (`cut -d' '` vs `awk`):** On `"root      1024  0.0  0.1 slurmd"`, `cut -d' ' -f2` returns an empty string `""` (between the first and second spaces), whereas `awk '{print $2, $5}'` splits on runs of whitespace and returns `"1024 slurmd"`.
3. **Exercise 3 (Masking and Ranking Error Logs):** `grep -i error` keeps the 3 `ERROR` lines (dropping `WARN`), `sed -E 's/[0-9]+/N/g'` normalizes both `rank 3` and `rank 5` timeouts into the identical string `"... ERROR NCCL timeout on rank N"`, and `sort | uniq -c | sort -rn` ranks the NCCL timeout first with count `2` and the CUDA OOM error second with count `1`.
4. **Exercise 4 (`find -print0 | xargs -0 -n 2`):** `xargs -0 -n 2` forms two batches (`["run 01.log", "run 02.log"]` and `["run 03.log"]`) while preserving the space inside each filename; plain `xargs` without `-0` splits on whitespace and passes `"run"` and `"01.log"` as separate nonexistent filenames.
5. **Exercise 5 (`tail -n +2` and `nvidia-smi` CSV Aggregation):** (a) `tail -n +2` skips the header row and returns the 3 data rows (`0,95,40000`, `1,85,20000`, `2,92,60000`); (b) GPUs `0` (`95%`) and `2` (`92%`) exceed `90%` utilization; (c) total GPU memory used is `40,000 + 20,000 + 60,000 = 120,000 MiB`.
6. **Exercise 6 (Portable `sed -i` and `LC_ALL=C`):** (a) BSD `sed` on macOS requires an explicit backup suffix argument to `-i` (`sed -i ''`), whereas `sed -i.bak 's/debug=1/debug=0/' app.conf` works on both GNU and BSD `sed`; (b) `LC_ALL=C` forces deterministic ASCII byte-order sorting and matching across all machines.
