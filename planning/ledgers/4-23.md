## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Repository Architecture `modules/` vs. `live/` and Multi-Stack Orchestration `Terragrunt`, `TUR` Ch. 8 & 10):** Partition `live/` by environment (`prod/`, `staging/`, `lab/`), region, and layered stack (`global -> network -> storage -> cluster -> gpu-pools`); `render_terragrunt_backend_key()` models Terragrunt's `path_relative_to_include()` generating unique S3 state keys per child folder while `dependency` blocks and `run-all` orchestrate cross-stack ordering.
2. **Exercise 2 (The Production-Readiness Checklist, Essential vs. Accidental Complexity, and Module Decomposition, `TUR` Ch. 8):** Production readiness spans Correctness/Safety, Security/Compliance, Operability, and Quality (plus `TUR` Ch. 8's 20-item checklist); decomposing monolithic modules into `asg-rolling-deploy` + `alb` + `hello-world-app` maximizes composability, while `local-exec`/`remote-exec`/`data "external"` are last-resort escape hatches.
3. **Exercise 3 (The Terraform Testing Pyramid, Dependency Injection `var.mysql_config`, and `RunTestStage`, `TUR` Ch. 9):** Optional `var.mysql_config` injection decouples module tests from `terraform_remote_state`; `random.UniqueId()` and `defer terraform.Destroy` isolate parallel Terratest runs; `run_terratest_stages()` models `SKIP_<stage>=true` skipping slow DB setup/teardown during local iteration; and a persistent `staging` environment avoids brittle from-scratch full-stack E2E tests.
4. **Exercise 4 (Team Workflow, the Golden Rule of Terraform, and Artifact Promotion, `TUR` Ch. 10):** The `main` branch of `live/` must be a 1:1 representation of production (never using long-lived `stage`/`prod` Git branches); changes flow through PR static/unit/plan/policy checks, merge to apply the saved plan in `staging`, soak, and promote to `prod` by bumping the immutable `?ref=vX.Y.Z` tag.
5. **Exercise 5 (Policy as Code Guardrails `OPA`/`Rego`, `Conftest`, `Infracost` for GPU Infrastructure):** `evaluate_production_guardrails()` inspects `plan.json` `resource_changes` to block deleting `tier == "prod"` node pools without `allow-prod-destroy`, block unversioned storage buckets, enforce `ManagedBy = "Terraform"` tags, and verify multi-NIC EFA/GPUDirect-TCPX configurations.
6. **Exercise 6 (Operating the Estate at Scale: Upgrades, Break-Glass Reconciliation, and GPU Capacity Reservations):** Upgrade providers/core one stack/layer at a time in separate PRs; reconcile emergency console changes into `.tf` + `import {}` within 24 hours; and protect GPU capacity reservations with `prevent_destroy = true` while draining Slurm/Kubernetes nodes before rolling updates.
