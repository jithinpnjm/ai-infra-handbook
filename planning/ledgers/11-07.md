## 4. One-Line Expected Exercise Solutions
1. **Exercise 1:** `requested_as_single_pod=True` returns `schedulable=False` because `64 > 8` GPUs/node and a Pod cannot span nodes; `requested_as_single_pod=False` returns `required_pods=8` and `gpus_per_pod=8`.
2. **Exercise 2:** With `gang_enabled=False`: `placed_pods=7`, `pending_pods=1`, `wasted_idle_gpus=56`, `wasted_usd_per_hour=140.0`; with `gang_enabled=True`: `placed_pods=0`, `pending_pods=8`, `wasted_idle_gpus=0`, `wasted_usd_per_hour=0.0`.
3. **Exercise 3:** Node 1 scores `67.86` (`(75*5 + 50 + 50)/7`) and Node 2 scores `39.29` (`(25*5 + 75 + 75)/7`); Node 1 wins because `nvidia.com/gpu` carries `weight: 5` vs `weight: 1` for CPU and memory.
4. **Exercise 4:** Valid: `("MostAllocated", ("HighNodeUtilization",))` and `("LeastAllocated", ("LowNodeUtilization",))`; invalid (eviction loops): `("LeastAllocated", ("HighNodeUtilization",))`, `("MostAllocated", ("LowNodeUtilization",))`, and enabling both plugins together.
5. **Exercise 5:** `backfilled_jobs = ["short-8gpu-a", "short-16gpu-d"]` (both have `TimeLimit <= 45` min, consuming `8 + 16 = 24` GPUs and leaving `976` idle GPUs), while `long-8gpu-b` (`90 > 45` min) and `no-timelimit-c` (`None`) are blocked.
6. **Exercise 6:** (a) Llama 3.1 `8B` LoRA: `2 * 16.0 + 68.0 = 100.0 GB`; (b) `70B` full fine-tuning: `2 * 140.0 + 220.0 = 500.0 GB`.
