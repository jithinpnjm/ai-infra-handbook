## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The Five Netfilter Hooks, Table Priority Order, and Loopback Re-Entry, `NK` Chapter 2):** Using `trace_netfilter_hooks()`: external-to-local packets hit `prerouting -> input`, local-to-external hit `output -> postrouting`, forwarded packets hit `prerouting -> forward -> postrouting`, and local-to-local (loopback) packets hit `output -> postrouting -> prerouting -> input`; within a hook, subsystems run in priority order `raw -> conntrack -> mangle -> nat (dnat) -> filter -> security -> nat (snat)`.
2. **Exercise 2 (`iptables` Linear `O(n)` Chains vs. `nftables` Families, Sets, Verdict Maps, and Flowtables):** `iptables` evaluates rules linearly (`O(n)`) and requires separate `iptables`/`ip6tables`/`arptables`/`ebtables` binaries, whereas **`nftables`** compiles rules into bytecode in a unified `inet` (IPv4+IPv6) table, uses `O(1)`/`O(log n)` **sets and maps** (`@mgmt_nets`, `@blocklist`), replaces rulesets atomically (`nft -f`), and offloads established forwarded flows via **`flowtable`s**.
3. **Exercise 3 (Writing a Default-Deny GPU Node Firewall and a Router/NAT Gateway in `nftables`):** Accept `iif lo` and `ct state established,related` first, drop `ct state invalid`, allow essential ICMP/ICMPv6 (`echo-request`, `destination-unreachable`, `packet-too-big`, `time-exceeded`, `nd-*`) for PMTUD and Neighbor Discovery, restrict `tcp dport 22` to `@mgmt_nets` and exporters (`9100`, `9400`) to Prometheus, and apply a safety rollback timer before loading remotely.
4. **Exercise 4 (`nf_conntrack` States, Sizing `nf_conntrack_max` and `hashsize`, Timeouts, and `notrack` Bypass):** Using `classify_conntrack_packet_state()` and `size_conntrack_table()`: conntrack classifies flows into `NEW`, `ESTABLISHED`, `RELATED` (e.g., ICMP Frag Needed for an active flow), `INVALID` (dropped), and `UNTRACKED` (`raw` `notrack`); when `nf_conntrack_count == nf_conntrack_max`, the kernel silently drops new connections (`nf_conntrack: table full, dropping packet`, `insert_failed` in `conntrack -S`)—fix by lowering `nf_conntrack_tcp_timeout_established` from `432,000 s` (5 days) to `3600 s`, raising `nf_conntrack_max` (`2097152`) with `hashsize = max / 8` (`262144`), or exempting high-rate stateless flows with **`notrack`** (plus bidirectional stateless allow rules).
5. **Exercise 5 (Docker `DOCKER-USER` and Kubernetes `kube-proxy` `KUBE-SERVICES` / `IPVS` / Cilium `eBPF` Interactions):** Docker inserts its `DOCKER` DNAT chain before host input/forward rules (so user restrictions on published ports must go in **`DOCKER-USER`** or bind to `127.0.0.1:8080:80`); `kube-proxy` in `iptables` mode creates `O(N)` `KUBE-SVC-*` and `KUBE-SEP-*` chains per Service, whereas **IPVS mode** uses `O(1)` kernel hash tables and **Cilium eBPF** performs service translation at the socket/TC layer without `iptables`.
6. **Exercise 6 (Tracing Dropped Packets with `meta nftrace set 1`, `conntrack -E`, and `dropwatch`):** Insert a priority `-300` `prerouting` rule matching the problem flow with **`meta nftrace set 1`** and run **`sudo nft monitor trace`** to see every table, chain, rule handle, and verdict hit by the packet in real time, complemented by `conntrack -L`/`-E` and `dropwatch -l kas`.
