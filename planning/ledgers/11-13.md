## 4. One-Line Expected Exercise Solutions
1. **Exercise 1:** `research = 50.0%` (`16/32`), `data-eng = 37.5%` (`12/32`), `interns = 12.5%` (`4/32`); dedicated nodes strand idle GPUs whenever a team uses `< 100%` of its nodes (`60.0%` utilization), whereas shared fair-share quotas allow bursting into idle GPUs (`85.0%` utilization, `+25.0` percentage points).
2. **Exercise 2:** (a) Professor A (`8` GPUs): `balance = -100.0` GPU-hr, `deficit_ratio = +0.20`, `priority_score = -0.20`; (b) Professor B (`2` GPUs): `balance = +150.0` GPU-hr, `deficit_ratio = -0.60`, `priority_score = +0.70` (`+0.60 + 0.10` small-job boost).
3. **Exercise 3:** `600.0 + 100.0 = 700.0` GPU-hours used out of `750.0` quota GPU-hours = `93.33%` (`~93%`) utilization; hard-capping Professor A at `500.0` would have wasted `100.0` additional GPU-hours (leaving `150.0` of Professor B's unused quota idle).
4. **Exercise 4:** Default `kube-scheduler` rejects fractional `0.5` GPU requests and has neither native all-or-nothing gang scheduling nor automatic NVSwitch domain co-location (`default_scheduler_satisfies_all=False`), whereas `kai-scheduler` supports all three natively (`kai_scheduler_satisfies_all=True`).
5. **Exercise 5:** At `8` seconds (`<= 30s`), `saved_before_sigkill=True` and `computation_lost_steps=0`; at `45` seconds (`> 30s`), `kubelet` sends `SIGKILL` at `30s`, so `saved_before_sigkill=False` (`computation_lost_steps=-1`).
6. **Exercise 6:** (1) Increase the team's guaranteed quota; (2) reduce cluster oversubscription; (3) enable age-based priority promotion / `> 2x` over-quota threshold for jobs `> 8` hours; (4) provide reserved exclusive time slots (e.g., `3 AM – 7 AM`).
