## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Why Kubernetes Exists `KUR` Ch. 1 and the Two Architectural Invariants):** Kubernetes provides Velocity (via Immutability, Declarative Configuration, and Self-Healing), Scaling, Infrastructure Abstraction, Efficiency, and Ecosystem integration; `validate_k8s_communication_edges()` verifies that only `kube-apiserver` talks to `etcd` and all other components coordinate via `kube-apiserver` watches and state updates.
2. **Exercise 2 (Control-Plane Components, Ports, and the `kubectl apply` -> Running Pod Sequence):** `kubectl` (`POST :6443`) -> `kube-apiserver` (APF -> AuthN -> AuthZ -> Mutating Admission -> Schema Validation -> Validating Admission) -> `etcd` (`:2379`) -> `Deployment` controller (`:10257`) -> `ReplicaSet` controller -> `kube-scheduler` (`:10259`) -> `kubelet` (`:10250`) -> `containerd` CRI -> `EndpointSlice` controller.
3. **Exercise 3 (Node Components, `Capacity` vs. `Allocatable`, and Version Skew, `KUR` Ch. 3):** `compute_node_allocatable()` computes `Allocatable = Capacity - kube-reserved - system-reserved - eviction-threshold` so user pods cannot starve `kubelet`/`containerd` while keeping all 8 `nvidia.com/gpu` allocatable; `kubectl` skews $\pm 1$ minor version, controllers up to $-1$, and `kubelet` up to $-2$/$-3$ relative to `kube-apiserver`.
4. **Exercise 4 (The Declarative Object Model):** Level-triggered reconciliation compares current state against `spec` using SharedInformer list+watch caches (`resourceVersion` optimistic concurrency rejecting stale updates with HTTP `409 Conflict`), while `ownerReferences` drive cascading garbage collection and `finalizers` gate deletion until external cleanup completes.
5. **Exercise 5 (High Availability, Raft Quorum, Leader Election, and Failure Timelines):** `compute_etcd_raft_quorum()` shows 3-node (`quorum=2, tol=1`) beats 4-node (`quorum=3, tol=1`) and 5-node tolerates 2 failures; running pods survive control-plane outages; when `kubelet` stops heartbeating (`10s` Lease), the node becomes `Unknown` at `40s` (`node-monitor-grace-period`) and pods are evicted after `340s` (`300s` `unreachable` taint toleration).
6. **Exercise 6 (Extension Points and Scaling a 5,000-Node GPU/AI Cluster):** Combine CRI, CNI + Multus/SR-IOV, CSI, NVIDIA Device Plugin / DRA, Admission Webhooks/CEL, Operators, and Kueue/Volcano, and scale the control plane with dedicated NVMe `etcd` (plus separate `etcd-events`), tuned APF/`--max-requests-inflight`, higher controller QPS/burst, and P2P image distribution.
