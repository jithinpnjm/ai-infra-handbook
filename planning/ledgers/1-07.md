## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (RPM `.rpmnew` vs `.rpmsave` & Debian `remove` vs `purge`):** (a) Under `%config(noreplace)`, the user's edited `/etc/ssh/sshd_config` is kept and the new default is written as `/etc/ssh/sshd_config.rpmnew`; under `%config` (replace), the user's file is backed up as `.rpmsave` and the new default is installed; (b) on Ubuntu, `apt remove` leaves config files on disk (`rc` in `dpkg -l`), whereas `apt purge` removes config files too (`ii` means installed and configured).
2. **Exercise 2 (`ld.so` Search Order & `RPATH`):** (a) `ld.so` searches `DT_RPATH` (if no `DT_RUNPATH`), `LD_LIBRARY_PATH`, `DT_RUNPATH`, `/etc/ld.so.cache`, and default directories (`/lib`, `/usr/lib`); (b) link with `cc -o myprog myprog.o -Wl,-rpath=/opt/obscure/lib -L/opt/obscure/lib -lweird`.
3. **Exercise 3 (`Makefile` Timestamp Rebuild Graph):** (a) Running `make` with unchanged timestamps rebuilds `[]` (`Nothing to be done`); (b) `touch greet.c && make` rebuilds `["greet.o", "hello"]` (skipping `main.o`); (c) `touch greet.h && make` rebuilds `["main.o", "greet.o", "hello"]`.
4. **Exercise 4 (Source Builds & `patch -p1`):** (a) `tar tzf` checks that all files sit inside one top-level directory and contain no malicious absolute paths (`/etc/passwd`), and `make -n install` previews every install command without writing to disk; (b) `patch -p1 < fix.patch` strips the leading `package-3.42/` component.
5. **Exercise 5 (10-Step Mini-Cluster Build & OFED):** (a) Building and testing a 2-compute-node mini-cluster (Steps 1–9) verifies OFED bandwidth/latency and Slurm job execution before Step 10 clones the image across the fleet; (b) for OFED, back up existing OFED packages first (the installer removes old packages before compiling) and set `* soft memlock unlimited` and `* hard memlock unlimited` in `/etc/security/limits.conf`.
6. **Exercise 6 (Prototype Node Cloning Preparation):** (1) Replace hardware-specific `/dev/disk/by-id/...` references in GRUB and `/etc/fstab` with portable `UUID=` or device names, (2) delete MAC-bound network interface udev rules (`70-persistent-net.rules`), and (3) remove SSH host keys and `/etc/machine-id`.
