## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Warp-batched L2 atomic work queues):** (a) Unbatched executes `1,048,576` atomics vs `131,072` (`batchSize = 8`, `8x` reduction), `65,536` (`batchSize = 16`, `16x` reduction), and `32,768` (`batchSize = 32`, `32x` reduction); (b) target `atomic_transactions_per_request` is `~1.0`; (c) `computeKernelDynamicBatch` cuts runtime from `200 ms` to `100 ms` (`2.0x` speedup).
2. **Exercise 2 (LLM decode CPU launch overhead & Table 12-1):** (a) `45.0 / (45.0 + 9.0) = 83.3%` (`> 80%`) of wall-clock time is spent in CPU launch overhead; (b) `500 * 80 = 40,000` kernel launches are collapsed into `500` graph replays (`39,500` launches eliminated); (c) Table 12-1 shows CPU launches drop `300 -> 100`, host syncs drop `300 -> 0`, inter-kernel gaps drop `~3 µs -> 0 µs`, and iteration latency drops `~1.00 ms -> ~0.75 ms` (`25%` faster).
3. **Exercise 3 (Device-initiated graph modes & Conditional Graph Nodes):** `cudaStreamGraphFireAndForget` runs immediately/concurrently (`120` max), `cudaStreamGraphTailLaunch` runs after the launching kernel completes (`255` max pending, `1` max self-tail-launch via `cudaGetCurrentGraphExec()`), and `cudaStreamGraphFireAndForgetAsSibling` runs as a peer without delaying parent tail launches; `IF` node uses `cudaGraphConditionalHandleCreate`, `cudaGraphSetConditional` (from `threadIdx.x == 0`), `cudaGraphAddConditionalNode` (`cudaGraphCondTypeIf`, `size = 1`), `cudaGraphInstantiateFlagDeviceLaunch`, and `cudaGraphUpload`.
4. **Exercise 4 (Dynamic Parallelism Table 12-2):** Host launches drop `3 -> 1`, per-launch overhead shifts `~20 µs -> ~25 µs`, GPU idle cycles drop `~40% -> ~5%` (`-35` percentage points), and runtime drops `1.00 ms -> 0.75 ms` (`25%` faster); controlled via `cudaLimitDevRuntimePendingLaunchCount` (`2,048` default) and `cudaLimitStackSize`.
5. **Exercise 5 (`NVSHMEM` one-sided PGAS & Graph-Captured `NCCL`):** `sender_kernel` calls `nvshmem_float_p(remote_data + 1, value, dest_pe)` -> `nvshmem_quiet()` -> `nvshmem_int_p(remote_flag + 0, 1, dest_pe)` while `receiver_kernel` calls `nvshmem_int_wait_until(remote_flag + 0, NVSHMEM_CMP_EQ, 1)`; `nvshmemx_collective_launch()` is required whenever kernels invoke device-wide NVSHMEM barriers (`nvshmem_barrier_all()`); graph-captured `NCCL` requires identical collective sequences across all ranks, warmup collectives prior to capture, and preallocated fixed-address buffers.
6. **Exercise 6 (Volume 03 Funnel & Lab 04 Diagnostics):** Regression A (`cudaDeviceSynchronize`) slows `812.4 ms -> 1,928.3 ms` (`2.37x` / `~2.4x`), Regression B (`16 KiB` tiny chunks, `1,024x` more chunks) slows to `3,140.9 ms` (`3.87x` / `~3.9x`), and Regression C (pageable host memory) slows to `2,214.8 ms` (`2.73x` / `~2.7x`); `512 MiB` fails despite `1,895 MiB` free because `1,240 MiB` is fragmented across `340` non-contiguous blocks; `3906 * 256 + 287 = 1,000,223 > 1,000,003`.
