## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) Storage `DSCP 18` + `ECT(0)` (`2`) = `74` (`0x4a`); RoCE `DSCP 26` + `ECT(0)` (`2`) = `106` (`0x6a`) and with `CE` (`3`) = `107` (`0x6b`); RoCE `EF` (`DSCP 46`) + `00` = `184` (`0xb8`); `CNP` `DSCP 48` + `ECT(1)` (`1`) = `193` (`0xc1`); (b) `DSCP 18` -> bucket `16-23` (`Priority 4`, `TC4`), `DSCP 26` -> bucket `24-31` (`Priority 3`, `TC3`), `DSCP 46` -> bucket `40-47` (`Priority 3`, `TC3`), and `DSCP 48` -> bucket `48-55` (`Priority 6`, `TC6`).
2. **Exercise 2:** (a) On `400.0 Gbps`, full contention allocates `TC6 = 10.0 Gbps`, `TC0 = 39.0 Gbps`, `TC2 = 39.0 Gbps`, `TC3 = 195.0 Gbps`, and `TC4 = 117.0 Gbps`; `TC3 + TC4` only (`50:30 = 5:3`) allocates `TC3 = 250.0 Gbps` and `TC4 = 150.0 Gbps`; `TC4` alone gets `400.0 Gbps`; (b) `tc: 1` (`strict`) takes `400.0 Gbps` and starves `tc: 0` (`0.0 Gbps`), whereas `dwrr 95:5` guarantees `tc: 0` `20.0 Gbps` (`tc: 1 = 380.0 Gbps`).
3. **Exercise 3:** (a) `256:128:128:512` reduces to `2:1:1:4` across `8` clock cycles, and with `1` `AF41` packet, `0` `AF21` packets, and `3` unclassified packets, Cycles `2`, `4`, and `8` transmit `AF31`, `unclassified`, and `AF31` respectively; (b) on a congested `1,024 Kbps` link (`512 Kbps` `LLQ` cap), `9` calls (`576 Kbps`) drop `64 Kbps`, `12` calls (`768 Kbps`) drop `256 Kbps`, `32` calls at `16 Kbps` (`512 Kbps`) drop `0 Kbps`, and `10` calls (`640 Kbps`) with `<= 384 Kbps` other traffic pass uncongested with `0` drops; (c) at `100 Mbps`, `9,000` B takes `0.72 ms` and `64` B takes `0.00512 ms` (`.05 ms` textbook, `14x` ratio), while at `400 Gbps`, `9,000` B takes `180.0 ns` and `64` B takes `1.28 ns` (`140.625x`).
4. **Exercise 4:** (a) `LLDP` uses `EtherType 0x88CC`, MAC `01:80:C2:00:00:0E`, and IEEE `802.1` OUI `00:80:C2` with subtypes `9` (`ETS Config`, asymmetric), `10` (`ETS Recommend`, asymmetric), `11` (`PFC Config`, symmetric), and `12` (`Application Priority`, symmetric); (b) `(i)` `SWITCH_PEER` (healthy), `(ii)` `BOTH_LOCAL_STATIC` (healthy), `(iii)` `BOTH_LOCAL_STATIC` with `4` mismatches (`PFC_MISMATCH`, `ETS_WEIGHT_MISMATCH`, `APP_TLV_ROCE_4791_MISMATCH`, `TRUST_MODE_MISMATCH`), and `(iv)` `CONFLICT_BOTH_WILLING`.
5. **Exercise 5:** On a `262,144` B port buffer (`65,536` B per lossless priority: `XON = 32,768` B, `XOFF = 49,152` B, headroom = `16,384` B): `(a)` `1` lossless priority reserves `65,536` B (`25.0%`) and leaves `196,608` B (`75.0%`) lossy (`HEALTHY_BUFFER_CARVING`); `(b)` `2` lossless priorities reserve `131,072` B (`50.0%`) and leave `131,072` B (`50.0%`) lossy (`HEALTHY_BUFFER_CARVING`); `(c)` `4` lossless priorities reserve `262,144` B (`100.0%`) and leave `0` B (`0.0%`) lossy (`BUFFER_EXHAUSTED_TOO_MANY_LOSSLESS_CLASSES`).
6. **Exercise 6:** (a) Because `leafB_swp19` is in `trust: pcp` and the routed IP packet has no `802.1Q` VLAN tag (`PCP = None`), `swp19` maps it to lossy **Priority `0`**, causing `rx_prio0_discard = 18,420` while `rx_pfc_prio3 = 0`; (b) `Lab 03` (`47,829` ECN marks, `412` RX PFC, `89.2 + 87.1 = 176.3 Gbps`) demonstrates healthy closed-loop contention on `Priority 3`, whereas `Lab 04` (`392 -> 156 Gbps`, `2.51x` slower, `24` `RETRY_EXC_ERR`s) is a Layer 3 endpoint RoCE device/GID selection error (`mlx5_1` vs `mlx5_0`).
