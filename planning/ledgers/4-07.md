## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Variable Naming, Subscript `['key']` vs. Dot `.key` Access, Scope, and Lazy Evaluation, `AUR` Ch. 5):** Variable names must use letters, digits, and underscores without starting with a digit; subscript notation `d['values']` avoids colliding with Python `dict` methods (`.values`, `.items`, `.keys`, `.copy`) or hyphenated keys; and `set_fact` (`cacheable: true`) creates host-scoped variables persisting across plays while static `group_vars` evaluate lazily at point of use.
2. **Exercise 2 (Registered Variables `register`, Skipped Tasks, and Loop `results`, `AUR` Ch. 5):** `register` stores the module return dictionary (`rc`, `stdout`, `stdout_lines`, or `stat.exists`/`stat.isdir`); skipped tasks still bind the registered variable with `skipped: true` (requiring `when: drv is not skipped`); and looped tasks store per-item results inside `reg.results`.
3. **Exercise 3 (Host Facts `setup`/`ansible_facts`, `gather_subset`, Fact Caching, and `/etc/ansible/facts.d/*.fact`, `AUR` Ch. 5):** `ansible_facts['distribution']` avoids top-level namespace pollution while `gather_subset` and `fact_caching = jsonfile` accelerate large fleets; `parse_local_fact_file()` parses static INI/JSON or executable JSON scripts in `/etc/ansible/facts.d/<name>.fact` into `ansible_local.<name>`.
4. **Exercise 4 (Magic Variables `hostvars`, `groups`, `group_names`, and the `--limit` Missing-Facts Trap, `AUR` Ch. 5):** `host_vars/` is an on-disk directory whereas `hostvars` is the runtime in-memory dictionary of all hosts' variables and facts; `render_haproxy_backend_from_groups()` iterates `groups['web']` and indexes `hostvars[h]`, which requires gathering facts on all referenced hosts (or enabling fact caching) before running with `--limit`.
5. **Exercise 5 (Control-Node Lookups `lookup` vs. `query` and Loop Control `loop_control`, `dict2items`, `subelements`):** Lookups execute on the control node (`lookup` returns comma-joined strings while `query`/`q` returns a list, `password` persists generated secrets, and `first_found` selects OS-specific var files); passing a list to `package: name:` runs in one transaction, and `loop_control: { label: "{{ item.name }}" }` keeps loop logs concise.
6. **Exercise 6 (Configuration Generation Filters `extract`, `combine`, `to_nice_json` and Deterministic Templates):** `groups['gpu'] | map('extract', hostvars, 'ansible_host') | map('regex_replace', '$', ':9400') | list` projects target endpoints into `to_nice_json`, and sorting lists (`| sort`) and dictionaries (`| dictsort`) guarantees deterministic renders that never trigger spurious handler restarts.
