## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Lab 1: Building a Namespace Router, PMTU Black Hole, and `rp_filter` Asymmetric Drop):** Connecting `hA` (`10.1.0.2/24`) and `hB` (`10.2.0.2/24`) through router namespace `r` requires `sysctl net.ipv4.ip_forward=1` in `r` and default routes in `hA`/`hB`; lowering `rB` MTU to `1400` while dropping ICMP Type 3 Code 4 stalls a `20 KB` `nc` transfer until fixed with `TCPMSS --clamp-mss-to-pmtu`, and asymmetric replies across a second router `r2` are dropped by `rp_filter=1` (`ReversePath` in `nstat`) until relaxed to `rp_filter=2`.
2. **Exercise 2 (Lab 2: Running Per-Namespace FRR `zebra` + `ospfd`/`isisd` with Separate Sockets and PIDs):** A software router is simply a Linux network namespace running `zebra` (FIB manager) and protocol daemons (`ospfd`, `isisd`, `bgpd`, `bfdd`) pointed at isolated `--vty_socket /tmp/frr/$n` and `-z /tmp/frr/$n/zserv.api` paths, demonstrating OSPF `ExStart -> Full` adjacency, `ExStart` MTU hangs, and 2-way ECMP across a 4-router diamond.
3. **Exercise 3 (Lab 3: Containerlab Topology-as-Code and Jinja2 FRR Config Generation for eBGP Unnumbered Clos):** Using `build_clos_clab_links(2, 4, 2)` and `render_frr_ebgp_unnumbered_leaf()`: the 2-spine × 4-leaf × 2-host `fabric.clab.yml` defines `16` point-to-point `veth` links (`8` fabric + `8` host), while `gen.py` renders `frr.conf` with `frr defaults datacenter`, `bgp bestpath as-path multipath-relax`, `neighbor swp remote-as external`, `bfd`, and `redistribute connected route-map CONN` so every leaf installs 2 IPv6 link-local (`fe80::`) ECMP next hops per remote rack.
4. **Exercise 4 (Lab 4: Adding EVPN-VXLAN Symmetric IRB, Distributed Anycast Gateway, and Single-VXLAN-Device `vnifilter`):** On each leaf, create a VLAN-aware bridge `br0` (`vlan_filtering 1`), attach a Single VXLAN Device (`vxlan0` with `external vnifilter`, mapping `vid 100` -> `vni 10100`), bind `vlan100` with shared anycast IP/MAC (`10.100.1.1/24`, `00:00:5e:00:01:01`) to `tenantA` (`L3VNI 5001`), and activate `address-family l2vpn evpn` with `advertise-all-vni` to verify Type 2, Type 3, and Type 5 routes and MAC mobility.
5. **Exercise 5 (Lab 5 & Lab 6: Tunnel MTU/Entropy Comparison, SRv6/MPLS Encapsulation, and Anycast Failure Matrix):** Compare usable MTU and CPU across `GRE`, `IPIP`, `VXLAN`, and `WireGuard`, show how `sysctl net.ipv4.fib_multipath_hash_policy=2` enables inner-header ECMP hashing for `GRE`/`IPIP`, demonstrate Linux `encap seg6` (`SRv6`) and `encap mpls`, and record a systematic **failure matrix** (loss and convergence time across link, spine, leaf, LB, and backend failures).
6. **Exercise 6 (Lab 7: Automated Network Validation as Code in CI with `vtysh ... json`):** Using `validate_frr_bgp_and_ecmp_state()`, parse `vtysh -c 'show bgp summary json'` and `vtysh -c 'show ip route <prefix> json'` across all leaves to assert programmatically in CI that all spine sessions are `Established`, every remote rack prefix has `2` ECMP next hops, and all host-to-host pings have `0%` packet loss.
