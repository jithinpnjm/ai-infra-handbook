## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Test Pyramid, `pytest` Fixtures `yield`/`monkeypatch`/`tmp_path`, Parametrization, and State Leakage, `FA` Ch. 8 & `volume-02`):** Fast unit tests test the pure core (`parsers.py`, `rules.py`) with recorded GPU payloads while contract/integration/hardware-in-the-loop (`@pytest.mark.gpu`) tiers test boundaries; `yield` fixtures guarantee teardown, `monkeypatch.setenv` undoes environment mutations per test, and `pytest-randomly` exposes order-dependent state leaks.
2. **Exercise 2 (Fakes vs. Stubs vs. Mocks, Dependency-Injected `Drainer` + `FakeKube`, and `respx`):** Injecting `FakeKube`, `clock`, and `sleep` into `Drainer` tests 600-second timeout loops in milliseconds without brittle mocks; when using `mocker.patch`, patch where the name is looked up (`fleetctl.client.httpx`) with `autospec=True`, or intercept HTTP at the transport layer with `respx`.
3. **Exercise 3 (Property-Based Testing `Hypothesis`, Golden Snapshots, Contract Testing, and Mutation Testing `mutmut`):** `@given(...)` generates and shrinks edge-case inputs to verify round-trip and exception invariants; branch coverage (`branch = true`) checks both `True`/`False` arms of conditionals while `mutmut` mutates AST operators (`>` to `>=`) to expose weak assertions.
4. **Exercise 4 (Static Quality Gates `ruff`/`mypy`/`bandit`/`pip-audit`/`pre-commit` and GitHub Actions CI Hardening):** `ruff` enforces linting/formatting and `S` bandit security rules, `mypy --strict` enforces static types, and `coverage` gates `fail_under = 85` with `branch = true`; the CI pipeline runs `lint -> test matrix -> integration -> wheel build -> OIDC trusted publish` (`id-token: write`, `permissions: { contents: read }`).
5. **Exercise 5 (Empirical Python Benchmarking `timer.py`, `timeit`, and the 5 Iteration Alternatives, `LP` Chapter 21):** `timer_bestoftotal()` and `min(timeit.repeat(...))` take the `min()` because OS noise only inflates runtimes; `map(abs, repslist)` (`0.144s`) beats `[abs(x) for x in repslist]` (`0.208s`) on built-in C functions, whereas `[x + 10 for x in repslist]` (`0.244s`) beats `map(lambda x: x + 10, repslist)` (`0.496s`) because per-item `lambda` calls add Python stack-frame overhead.
6. **Exercise 6 (Testing Infrastructure-as-Code `Molecule` + `Testinfra` and DevOps vs. MLOps Architecture, `AUR` Ch. 14 & `EAS` Ch. 2):** Molecule runs `create -> converge -> idempotence -> verify -> destroy` and `verify_sshd_host()` asserts `openssh-server`, `sshd`, `0o644` key permissions, and user existence via Testinfra; microservices communicate strictly via networked APIs (REST or GraphQL), and MLOps extends the DevOps CI/CD loop with data-quality and model-training/evaluation verification.
