## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) For `GPT-3` `175B` (`H = 12288, FFN = 49152, 96` heads) under `TP = 8`, `W_1` has **`603,979,776` parameters (`~1,208 MB` / `~1.2 GB` in `BF16`)**, `ColumnParallelLinear` shard shape **`(12288, 6144)`**, `RowParallelLinear` `W_2` shard shape **`(6144, 12288)`**, and **`12` attention heads per GPU**; (b) `SP` (`--sequence-parallel`) moves the exact same **`2 * ((TP - 1)/TP) * M`** bytes (`1` `ReduceScatter` + `1` `AllGather` = `1` `AllReduce`) while cutting non-`TP` activation memory by **`8x`** (`local_seq_len = 256`).
2. **Exercise 2:** On a `219 MB` shard across `120` layers (`240` `AllReduce`s), `900 GB/s` intra-node `NVLink` takes **`0.243 ms` (`~0.25 ms`) per collective (`58.4 ms` ~ `60 ms` total)** versus **`8.76 ms` (`~9 ms`) per collective (`2,102.4 ms` ~ `2,160 ms` total)** on `25 GB/s` inter-node InfiniBand (**`36x` slower per collective**), and constraining `TP = 8` within nodes + `PP = 4` across nodes recovers throughput by **`15x` (`1.2 tok/s -> 18 tok/s` vs `16.7x` slowdown from `20 tok/s`)**.
3. **Exercise 3:** (a) Pipeline bubble `(PP - 1) / (m + PP - 1)` is **`27.3%` (`3/11`), `15.8%` (`3/19`), and `8.6%` (`3/35`)** for `PP = 4` at `m = 8, 16, 32`, and **`30.4%` (`7/23`), `9.9%` (`7/71`), and `1.35%` (`7/519`)** for `PP = 8` at `m = 16, 64, 512`; (b) at `PP = 16, m = 256` (`0.5 GB`/micro-batch), `1F1B` caps Stage `0` in-flight activations at **`16` micro-batches (`8.0 GB`) vs `GPipe`'s `256` micro-batches (`128.0 GB`, a `16x` saving)**, and `v = 2` virtual stages halves the bubble-to-useful ratio `(PP - 1) / (m * v)` by **`2x`**.
4. **Exercise 4:** For `B = 1, S = 32768, num_heads = 32, num_kv_heads = 8, head_dim = 128` at `CP = P = 4`, each GPU holds **`8,192` tokens**, Ring Attention executes **`3` (`CP - 1`) rotation steps**, and `DeepSpeed-Ulysses` transposes from sequence-parallel **`(1, 8192, 32, 128)`** to head-parallel **`(1, 32768, 8, 128)`**.
5. **Exercise 5:** (a) For `Mixtral 8x7B` (`E = 8, EP = 8, top_k = 2, B = 2, S = 4096, CF = 1.25`), each GPU hosts **`1` expert**, dispatches **`16,384` token embeddings**, has **`16,384` uniform tokens/expert**, and enforces a maximum capacity of **`20,480` tokens/expert**; (b) `DeepSeek-V3` activates **`9` experts/token (`1` shared + `8` routed of `256`)** and places **`4` routed experts/GPU** at `EP = 64`.
6. **Exercise 6:** (a) Megatron's Distributed Optimizer on `d = 8` `DP` ranks reduces `bf16` params / `fp32` grads memory from `18 B` to **`6 + 12 / 8 = 7.5 bytes/param` (`2.4x` reduction)**; (b) `GPT-3 175B` on `1024` `H100`s (`TP = 8, PP = 16`) yields **`DP = 8`, `6` layers/stage, `1.367B` (`~1.37B`) params/GPU = `21.875 GB` (`~22 GB`) state, `m = 256` micro-batches, and a `5.54%` (`~5.5%`) bubble**, while the `70B` hybrid config on `64` GPUs (`TP = 4, PP = 2`) yields **`DP = 8` and `40` layers/stage**.
