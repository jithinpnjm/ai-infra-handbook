## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Service Types and Service Discovery, `KUR` Ch. 7 & `PK` Ch. 6):** Covers `ClusterIP`, `NodePort`, `LoadBalancer` (with internal annotations on GCP/AWS/Azure/Alibaba), `ExternalName`, Headless (`clusterIP: None`), and selector-less Services; `enableServiceLinks: false` + CoreDNS avoids `<SVC>_SERVICE_HOST` creation-order bugs and environment bloat.
2. **Exercise 2 (`EndpointSlices` vs. Legacy `Endpoints`):** `build_endpointslices()` shards endpoints into 100-endpoint objects (eliminating the $O(N^2)$ monolithic `Endpoints` update storm) and routes to `serving && terminating` endpoints when 0 `ready` endpoints remain.
3. **Exercise 3 (Comparing `kube-proxy` Modes and Cilium eBPF Socket-LB, `NK` Ch. 4 & `PK` Ch. 6):** `compute_iptables_sep_probabilities()` proves sequential rule $i$ uses `1 / (N - i)` so every backend gets an equal `1 / N` share; `IPVS` uses `kube-ipvs0` + `ipset` + 6 schedulers (`rr`, `lc`, `dh`, `sh`, `sed`, `nq`), `nftables` uses $O(1)$ verdict maps, and Cilium eBPF rewrites `connect()` at the socket layer (`cgroup/connect4`) without packet NAT.
4. **Exercise 4 (`externalTrafficPolicy: Cluster` vs. `Local` and gRPC Imbalance):** `simulate_external_traffic_policy()` shows `Cluster` SNATs client source IPs to the ingress node IP and allows cross-node hops, whereas `Local` preserves client source IP and fails `healthCheckNodePort` (`503`) on nodes without local pods; gRPC / HTTP/2 multiplexing over L4 `ClusterIP` pins all requests to 1 pod and is fixed via Headless + client-side LB or an L7 proxy.
5. **Exercise 5 (Linux `conntrack` Internals, Table Exhaustion, and UDP DNS Races):** `conntrack` maps pre-NAT and post-NAT 5-tuples so return packets from backend pods are un-NAT'd back to `ClusterIP`; `nf_conntrack_max` exhaustion drops new connections, and `NodeLocal DNSCache` (`NOTRACK`) eliminates UDP DNS conntrack races.
6. **Exercise 6 (Systematic 4-Step Service Debugging):** Verify DNS resolution (`dig`), check `EndpointSlice`s (`ready: true` and selector/targetPort match), inspect node datapath rules (`iptables-save` / `ipvsadm` / `nft` / `conntrack -L`), and capture packets (`tcpdump -ni any`) before and after DNAT.
