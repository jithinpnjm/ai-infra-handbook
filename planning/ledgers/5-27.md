## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The End-to-End AI Software Supply Chain Threat Model):** Maps source (`A1`), build (`A2`), dependencies/models (`A3`), registry (`A4`), deployment (`A5`), and runtime (`A6`) attack vectors to branch protection/MFA, ephemeral SLSA L3 builders, hash-pinned private indexes + `safetensors`, digest signing + immutability, admission `verifyImages` + `mutateDigest`, and `readOnlyRootFilesystem` + default-deny egress + eBPF runtime detection.
2. **Exercise 2 (The Golden Base Images Antipattern, Cloud Native Buildpacks, and `Tekton` Pipelines, `PK` Ch. 15):** Rebasing third-party images onto a single corporate OS base breaks upstream dependencies and delays security updates; `evaluate_quarantine_image_promotion()` replaces it with a Quarantine-to-Approved promotion gate while Tekton `Task`s (`git-clone`, `buildpacks-phases`) build first-party images in-cluster without a privileged Docker socket.
3. **Exercise 3 (`SLSA` Build Levels `L1–L3`, `in-toto` Attestations, `SBOM`s, and `VEX` Triage):** SLSA L1 generates provenance, L2 signs it on a hosted builder, and L3 isolates ephemeral builds so provenance is non-falsifiable; `Syft` generates SPDX/CycloneDX SBOMs attached via `cosign attest`, and VEX (`not_affected`) suppresses non-exploitable CVEs with documented justification.
4. **Exercise 4 (Keyless Signing with `Sigstore`, `Notary v1` `GUN` Limitations `PK` Ch. 15, and Admission Enforcement):** `verify_image_signature_and_mutate_digest()` checks the OIDC `issuer`, workflow `subjectRegExp`, and SLSA `buildType` before mutating the image reference to its immutable `@sha256:...` digest; unlike Notary v1's registry-URL-coupled `GUN`, `cosign` signs the manifest digest directly so signatures survive registry mirroring.
5. **Exercise 5 (Securing the Python/CUDA Dependency Chain):** `audit_ml_model_and_pip_supply_chain()` flags `--extra-index-url` (which allows public PyPI packages with higher version numbers to shadow internal package names) and enforces a single private `--index-url` + `--require-hashes` + `--only-binary=:all:` + BuildKit `RUN --network=none`.
6. **Exercise 6 (AI Model and Dataset Supply Chain and Incident Response):** Replace unsafe Python `pickle` checkpoints with `safetensors` (or `torch.load(weights_only=True)`), forbid unreviewed `trust_remote_code=True`, sign models via OpenSSF `model-signing` / OCI artifacts, and intersect running cluster digests against your central SBOM database (`Dependency-Track`/`GUAC`) to scope zero-day CVEs in minutes.
