## 4. Source contradictions found

- ASP Table 4-4 percentages: 148 faulty-GPU interruptions is printed as 30.1 percent. With 419 unexpected interruptions it is 35.3 percent. The chapter uses counts only.
- Young and Aupy conventions: Aupy et al. write the period as the square root plus C. Daly, as summarised by Colyer, writes the work interval as the square root minus C. They differ by 2C in the period and agree when C is much smaller than M. Resolved by quoting both and testing that both are within 2 percent of the numeric optimum.
- nvidia-devops Vol 24 Ch 3 says the elastic launcher waits 30 seconds and spins up a replacement GPU. PyTorch 2.15 torchrun docs say agent or node failure is left to the job manager. Chapter follows the PyTorch docs.
- Handbook 14.11 goodput for the optimal case is 88.82 percent; this chapter's waste model gives 89.13 percent for the same inputs. Different models (14.11 ignores fault-time half-period for the restart share). Not an error in either; noted.
- Handbook 12.18 recommends `TORCH_NCCL_ASYNC_ERROR_HANDLING=1`. The 2.15 table says the default is 3. The chapter leaves it at the default and says why.
