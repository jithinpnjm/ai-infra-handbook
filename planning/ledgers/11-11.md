## 4. One-Line Expected Exercise Solutions
1. **Exercise 1:** When `host_gpu_driver_ready=False`, `nv-peer-mem-daemonset` is omitted (`4` operands scheduled) and `gpudirect_rdma_ready=False`; when `True`, all `5` operands schedule and `gpudirect_rdma_ready=True` because `nvidia-peermem` requires both `ib_core` (MOFED) and `nvidia.ko` (GPU driver).
2. **Exercise 2:** (a) `200 Gbps` HDR without GRH: `26` bytes framing, `25.0 GB/s` line rate; (b) `400 Gbps` NDR with `40B` GRH: `66` bytes framing, `50.0 GB/s` line rate; RoCEv2 has `Base lid = 0` and `SM lid = 0` because it uses IP routing over UDP port `4791` instead of an InfiniBand Subnet Manager.
3. **Exercise 3:** (a) `30.72 TB` (`8 * 3.84 TB`); (b) `32.0 GiB` (`33,554,432 KB / 1,048,576`); (c) `280` `WebDataset` `.tar` files (`14,000,000 / 50,000`), reducing `stat()` calls by `50,000x`.
4. **Exercise 4:** (a) `pfc_circular_buffer_deadlock` -> enforce loop-free Clos topology and enable `50ms` `PFC Watchdog`; (b) `roce_microburst_ecn_threshold_too_high` -> lower switch `minimum-absolute` ECN threshold (e.g., `150` KB) so `CNP` (`0x81`) triggers `DCQCN` before `PFC` pauses.
5. **Exercise 5:** `D`-state processes are blocked inside an uninterruptible kernel lock (`rpc_wait_bit_killable`) where signal delivery is masked to prevent kernel memory corruption; check `symbol_error_counter > 1000` / link `DOWN` in `ibstat`/`ibv_devinfo`, hard-reset the wedged node via IPMI (`ipmitool chassis power reset`), and use bounded timeouts on read-only dataset mounts.
6. **Exercise 6:** `1` or `3` compute nodes with `>= 250 GiB` disk and `>= 64 GiB` RAM; run `cm-cmd-ports --http 8083 --https 8084 && systemctl restart cmd` on the head nodes.
