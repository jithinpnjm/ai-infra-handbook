## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (`0 MiB` memory, zombie PID, `DKMS`, `Enroot`):** (a) `GPU 0` has `MIG Mode: Enabled` with `0` GPU Instances (`GI`) created (`nvidia-smi mig -lgi` empty); fix with `sudo nvidia-smi mig -cgi 9,9 -C` or `sudo nvidia-smi -i 0 -mig 0 && sudo nvidia-smi -i 0 --gpu-reset`; (b) clear zombie PID `48213` (`71,234 MiB`) with `sudo fuser -k /dev/nvidia0` or `sudo nvidia-smi --gpu-reset -i 0`; (c) fix `kernel-patch-dkms-break` with `dkms autoinstall` and `enroot-gpu-not-visible` by restoring `/etc/enroot/hooks.d/*nvidia*`.
2. **Exercise 2 (Thermal vs power bitmask & fan rise rate):** (a) `(1980 - 1833) / 1980 = 7.42%` (`~7%`) clock reduction; `nvidia-smi -q -d PERFORMANCE` is required because lower clocks reduce power draw regardless of cause; (b) `(70 - 55) / 60 = 0.25°C/sec` and `(83 - 55) / 30 = 0.93°C/sec` (vs `0.05°C/sec` healthy baseline); (c) `135 min` (`2h 15m`) detection latency + `20 min` repair = `155 min` (`2h 35m`) wasted compute, prevented by `deriv(gpu_temp[1m]) > 0.15` for `10m`.
3. **Exercise 3 (PSU sizing, `12V` sag & DVFS):** (a) `4 * 300 W * 1.3 = 1,560 W` minimum PSU (`1,500 W` is undersized; `0.8 * 1,500 = 1,200 W` safe node budget); (b) `10.8 V < 11.4 V` threshold (`12.0 V ± 0.5 V` nominal) confirms PSU rail sag under burst load; (c) enable persistence mode (`nvidia-smi -pm 1`), set CPU governor to `performance`, and lock clocks via `sudo nvidia-smi -i 0 -lgc 1800` (reset with `-rgc`).
4. **Exercise 4 (PCIe down-training & `NCCL` straggler hunt):** Weekly Gen4 x16 gate is `0.8 * 22.0 = 17.6 GB/s`; retrain via `echo 1 > /sys/bus/pci/devices/0000:08:00.0/remove && sleep 3 && echo 1 > /sys/bus/pci/rescan`; in `NCCL_DEBUG=INFO`, Ranks `0–2` at `opCount 4821` waiting on Rank `3` (`opCount 4820`, `2%` GPU util, `47.31 s` batch fetch, `96%`-full disk, `187 GB / 41 GB = 4.56x` shard skew) proves upstream data starvation on Rank 3.
5. **Exercise 5 (Pre-collective ratio, `NVLink 3` & ECC storm rates):** `1250.5 / 124.8 = 10.02x` (`> 1.2x` straggler threshold); `A100` `NVLink 3` runs at `25 GB/s` per link (`< 20 GB/s` warning); `50 / 0.5h = 100/hr`, `50 * 6 = 300/hr`, and `34 * 60 = 2,040/hr` all exceed the `> 10/hr` (`100/hr` critical) automated job-stop threshold.
6. **Exercise 6 (Cross-Layer Diagnosis & Heisenbug):** Priority order is `1. Data Integrity (Xid 48/95/64 & ECC) > 2. Hardware Performance Cause (Throttle bitmask) > 3. Downstream Symptom (NCCL hang)`; in the `750.00 ms` step, `data_load_cpu` is `60.0%` (`450 ms`), `allreduce_network` is `20.0%` (`150 ms`), and GPU compute is `14.4%` (`108 ms`); `nvidia-smi` polling adds `10.0%` overhead (`500 -> 450`) and `nsys` adds `50.0%` overhead (`500 -> 250`).
