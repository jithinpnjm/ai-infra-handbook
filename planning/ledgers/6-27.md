## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (Verifying Hard-Link Snapshots and Pack Integrity Checks):** `simulate_hardlink_snapshot()` proves that unchanged files share the same inode (`4,004 + 24 = 4,028 KB`), while `verify_pack_repository()` proves that `restic check --read-data` catches a 2-byte pack corruption that metadata-only `restic check` misses.
2. **Exercise 2 (GNU `tar` Incremental Archives and Streaming Pipes):** `--listed-incremental=/var/log/usr.snar --level=0` writes a full baseline archive and subsequent runs write changed files only; restore by extracting level-0 then each increment in order with `--listed-incremental=/dev/null`.
3. **Exercise 3 (Configuring a 3-Daemon Bacula Backup Topology):** Configure Director (`9101`, `bacula-dir.conf`), File Daemon (`9102`, `bacula-fd.conf`), and Storage Daemon (`9103`, `bacula-sd.conf`) with `Write Bootstrap = "/var/spool/bacula/%n.bsr"` so data can be recovered even if the SQL Catalog database is lost.
4. **Exercise 4 (Distributing Identical Updates with `rsync --write-batch` and `--link-dest`):** `--link-dest` creates hard-linked snapshot trees on a backup server, while `--write-batch=update` generates `update` and `update.sh` to replay a precomputed delta across many identical hosts.
5. **Exercise 5 (Designing Control-Plane and Parallel Filesystem Data Protection):** Back up `slurmdbd` (`mysqldump --single-transaction`), LDAP/FreeIPA (`slapcat`/`ipa-backup`), and Vault (`raft snapshot`) hourly/daily to an append-only/WORM repo; back up `/home` daily; use Lustre changelogs + `mpifileutils` `dsync` to versioned S3 Object Lock for curated datasets/models; and exclude `/scratch` by policy.
6. **Exercise 6 (Ransomware Recovery Order and Clean-Room Restoration Drill):** Immutable/WORM (`S3 Object Lock` / append-only repo) and offline copies survive compromised admin credentials; restore in strict dependency order: network/DNS/NTP $\to$ PKI/Vault/`munge.key` $\to$ LDAP/SSSD $\to$ BCM/Warewulf/xCAT $\to$ storage mounts $\to$ `slurmdbd`/`slurmctld`/`slurmd` $\to$ login/OOD portals.
