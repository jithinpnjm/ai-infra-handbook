## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) One `4 KiB` in-capsule `NVMe-o-TCP` `PDU` is `24 + 4 + 64 + 4096 + 4 = 4,192 bytes`, so `MTU 9000` (`MSS = 8,960 bytes`) packs **`2` `PDUs`** (`8,384 bytes`) with **`576 bytes`** remaining; (b) `NVMe-o-RDMA` traverses **`TCP 8009`** (Discovery with `RDMA_PRTYPE = 0x04` `RoCEv2`, `0x02` `InfiniBand`, `0x05` `iWARP`) -> **`UDP 4420`** (`RDMA CM`) -> **`UDP 4791`** (`RoCEv2` `BTH`/`RETH` data).
2. **Exercise 2:** (a) An `LRH` `LID` is **`16` bits** (`65,536` values) supporting up to **`48,000` nodes** per subnet, so `32,000` nodes fit in one subnet while `60,000` nodes require inter-subnet routing via the **`GRH`**; (b) a `4,096-byte` block requires `4096 / 64 =` **`64` `CBFC` credits** (`64 bytes`/credit) across up to **`16` `VLs`** per port.
3. **Exercise 3:** `UET-over-UDP` uses **`IP Protocol 17`**, **`UDP Dst Port 49150`**, and **`UDP Source Port`** entropy, whereas `UET-over-IP` uses **`IP Protocol 253`**, no `UDP` header, and the **`PDS Entropy` field** within the **`128-byte`** switch parse budget; dropping packet `#1` of `64` triggers **`64` retransmissions** under `RoCEv2` `Go-Back-N` vs **`1` selective retry** under `UET` (`63` packets saved, **`64.0x` reduction**).
4. **Exercise 4:** (a) For `65,536 bytes` (`64 KiB`), `RCCC` grants `65536 / 256 =` **`256` credits** (`256 bytes`/credit) in the `24-bit` ACK field (max window `(2^24 - 1) x 256 = 4,294,967,040 bytes` `~4.0 GiB`); (b) `UEC` `CBFC` supports **`32` `VCs` per port** (`2x` InfiniBand's `16` `VLs`) and signals consumed credits via **`PCS` `CtlOS` `CP_Update`** messages after `LLDP` negotiation.
5. **Exercise 5:** (a) With a `256B` payload, single-hop `SUE-T` (`6B` compressed `AFH Gen 2` + `2B` EtherType + `8B` `RH` + `8B` CRC/FCS) is **`280 bytes`** (**`91.43%`** payload efficiency) vs two-hop (`12B` `AFH Gen 2`) at **`286 bytes`** (**`89.51%`** efficiency); (b) `ARM AXI 4.0` maps **`AR`, `AW`, `W` requests to `VC0`** and **`B`, `R` responses to `VC1`** (`5` channels total) vs `1` raw stream (`10-bit xPU + 2-bit VC`) on `FIFO`.
6. **Exercise 6:** (a) `8` stations x `4` lanes = **`32` lanes** x `200 Gbps` = **`6,400 Gbps` (`6.4 Tbps`)** per `xPU`; (b) `16 x 4B` sectors = **`64B` `TL` flit** (`2 x 32B` half-flits), `10 x 64B =` **`640B` `DL` flit** (`+ 8B` `CRC`), and `+ 40B` `FEC` = **`680B` wire unit** aligned `1:1` with `RS(544, 514)` `10-bit` `PCS` codewords (`4.0x` and `2.0x` faster FEC decode under `1-way` and `2-way` interleaving vs `4-way`); (c) **`GVA`** -> Source `MMU` (`PTE` + Address Handle) -> **`NPA`** (`10-bit ACC-ID`) -> `ULS` switch -> Destination Link `MMU` -> **`SPA`**.
