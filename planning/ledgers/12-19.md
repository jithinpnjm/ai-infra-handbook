## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) For `10.0 GB`/GPU across `8` GPUs (`80.0 GB` total), bounce-buffer staging generates `20.0 GB` `PCIe` + `20.0 GB` `DRAM` traffic per GPU (`160.0 GB` `PCIe` + `160.0 GB` `DRAM` across the node), whereas `GPUDirect RDMA` generates `10.0 GB` `PCIe` switch traffic + `0.0 GB` `DRAM` per GPU (`80.0 GB` `PCIe` + `0.0 GB` `DRAM` across the node); (b) transferring `10.0 GB` takes `1.60 s` at `6.25 GB/s` (`50 Gbps` staged) vs `0.20 s` at `50.0 GB/s` (`400 Gbps` `GDR`, an `8.0x` speedup).
2. **Exercise 2:** (a) `dma-buf` (kernel `5.15 >= 5.12`, OpenRM `-open`, `rdma-core 44 >= 34`, `large_bar1=True`); (b) `nvidia-peermem` (kernel `5.4`, proprietary driver, `peermem_loaded=True`, `large_bar1=True`); (c) `host-staging-fallback` (`large_bar1=False` blocks both paths); (d) `host-staging-fallback` (proprietary driver cannot use `dma-buf` and `peermem_loaded=False`).
3. **Exercise 3:** (a) At default `NCCL_NET_GDR_LEVEL=PXB`, `PIX` and `PXB` enable `GDR Write + Read`, while `PHB` and `SYS` disable both; (b) at `NCCL_NET_GDR_LEVEL=PHB` (default `NCCL_NET_GDR_READ`), `PIX`/`PXB` enable `Write + Read`, `PHB` enables `Write-only` (`Read` host-staged), and `SYS` disables both; (c) adding `NCCL_NET_GDR_READ=1` with `NCCL_NET_GDR_LEVEL=PHB` enables `Write + Read` on `PHB` (`SYS` still disabled).
4. **Exercise 4:** `SrcValid+ ReqRedir+ CmpltRedir+ UpstreamFwd+` on `0000:16:00.0` forces `P2P` TLPs upstream to the CPU Root Complex (`PHB`), downgrading a physical `PIX` path to `PHB` (`> PXB`) and disabling `GDR`; fix at runtime with `sudo setpci -v -s 0000:16:00.0 ECAP_ACS+0x6.w=0000` and persist in `BIOS` (`ACS` off) + `GRUB` (`intel_iommu=on iommu=pt` or `amd_iommu=on iommu=pt`).
5. **Exercise 5:** Switching `gdsio` from `-x 2` (`8.0 GB/s`, `1.25 ms`) to `-x 0` (`9.6 GB/s`, `1.00 ms`) increases throughput by `+20.0%`, reduces average latency by `-20.0%`, and cuts `10.0 GB` read time from `1.2500 s` to `1.0417 s` (`0.2083 s` saved); `use_poll_mode: true` only polls I/Os `<= poll_mode_max_size_kb` (`4 KiB`), so `1 MiB` (`1,024 KiB`) I/Os still use interrupts.
6. **Exercise 6:** (a) `2.0 TB` (`2,000 GB`) / `60 s` = **`33.33 GB/s`** minimum sustained write bandwidth (fits on `>= 1` `400 Gbps` = `50.0 GB/s` storage link, distributed across `256` nodes); (b) `14,000,000 / 50,000 = 280` `WebDataset` `.tar` shards (`1.0 GB` each), reducing `MDS` `stat()`/`open()` syscalls by a factor of **`50,000x`**.
