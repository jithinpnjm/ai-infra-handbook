## 4. One-Line Expected Exercise Solutions

1. **Exercise 1:** (a) ConnectX-7 NIC activates VFs via `echo 8 > /sys/class/net/ens1f0np0/device/sriov_numvfs` (up to `sriov_totalvfs`); (b) NVIDIA H100/A100 GPU activates VFs via `/usr/lib/nvidia/sriov-manage -e ALL`; time-sliced vGPU VFs share GPU SMs across VMs, whereas MIG-backed vGPU VFs map each VF to a hardware-isolated MIG GPU Instance (`GI`).
2. **Exercise 2:** Without IOMMU (`iommu_enabled=False`), a VF can issue unrestricted DMA reads against host physical RAM, and unverified firmware (`firmware_signed_and_verified=False`) risks a silicon rootkit; when IOMMU is active, any unauthorized VF DMA read is blocked in hardware by the IOMMU DMAR table and logged as a DMAR fault.
3. **Exercise 3:** SR-IOV VFs DMA directly between guest memory and hardware rings, bypassing the host OS kernel stack and `QEMU` proxy (`host_iostat_visible=False`); Gregg lists `ixgbe`, `ena`, `hv_netvsc`, and `nvme`; **Cilium** replaces `Calico`/`kube-proxy` `iptables` rule traversal with eBPF (`XDP`/`tc`/`cgroup`) + Hubble; and the **Token Bucket Filter (`tbf`)** qdisc implements `kubernetes.io/ingress-bandwidth` and `egress-bandwidth`.
4. **Exercise 4:** `1. Supply Chain` (Trivy, Cosign, `.safetensors`), `2. Kubernetes` (RBAC, PSA `Restricted`), `3. Network` (`NetworkPolicies`, BlueField DPU ARM firewall), `4. Hardware` (Secure Boot, signed drivers, IOMMU), and `5. Data` (Hopper Confidential Computing + `AMD SEV-SNP` / `Intel TDX`); BlueField DPUs run firewall enforcement on isolated ARM cores so a compromised x86 host OS cannot flush the firewall.
5. **Exercise 5:** Deleting `jupyter-research-1` wiped volatile RAM/VRAM evidence and left the exploited Jupyter CVE unpatched, allowing the attacker to return and deploy ransomware; the 6 forensic IR steps are `1. Cordon` (`kubectl cordon gpu-node-42`) -> `2. Network Quarantine` (Deny-All `NetworkPolicy`) -> `3. Capture RAM/VRAM, audit logs, image digest & DCGM` -> `4. Patch CVE globally` -> `5. Scorched-earth PXE OS re-image + GPU/ConnectX NIC signed firmware reflash` -> `6. Rotate all Secrets/Registry/S3 keys & uncordon`.
6. **Exercise 6:** Hardware/Boot (items `1, 2, 8`: Secure Boot, signed kernel/GPU drivers, IOMMU), Supply Chain/Models (items `3, 11`: CVE scanning, signed model artifacts/`.safetensors`), Kubernetes/Network/GPU Isolation (items `4, 5, 6, 7, 9`: RBAC, PSA `Restricted`, default-deny `NetworkPolicies`, MIG/dedicated GPU isolation, BlueField DPU), Confidential Compute (item `10`: Hopper CC + TEE), and Audit/IR (items `12, 13, 14`: centralized audit logs, quarterly IR drills, compliance assessments).
