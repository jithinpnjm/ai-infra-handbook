## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (The Terraform-to-Ansible Hand-Off `var.nodes` -> `local_file.inventory` -> `hosts.yml`):** `generate_ansible_inventory_from_tf_nodes()` validates node roles, assigns deterministic IPs (`172.28.0.10 + i`) and ports (`2200 + i`), and renders `ansible/inventories/lab/generated/hosts.yml` grouped by `login`, `controller`, and `gpu`; `generated/` is gitignored so Terraform remains the single source of truth for node existence.
2. **Exercise 2 (Swapping Infrastructure Backends `nodes_docker` vs. `nodes_gcp`):** Because `nodes_docker` (Path A) and `nodes_gcp` (Path B) expose the exact same input variables (`cluster_name`, `nodes`, `ssh_public_key`) and `output "nodes"` map structure, switching from local Docker containers to cloud VMs requires zero changes to `ansible/playbooks/site.yml` beyond setting `gpu_tools_stub: false`.
3. **Exercise 3 (Ordered Cluster Configuration `site.yml` and Hardware Stubbing `gpu_stub`):** `site.yml` runs `base_os` on `all` (populating `hostvars`), `gpu_stub`/`nvidia_driver` + `node_validate` on `gpu` (`serial: ['34%', '100%']`, `max_fail_percentage: 0`), `monitoring` + `munge_slurm` on `controller`, and `munge_slurm` + `node_validate` on `gpu`; `render_stub_nvidia_smi_list()` emulates `nvidia-smi -L` and CSV queries per node's `gpu_count`.
4. **Exercise 4 (End-to-End Behavioral Verification `playbooks/verify.yml`):** `verify_cluster_end_to_end()` checks SSH/chrony clock sync, `nvidia-smi -L` count == `gpu_count`, `:9100`/`:9400` exporter endpoints, Prometheus `/api/v1/targets` all `up`, and Slurm `sinfo` `idle` + `srun -N3 hostname`.
5. **Exercise 5 (The Unified CI/CD Pipeline `ci/lab-pipeline.yml`, Idempotency Gate, and Dual-Layer Drift Detection):** The pipeline runs `static` checks (`terraform fmt/validate`, `yamllint`, `ansible-lint`, `gitleaks`), applies Terraform, runs `site.yml` twice asserting `changed=0` on the second run, runs `verify.yml`, and always runs `terraform destroy` (`if: always()`); nightly cron runs `terraform plan -detailed-exitcode` and `ansible-playbook --check --diff`.
6. **Exercise 6 (Day-2 Operations: Scale-Out, Safe Scale-In, Canary Upgrades, and Munge Key Rotation):** Add `gpu04` in `var.nodes` and run `site.yml`; remove `gpu03` by draining in Slurm first, removing from `var.nodes`, and updating `slurm.conf`/Prometheus; and rotate the Vault-encrypted `munge.key` (`0400`, `no_log: true`, `diff: false`) across controller and workers via handlers.
