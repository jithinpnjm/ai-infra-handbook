## 4. One-Line Expected Exercise Solutions

1. **Exercise 1 (OpenSSH `StrictModes`):** (a) **Accepted** (`0750` `~`, `0700` `~/.ssh`, `0600` `authorized_keys` and `id_ed25519`); (b) **Rejected** (`ssh_dir_too_open_must_be_700` and `authorized_keys_group_or_world_writable`); (c) **Rejected** (`home_dir_group_or_world_writable`); (d) **Rejected** (`private_key_unprotected_must_be_600_or_400`).
2. **Exercise 2 (`rsync` Trailing Slash vs `scp -r`):** (a) `rsync -a data/ gpu01:/scratch/data` writes `/scratch/data/a.pt` and `/scratch/data/b.pt`; (b) `rsync -a data gpu01:/scratch/data` writes `/scratch/data/data/a.pt` and `/scratch/data/data/b.pt`; (c) because `/scratch/data` already exists, `scp -r data gpu01:/scratch/data` nests a duplicate subdirectory at `/scratch/data/data/`.
3. **Exercise 3 (SSH Port Forwarding `-L`, `-R`, `-D`):** (a) `-L 6006:localhost:6006 gpu01` listens on `local_client:6006` and forwards via `gpu01` to `gpu01`'s `localhost:6006`; (b) `-R 9000:localhost:8000 bastion` listens on `bastion:9000` and forwards back to `local_client:8000`; (c) `-D 1080 bastion` opens a local SOCKS proxy on `local_client:1080` egressing through `bastion`.
4. **Exercise 4 (`~/.ssh/config` First-Match-Wins):** For `ssh gpu01`, the first stanza locks in `HostName = 10.20.0.11` and `User = alice` while later matching stanzas supply `ProxyJump = bastion` and `ServerAliveInterval = 30`; for `ssh gpu02`, `Host gpu*` matches first, setting `User = clusterdefault` and `ProxyJump = bastion` alongside `ServerAliveInterval = 30`.
5. **Exercise 5 (`--bwlimit` and `-avhn --delete`):** (a) Saturating an asymmetric uplink queues outgoing TCP `ACK` packets required by incoming downloads, stalling the connection; `--bwlimit=10000` caps the upload at `10,000 KB/s` (`~10 MB/s`); (b) `--delete` deletes any destination file absent from the source, so running `-avhn --delete` (`--dry-run`) first prevents wiping the destination due to a trailing-slash mistake or an unmounted empty source.
6. **Exercise 6 (IPMI SOL and Safe Config Editing):** (a) `ipmitool -I lanplus -H bmc-gpu01 -U admin -E sol activate` (disconnect with `~.`); (b) (1) backup `cp -a /etc/ssh/sshd_config /etc/ssh/sshd_config.bak.$(date +%F)`, (2) edit with `sudoedit /etc/ssh/sshd_config`, (3) review `diff -u`, (4) validate syntax `sudo sshd -t`, and (5) reload `sshd`.
