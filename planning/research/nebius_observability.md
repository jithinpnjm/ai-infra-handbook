2. https://docs.tokenfactory.nebius.com/ai-models-inference/observability.md [official]. Metrics only for Dedicated Endpoints. Traffic, latency (p50/p90/p99, TTFT streaming-only), autoscaling (active replicas, active GPUs, GPU utilisation avg and busiest), error rate by status code. Not for billing reconciliation. Metrics collected in region, stored in eu-north. Project-scoped, deleted with project. Billing Manager has no access.
3. .../observability-api-integrations.md [official]. Prometheus federate endpoint read.monitoring.api.nebius.cloud, path /projects/<id>/service-provider/prometheus/federate, bearer static API key, scrape >=15 s, Prometheus 2 vs 3 config differ. Grafana data source URL .../service-provider/prometheus.
4. .../dedicated-endpoints/lifecycle-and-status.md [official]. Lifecycle: Starting, Updating, Running, Warning, Stopping, Stopped. Readiness: Not ready, Partially ready, Ready. Contact support after 3 hours of Warning or Partially ready. Docs say "Warning" in one list and "Error" in a table (discrepancy).
5. .../dedicated-endpoints/capacity-and-scaling.md [official]. No formal SLA unless contract. No mechanism holds previous GPUs after a stop. Min replicas reserved and non-preemptible while running. Burst not guaranteed.
6. .../ai-models-inference/rate-limits.md [official]. 15-minute windows, x1.2 at >=80% usage, /1.5 at <=50%, ceiling 20x base. 429 plus Retry-After. x-ratelimit-* headers incl. dynamic-scale and over-limit.
7. https://nebius.com/blog/posts/incident-post-mortem-analysis-us-central1-service-disruption-on-august-19 [vendor/post-mortem]. Detailed in chapter. Key: no alert on temperature; first actionable alert 10:15 UTC consequence-level; regional monitoring depended on in-region components; health check misreported region healthy for ~7 min; Token Factory partial/full unavailable from ~10:37, recovered 20:25; status page opened 10:43; direct notifications 12:29-12:41.
8. https://nebius.com/blog/posts/incident-post-mortem-analysis-eu-north-1-service-disruption [vendor]. 2026-02-26 power event; scope-understanding slower than desired; plans monitoring across power, compute, storage.
9. https://docs.nebius.com/legal/sla [official]. Published 2026-10-22, effective 2026-11-02. Credit not cash, claim via console within 14 days of period end, cap at service cost, 8 h/period maintenance and emergency works exclusion, 30 days notice for cluster upgrades, quotas exclusion, compensation within 30 days (60 if disputed). Reporting Period not defined on the page.
10. https://docs.nebius.com/legal/sla-levels/compute [official]. VM 99.50%, credits 10/15/30%. Unavailability = missing GPUs, NVLink, fabric, boot disk, external network. Degraded bandwidth or latency without loss of connectivity is excluded. I did NOT find a Token Factory SLA page.
11. https://docs.nebius.com/overview/support.md [official]. Table 1 (customers before 2026-11-01): Critical 30 min, High 60 min, Medium 4 h, Low 1 business day. Table 2 (others, from 2026-11-02): Medium 4 h and Low only. Check status page before ticket; attach CLI --debug output.
12. https://docs.nebius.com/compute/monitoring/virtual-machines.md [official]. DCGM_FI_* GPU metrics, IB counters (link downed, error recovery, port errors, discards), 5-10 min delay for new VMs, dashboard refresh 15 s, throttle bitmask (72 = 0x40+0x8). No XID metric listed.
13. https://nebius.com/blog/posts/how-we-build-reliable-clusters [vendor]. Passive checks (ECC, XID/SXID, IB counters, NCCL timeouts), active checks (DCGM level 2/3, NCCL, ib_write_bw), auto-drain in seconds, ~12 min MTTR average, Slack channel notifications. Context is Soperator/Managed K8s clusters, not Token Factory.
14. https://nebius.com/blog/posts/improving-ai-cluster-observability (2025-05-15) [vendor]. Grafana dashboards, custom metrics and logs ingestion, Audit Logs preview. Names Grafana only.
15. https://docs.nebius.com/observability and /audit-logs [official]. Alerts, metrics, logs, tracing, in preview; Grafana and Prometheus named integrations; audit logs exportable to Object Storage; retention not stated.
16. https://docs.tokenfactory.nebius.com/other-capabilities/billing-new.md [official]. Usage tab by project, service, product, region. No usage API or per-key breakdown mentioned.
