## github.com/nebius/api [source-code]
- README.md: .proto files for gRPC API. Endpoint form `{service-name}.api.nebius.cloud:443`, service-name = `option (api_service_name)`. TokenExchangeService -> tokens.iam. OperationService has no endpoint of its own; use the initiating service's endpoint. Bearer auth `Authorization: Bearer <IAM-access-token>`.
- Service account flow: JWT RS256 with kid, iss, sub, exp (short, e.g. 5 min); exchange via TokenExchangeService/Exchange or HTTPS POST auth.eu.nebius.com/oauth2/token/exchange (RFC 8693). Repeat before expires_in.
- Update is full-replace, not patch. Fields unknown to client are protected by Reset Mask, header `X-ResetMask`; SDKs manage it. Not Google FieldMask. Syntax `a, b.c, l.*.m`. Clear list/map by naming it in the mask.
- Operations: mutating methods return nebius.common.v1.Operation. Done when `status` set; null status = in progress; finished_at set when done. No concurrent operations on same resource: may error or first aborted. Ongoing operations never deleted; completed may be deleted per service retention.
- Errors: google.rpc.Status, details may hold ServiceError (BadRequest, QuotaFailure, TooManyRequests...) with retry_type.
- Idempotency: header `X-Idempotency-Key`, random alnum/dash, UUID preferred, ignored for Get and List.
- endpoints.md lists services by endpoint (e.g. compute.api..., cpl.iam.api..., audit.api...). Not found: published API rate limit numbers.
- common/v1/operation.proto: Operation fields id, description, created_at, created_by, finished_at, request (Any), request_headers (map, lowercase names, essential headers like x-resetmask), resource_id (empty if many/none), status (code subset OK, CANCELLED, PERMISSION_DENIED, RESOURCE_EXHAUSTED, FAILED_PRECONDITION, ABORTED, INTERNAL), progress_tracker, progress_data.
- common/v1/operation_service.proto: Get, List(resource_id, page_size 1..1000, page_token) only; read only.
- common/v1/error.proto: ServiceError{service, code, oneof details: BadRequest, BadResourceState, ResourceNotFound, ResourceAlreadyExists, OutOfRange, PermissionDenied, ResourceConflict, OperationAborted, OperationConflict, TooManyRequests, QuotaFailure(violations quota, limit, requested, region), NotEnoughResources, InternalError(request_id, trace_id)}, retry_type UNSPECIFIED/CALL ("just retry the failed call")/UNIT_OF_WORK ("retry whole logic before call")/NOTHING.
- common/v1/metadata.proto: ResourceMetadata id (IDENTIFIER), parent_id (required), name, resource_version ("Service allows zero value or current"), created_at/updated_at OUTPUT_ONLY, labels. GetByNameRequest where name unique within <type, parent_id>.
- annotations.proto: FieldBehavior IMMUTABLE, IDENTIFIER, INPUT_ONLY, OUTPUT_ONLY, MEANINGFUL_EMPTY_VALUE; ResourceBehavior MOVABLE, UNNAMED, IMMUTABLE_NAME; `sensitive` and `credentials` field options mask in logs.
- compute/v1/instance_service.proto: Get, GetByName, BatchGet, List, Create, Update, Delete, Start, Stop, ListOperationsByParent. List pattern: parent_id, page_size, page_token -> items, next_page_token. Requests take metadata (parent project) + spec.
- iam v1 services at cpl.iam: ServiceAccountService, GroupService, GroupMembershipService, AccessPermitService (resource_id+role, both IMMUTABLE; subject is parent), FederationService, FederatedCredentialsService (OIDC provider -> impersonate service account), AuthPublicKeyService (authorized keys: Activate/Deactivate/Delete), AccessKeyService v1 and v2, StaticKeyService (Issue, Revoke), TenantService (Get, List only), ProjectService, TokenService, TokenExchangeService (tokens.iam). ExchangeTokenRequest has `credentials` annotated subject_token, scopes, audience, actor_token.
- quotas/v1: QuotaAllowanceService at quota-dispatcher.billing-cpl; Create "if the quota already exists, its value is replaced".
- audit/v2: AuditEventService at audit.api; List requires tenant id, filters on action, subject, resource, service.name, status.
- Own parser (c35_proto_catalog.py) over all 226 .proto at that commit: 90 services, 487 methods, 210 return a common Operation (v1 or v1alpha1). Create 50+ Delete 50+ Update 45+ for v1; only one Create/Update/Delete-named method does not return an Operation (maintenance v1alpha1 Update).  Note OperationService.Get itself returns an Operation but is a read: parser excludes it.

## docs [official]
- cli/install: `curl -sSL https://artifacts.nebius.cloud/cli/install.sh | bash`, `nebius version`; Ubuntu and macOS; profile per project.
- cli/configure, no-browser: `nebius profile create --endpoint api.nebius.cloud --service-account-id --public-key-id --private-key-file --profile --parent-id`; `nebius iam auth-public-key generate --service-account-id --output file [--expires-at]`; CI: write secret to ~/.nebius/$SA_ID-credentials.json.
- cli reference (compute instance create): flags `--async` (returns operation id; otherwise waits and returns the resource), `--format yaml|json|jsonpath|table|text`, `--timeout` default 1m0s, `--retries` default 3 (1 disables), `--per-retry-timeout` default 20s, `--auth-timeout` 15m, `-I/--impersonate-service-account-id`, `--debug`, `--no-progress`.
- cli/exit-codes: 1-10 general; 11-20 gRPC errors for target call (11 CANCELLED, 12 DEADLINE, 13 NOT_FOUND, 14 ALREADY_EXISTS, 15 PERMISSION_DENIED, 16 RESOURCE_EXHAUSTED, 17 FAILED_PRECONDITION, 18 ABORTED, 19 OUT_OF_RANGE, 20 UNAVAILABLE); 21-25 service errors (BadResourceState, ResourceConflict, TooManyRequests 23, QuotaFailure 24, NotEnoughResources 25); +40 for "extra call" (wait/get after). 7 auth error, 3 validation.
- cli/update: patch default with params; full default with --file/stdin; `--clear-mask`.
- CLI source: no nebius/cli repo in the org list (checked 2026-11-11); behaviour taken from docs only.
- iam/overview: tenant contains projects, groups, users, federation, quotas, audit logs; project per region at signup; tenant cannot be deleted; project isolates resources.
- iam access-tokens: token valid 12 hours. Static keys up to three years. Access keys (AWS-compatible, Object Storage) have optional expiry. Authorized keys used for CLI and Terraform; `--expires-at` optional.
- groups: default groups auditors, viewers, editors, admins; custom groups + access permits at tenant, project or resource level.
- iam/wif: STS https://sts.nebius.com /oauth2/token/exchange RFC 8693; workload exchanges its access token for an OIDC ID token.
- overview/quotas: per region, per project; only admin group can change; automatic quota reduction with email and usually two days grace; not below defaults. compute quotas: default vs full tier, VMs count while stopped.
- grpc-api/errors and rest-api/errors: code tables. RESOURCE_EXHAUSTED = quotas exhausted (HTTP 429). DEADLINE_EXCEEDED: a mutating request may complete although the response was late. ABORTED usually resource-version mismatch (409). REST generated from the same protos, https://api.nebius.cloud, OpenAPI spec at /openapi.json (llms.txt).
- audit-logs: in preview; event has request_id, idempotency_id, trace_id, response.status_code, status STARTED/DONE/ERROR; data-plane quota 1000 events/s/region, excess dropped; export to Object Storage.
- terraform-provider auth: SA via `service_account` block or NEBIUS_IAM_TOKEN; user credentials win if both present.
- Token Factory dedicated endpoints control plane: separate REST `https://api.tokenfactory.nebius.com/v0/dedicated_endpoints` (templates, create, PATCH, list, DELETE); data plane regional base URL. Sources do not say it is built on the gRPC API. Token Factory rate limits: dynamic, 15-minute windows, x1.2 at >=80% average use, /1.5 at <=50%, ceiling 20x base; 429; headers x-ratelimit-*; x-ratelimit-over-limit: yes.

## SDKs [source-code]
- gosdk: README says mutating methods return Operation; `Wait` polls; service account auth recommended, token refreshed in background; IAM token not refreshed by SDK. operations/options.go: DefaultPollInterval 1s, DefaultPollErrorBackoffMax 30s, jitter 0.2; Wait: sleeps interval then polls; on retriable poll error exponential backoff with jitter; resets after successful poll; ends when ctx done. conn/retries.go: retriable = ServiceError.retry_type CALL true, NOTHING or UNIT_OF_WORK false, else gRPC ResourceExhausted or Unavailable, Cloudflare-style 520-529 mapped to Unknown, network timeout/dial refused/reset/DNS; never retry context canceled/deadline. options.go: default retries three attempts, 1/3 of timeout per attempt, no cooldown or backoff; WithTimeout default 1 minute; WithAuthTimeout default 15 min. conn/idempotency.go: header constant, interceptor adds random UUID when none; in sdk.go the idempotency interceptor is chained before the retry interceptor [inference: so one key covers retries]. auth/cache.go: refresh at 0.9 of token lifespan, background.
- pysdk: default 60 s overall, 20 s per retry; operation wait(interval=1,...) with poll_ timeouts; NEBIUS_IAM_TOKEN, NEBIUS_PROFILE env; idempotency interceptor adds UUID4 to x-idempotency-key; RequestError carries request id and trace id ("save request ID and trace ID for support").
- js-sdk: 3 total attempts default; Operation.wait() rejects with OperationError; `filter()` iterates pages until token empty.

## Terraform provider [source-code + official]
- Built on the Go SDK (changelog: "Update Nebius Go SDK to v0.2.92"). Generated create code: service.Create then op.Wait. service/resource.go: after create, ID is saved to state even if error; read after create with 5 s ReadOnCreateTimeout. Import by resource ID via SUPPORT.md; `import` block and `-generate-config-out`; import cannot recover write-only values. Drift and node group facts reused from 20.24.
