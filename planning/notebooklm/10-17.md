## 2. Outline to follow
(taken from the current draft; keep this order, improve the depth)
1. Overlapping Kernel Execution and 3-Way Data Transfers with CUDA Streams | topics: Concurrent kernel dispatch and host interleaving (`Figure 11-1`); Three-way `H2D` / `Compute` / `D2H` overlap, hardware limits (`128` grids), and saturation contention (`Figure 11-2`)
2. The Stream-Ordered Memory Allocator (`cudaMallocAsync`) and LLM Scratch Pools | topics: Tuning the device memory pool (`cudaMemPoolSetAttribute` & `PYTORCH_ALLOC_CONF`); Three LLM workloads that depend on `cudaMallocAsync` (`Figure 11-3`)
3. Default vs. Explicit Streams, Per-Thread Default Streams (`PTDS`), Events, and Host Callbacks | topics: Comparing Legacy Default Stream (`stream 0`), `PTDS`, and Explicit Non-Blocking Streams (`Figure 11-4`); Fine-grained cross-stream events (`Figures 11-5 to 11-7`) and the `cudaLaunchHostFunc` deadlock rule
4. Two-Layer Pipelining: Intra-Kernel Warp Specialization + Inter-Kernel CUDA Streams + Thread Block Clusters | topics: Layering dual-pipeline 3-role warp specialization with CUDA streams (`warp_specialized_two_pipelines`); Combining Thread Block Clusters, Warp Specialization, and CUDA Streams (`launch_warp_specialized_cluster_pipeline_multistream`)
5. Multi-GPU Compute, P2P (`cudaMemcpyPeerAsync`), `NCCL` Ring All-Reduce, `NIXL`, and `CUDA Graph` Stream Capture | topics: Multi-GPU pipeline parallelism (`cudaMemcpyPeerAsync`) and data parallelism (`NCCL` & `NIXL`, `Figure 11-8`); Capturing a multi-stream iteration into a `CUDA Graph` (`cudaStreamCaptureModeGlobal`)
6. Programmatic Dependent Launch (`PDL`) and Combining `PDL` + Thread Block Clusters + Warp Specialization | topics: Overlapping Kernel B's prologue with Kernel A's epilogue in the same stream (`Figure 11-9`); Combining `PDL` + Thread Block Clusters (`__cluster_dims__(2,1,1)`) + Warp Specialization (`primary_gemm` → `secondary_gemm`, `Figures 11-10 & 11-11`)
7. Commands and Configurations That Matter | topics: Enable Per-Thread Default Streams (`PTDS`), compile `PDL` + Cluster kernels, and trace multi-stream overlap in `nsys` (untested here)
8. How It Fails: Six Multi-Stream, Allocator, Callback, and `PDL` Failure Modes
9. Hands-On Lab: Verify 3-Way Stream Overlap, Stream-Ordered Pools, Dual-Pipeline Warp Specialization, Cluster Streams, and `PDL`
