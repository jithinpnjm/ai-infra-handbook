## Worst 15 files with one example each

1. 12.21 storage-networks: "Network interface card A connects to leaf1, and network interface card B connects to leaf2." A human would say what the diagram shows in two sentences: each server has two NICs, each going to a different leaf, so one failure does not cut storage. Also "Fabric B" is described twice.
2. 12.16 nccl-topology: "This one covers path scoring and the NVLink versus SYS step penalty." Name the question in plain words ("Which path costs more, and by how much?"). All six items share the same opening and shape.
3. 04.05 inventory: "First, how `keyed_groups`, `groups`, `compose`, `filters` and `cache` work in the cloud and NetBox plugins." Teach one idea per exercise.
4. 04.09 real-playbook: exercise 4 lists five systemd hardening options in one sentence. Pick one, say what attack it blocks, link the rest.
5. 04.16 containers-cloud-network: "(a) Explain how you would use `docker_container` with `device_requests` for GPUs and `comparisons`..." Split into separate small tasks.
6. 04.20 terraform-modules: gotcha 2 stacks `aws_security_group_rule`, port 12345, `module.webserver_cluster.alb_security_group_id` in one paragraph. Tell the short story: two rules fight and overwrite each other.
7. 12.03 rocev2: "Synchronized elephant flows... collide at six distinct Clos fabric congestion points." Name the one collision that matters and give a small example.
8. 12.04 pfc-ecn-dcqcn: the XOFF paragraph stacks frame size, vector value and quanta. Say a pause frame tells the neighbor to stop one traffic class, then give the hex values in a table.
9. 12.15 nccl-collectives: "Those collectives include AllReduce, ReduceScatter, AllGather, Broadcast, Reduce, and AllToAll." Introduce one collective with a worked picture first.
10. 12.22 telemetry-kpis: "Compute the fixed IFA header bytes, the metadata stack bytes, the total overhead, and the tagged packet size." Ask for one result per step.
11. 04.17 gpu-nodes: the GPU tuning paragraph runs about 150 words of `nvidia-smi` flags. Use a table of setting, command, when needed.
12. 04.21 loops-lifecycle: exercise 5 chains six lifecycle keywords plus two deployment patterns. One keyword per exercise.
13. 04.10 debugging: "`stdout_callback = yaml` shows multi-line values clearly... `callbacks_enabled = timer, profile_tasks, profile_roles` adds timing." Put the settings in a short config block.
14. 04.06 playbooks: exercise 2 lists 14 modules in one sentence. A human would pick three and explain why.
15. 12.05 dcb-qos: "(`10% + 10% + 50% + 30% = 100%`)." Say the four class weights add up to a full link, in words.

## Other flags (note only)

Possibly wrong or inconsistent facts:
- 04.23: "15-25 minutes (795.63s)". 795 seconds is about 13 minutes.
- 04.16: "RFC 7938 BGP unnumbered". RFC 7938 covers BGP in data centers; unnumbered interfaces come from RFC 5549.
- 12.17: points to "Chapter 12.14 on GPUDirect RDMA", but that chapter is 12.19 in this sample.
- 12.01: Gloo fallback "slow down fifty-fold" and a "ten-fold" per-GPU throughput drop need sources.
- 12.15: "Below 37.24 MiB, Tree... At 1 MiB on 72 GPUs, Tree runs 4.27x faster" looks like model output, not a measurement.
- 12.18: ">6.3x" ratio of GPU faults to network faults is not backed by shown network counts.
- 12.20: "differ by roughly a factor of N - 1" is a risky generalization.
- 04.15: a quoted "one-bit decision" line has no attribution.

Style patterns seen across the sample:
- Exercise lists in both parts: "explain three things; First, Second, Third", stacked function names, code formatting and book-chapter pointers in one sentence.
- Semicolon chains are rare; parenthesis stacking is common in 04.05, 04.09, 04.16 and 12.05.
- Code formatting on ordinary words: mostly fine, but `Nexus`, `Artifactory`, `Terratest` and `perftest` are formatted as code in places.
- Acronyms undefined at first use: GRH, ETH, RETH, DETH (12.06); AN (12.20); PFE and SerDes (12.10); NNHN and sDLB (12.14); EE (04.15).
- Openings "Picture a..." and "Suppose..." recur very often and sound templated.
- Stock phrases: "deterministic" (12.01, 12.18, 12.24), "massive" (12.01), "rigorous" (12.23), "innocent workloads" (12.03, 12.04).
- Prose paragraphs usually read better than exercise lists; the two parts' weakest text is the exercise blocks.
