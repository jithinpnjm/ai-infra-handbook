# 20.2 The role in one page: the job posting line by line
Words: ~7000 | Read time: 47 | File: /Users/jithinpjoseph/Documents/GitHub/ai-infra-handbook/docs/part-20-nebius-sre-interview/02-the-role-in-one-page-the-job-posting-line-by-line.md
One-line purpose: Turns the Token Factory SRE posting into numbered lines (R1-R8, Q1-Q7), maps each to chapters, and gives a self-assessment table plus a gap-tracker script that ranks what to study.
Beginner friendly: partly. The posting-to-chapter tables and self-assessment are plain. Section 7 is a Python script with dataclasses, regex and pytest, and section 6 uses inference-serving terms (prefill, decode, KV cache, liveness probe). Read first: 3.4 (classes and dataclasses) and 3.5 (errors, files, text) before section 7; 17.1 (metrics, logs, traces) and 5.3 (Kubernetes architecture) before the tables in sections 2 and 4; 15.1 (anatomy of an inference request) and 15.2 (batching and the KV cache) before section 6.
Nebius rounds served: R1 (Linux/networking/Python scripting, self-assessment of console skills), R2 (scripting, DevOps, Kubernetes troubleshooting), R3 (design: autoscaling, routing, capacity), R4 (project deep dive: "which of these have you done yourself").
Chapter verdict: READ-SECTIONS: sections 2 and 4 (line tables), 5 (template), 6 (public Token Factory facts), 9 (gaps), the four "How to answer out loud" questions and Scenarios 1-2; section 7 code is OPTIONAL unless you want the Python practice; skip the test code except as a model for pytest.

Hands-on to do:
1. Fill the self-assessment template (`code/part20/c02_assessment_template.md`) in one sitting without looking things up; leave any row you cannot evidence blank.
2. Run the tests: `cd code/part20 && python3 -m pytest -q test_c02_gap_tracker.py` (the chapter states 17 tests pass; the test file is referenced in the chapter, so confirm it exists before running).
3. Run the tracker on your filled copy: `python3 -I c02_gap_tracker.py my_assessment.md` and take the top three skills into chapters 20.20, 20.23, 20.19 or whichever the output names.
4. Optional static check: `python3 -I tools/check_code_files.py code/part20` (the chapter reports 0 problems).

Likely interview questions from this chapter:
- Which of these responsibilities have you done yourself, and what was the scale?
- You have not run vLLM in production. Why should we consider you?
- How would you tune Kubernetes autoscaling to get more out of GPUs?
- What do you know about Token Factory, and what do you not know?
- What would you do in your first 90 days in this role?
- Where are you weakest against this posting?
