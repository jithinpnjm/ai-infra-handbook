# 4.5 Ansible inventory: hosts, groups, dynamic inventory and variables
Words: ~10,100 | Read time: 68 min | File: docs/part-04-automation/05-ansible-inventory-hosts-groups-dynamic-inventory-and-variables.md

Hands-on to do:
- On a 3-host lab, run `ansible-inventory -i inventories/prod --graph --vars`, then `--host <name>`, then `--list --yaml`. Read the merged value for one host.
- Reproduce the collapse trap: list three Vagrant hosts as `127.0.0.1:2222`, `127.0.0.1:2200`, `127.0.0.1:2201` with no aliases, then run `ansible <group> --list-hosts` and count. Fix it with aliases and `ansible_port`.
- Set `nccl_env` in `group_vars/gpu` with three keys, then a single-key override in `host_vars/<host>`. Check it with `ansible-inventory --host`. Fix it with `combine(recursive=True)`.
- Run `ansible 'gpu:&rack_r01:!gpu_a100' -i inventories/prod --list-hosts` and confirm that it matches the hosts you expect before any real change.
- Add a CI gate: `ansible-inventory -i inventories/prod --list > /dev/null`, plus an `assert` play that fails when a host lacks `rack` or `gpu_count`.

5. Static inventory versus dynamic inventory: how would you source it from NetBox or a cloud?
6. What is the difference between `group_by` and `add_host`?
