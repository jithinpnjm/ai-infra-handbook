# 3.7 Building APIs and microservices with FastAPI
Words: ~12150 | Read time: ~80 min (full read) | File: docs/part-03-python/07-building-apis-and-microservices-with-fastapi.md
One-line purpose: Teaches FastAPI end to end for infrastructure and inference services: ASGI and the event loop, routing and validation, dependency injection and lifespan, error handling and middleware, auth (authn vs authz), databases, background jobs and SSE streaming, testing, and Kubernetes deployment and observability.
Beginner friendly: partly. Assumes 3.1 to 3.4 (classes, typing, pydantic basics), 3.6 (asyncio and blocking calls) and HTTP basics from 2.10. The auth and database sections carry a lot of book code; for this reader, skip the framework-specific detail and keep the concepts.
Nebius rounds served: R1 (small API or CLI-to-API questions, testing), R2 (Kubernetes probes, graceful shutdown, service debugging), R3 (job-submission API design, streaming, capacity and backpressure), R4 (own project's API layer, auth, deploy)
Chapter verdict: READ-SECTIONS. A rusty Senior SRE who knows HTTP and Kubernetes can skip the quickstart code, the Jinja2 and NoSQL material and the book-digest checkpoints. Read ASGI and async-vs-def, dependency injection with `yield` and overrides, the 202-plus-queue job pattern, SSE with disconnect handling, authn vs authz and BOLA, the Kubernetes probe and shutdown section and the common-mistakes list (about 35-40 min of the 80).

Notes on the chapter text (verify before quoting):
- Pool rule: section 8 says `workers x pool_size <= max_connections`, while checkpoint 10 says `replicas x workers x (pool_size + max_overflow)`. The second is the safer count, because overflow connections also use the database.
- Section 11 Dockerfile sets `--forwarded-allow-ips=*`, while checkpoint 17 says never expose `*` to the internet. Restrict it to the proxy CIDR in real deployments.
