Hands-on to do:
- `python3 code/part03/python_core_fundamentals_lab.py` (the chapter's self-check lab; confirm the file exists in the repo before you rely on it).
- Mutable default: write `def add_node(ip, nodes=[])`, call it twice, then fix it with `nodes=None`. Add a plain `assert` that two calls do not share state.
- Object identity: `a = [1]; b = a; b.append(2); print(a)`, then `copy.copy` vs `copy.deepcopy` on a dict of lists, then `x = 257; y = 257; x is y`.
- Floor vs truncation: `python3 -c "import math; print(5 // -2, math.trunc(5/-2), int(-2.5), round(2.5))"`.
- Generator memory test: generate 5 million lines with a generator pipeline, then measure with `/usr/bin/time -v` (on macOS use `/usr/bin/time -l`) against `readlines()`.
- Retry with `for ... else`: write it against a fake flaky function, then time it with `python3 -m timeit`.
