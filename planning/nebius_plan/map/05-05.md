Hands-on to do:
- Raw API on a kind or kubeadm cluster: `kubectl proxy --port=8001 &`, then `curl -s localhost:8001/api/v1/namespaces/default/pods | jq '.items[].metadata.name'` and `kubectl get --raw /apis | jq '.groups[].name' | head`.
- Force a 409: `kubectl create configmap cm-test --from-literal=a=1`, then `kubectl get cm cm-test -o yaml > /tmp/old.yaml` (use your scratch folder instead), edit a value with `kubectl patch`, and then `kubectl replace -f` the stale file. The replace fails with a conflict. Compare with `kubectl patch`, which succeeds.
- Field ownership: `kubectl apply --server-side --field-manager=a -f cm.yaml`, then change the same field with `--field-manager=b`, and read `kubectl get cm cm-test -o yaml --show-managed-fields`.
- RBAC check: `kubectl auth can-i create pods --as=system:serviceaccount:default:<sa>` and `kubectl auth whoami`.
- On a kubeadm control-plane node only (not a Mac): run the etcdctl block in section 7 with `endpoint status -w table` and `alarm list`. Then `etcdctl snapshot save` and `etcdutl snapshot status` on the saved file.
