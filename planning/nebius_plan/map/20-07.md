# 20.7 The console round: text tools, systemd and everyday operations
Words: 11444 | Read time: 76 | File: docs/part-20-nebius-sre-interview/07-the-console-round-text-tools-systemd-and-everyday-operations.md
One-line purpose: Teaches how to answer timed Linux console tasks (log parsing, percentiles, systemd, signals, cron, logrotate, disk/user audits, transfers, safe bash) on a GNU box, out loud.
Beginner friendly: partly. Assumes you can already read a pipeline. Read first: Part 1 `04-text-processing-essentials-grep-sed-awk-find-xargs-sort.md`, `08-processes-signals-and-job-control.md`, `09-shell-scripting-that-survives-production.md`, `15-systemd-units-targets-timers-journald.md`, `16-logging-time-synchronisation-cron-and-batch-jobs.md`. Also 20.3 (triage order) and 20.4 (deleted-but-open files) for context.
Nebius rounds served: R1 (Linux console, primary), R2 (process/PID 1/SIGTERM/systemd restart loops as DevOps troubleshooting)
Chapter verdict: MUST-READ-FULL. The chapter is the R1 console round itself, and the 12 tasks are the practice set. Skip only the Sources section after a first pass.

Hands-on to do:
1. `python3 code/part20/c07_make_fixtures.py`, then `for f in code/part20/c07_t0*.sh code/part20/c07_t1[0-2]*.sh; do bash $f; done` and compare with the chapter outputs (paths are relative to the book's code folder, not the docs folder).
2. Time-box Task 4 (percentiles) and Task 1 (top talkers) to 4 minutes each, then add a cross-check with a second method (for example awk arrays instead of sort | uniq -c).
3. `bash -c 'set -o pipefail; yes | head -1 >/dev/null; echo st=$?'` should print st=141. Then rewrite with awk NR<=1 and confirm 0.
4. `docker run -d --name t ubuntu:24.04 sleep 1000`, then `docker stop -t 4 t` (expect ~4 s, SIGKILL), then repeat with `--init` (expect ~0.1 s). This is the PID 1 lesson from section 6.
