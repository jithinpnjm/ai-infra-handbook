# 1.27 Cloud computing and virtualization internals for Linux engineers
Words: 10984 | Read time: ~73 | File: docs/part-01-linux/27-cloud-computing-and-virtualization-internals-for-linux-engineers.md

One-line purpose: Gives the cloud vocabulary and the three ways to virtualise a machine (VM, container, microVM), then shows how to find software-imposed limits (CPU quota, cpuset, shares, memory, I/O) and observe a container or VM when you cannot see the whole machine, with the AI-cloud GPU decisions on top.

Beginner friendly: partly. Section 1 vocabulary (IaaS/PaaS/SaaS, instance, region, tenant) is easy; the CPU shares vs quota, cgroup and NSpid material needs chapters 1.18, 1.19 and 1.26 first. Read those before §2 and §5.

Nebius rounds served: R1, R2, R3, R4

Chapter verdict: READ-SECTIONS (§1 "Why a cloud GPU node behaves differently", instance-type questions, capacity planning and multitenancy; §2 container resource-control table and the CPU shares vs quota trap; §4 GPU options, placement and spot; §5 USE-with-limits and the throttling decision rule; §6 observing containers from host and guest; §7 failure-mode table), because the "why is my container/GPU node slow in the cloud" reasoning is R1 and R3 material; storage detail, microVM catalogue, the three-way table and the checkpoint/exercise blocks are skim-only.

Hands-on to do:
1. Identify the platform: `systemd-detect-virt`, `lscpu`, `lspci`, `ls /sys/class/net` (step 1; runs on any Linux VM).
2. Make a container with CPU and memory limits (`docker run --cpus 0.5 --memory 256m ...`), read `cat /sys/fs/cgroup/cpu.max` inside it, then generate load and read `cpu.stat` for `nr_throttled` and `throttled_usec` from the host (step 6).
3. Find the container's host PID with `grep NSpid /proc/<hostpid>/status`, then `nsenter -t <hostpid> -n ss -tnp` to see sockets as the container (step 6).
4. Run the five-fact throttling check from §5 on that container, and note which fact is binding (step 7). Also run `python3 code/part01/cloud_virt_internals_lab.py` (path inside the book repo, not checked here).
