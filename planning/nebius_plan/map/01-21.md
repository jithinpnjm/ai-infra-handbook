Hands-on to do:
- `grep Cap /proc/self/status; capsh --decode=000001ffffffffff; getpcaps $$` (read a process's capability sets and decode the mask).
- `sudo find / -xdev -perm -4000 -type f -ls 2>/dev/null` and `mount | grep -E 'nosuid|noexec'` (setuid audit and mount options).
- `sudo -l -U alice; sudo visudo -c` after adding a sudoers drop-in for one GPU command (on a throwaway VM).
- `docker run --rm alpine grep Seccomp /proc/self/status` (expect 2), then `--security-opt seccomp=unconfined` (expect 0).
- Rocky/Alma VM only: `getenforce; sudo ausearch -m avc -ts recent` after a deliberate denial, then fix with `semanage fcontext` and `restorecon` (never `setenforce 0`).
- SSH hardening (lockout risk): apply the drop-in, `sudo sshd -t`, `sudo sshd -T | sort`, and test in a second session before closing the first.
