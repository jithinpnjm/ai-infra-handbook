Hands-on to do:
- Build the synthetic log from the chapter (awk generator), then `grep -c ERROR train.log` and `grep -C 2 ERROR train.log`.
- Top-N pipeline on the log: `grep -oE 'gpu=[0-9]+' train.log | sort | uniq -c | sort -rn | head`, and check it against the count-by-key model.
- Masked error ranking: `grep -i error train.log | sed -E 's/[0-9]+/N/g' | sort | uniq -c | sort -rn`.
- Average a field with awk: `grep -oE 'tokens_per_sec=[0-9]+' train.log | cut -d= -f2 | awk '{s+=$1} END {print s/NR}'`.
- Fan-out drill: create 1000 files, some with spaces; break `ls | xargs rm` on purpose, then do it with `find -print0 | xargs -0 rm`.
