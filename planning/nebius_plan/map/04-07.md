# 4.7 Ansible variables, facts, templates and filters
Words: ~11,300 | Read time: 75 min | File: docs/part-04-automation/07-ansible-variables-facts-templates-and-filters.md
One-line purpose: Explains where Ansible variables come from and which wins, how `register`/`set_fact` and facts carry data through a run, how lookups, loops and filters shape it, and how templates turn that data into Slurm, hosts and Prometheus configs.
Beginner friendly: partly. The ideas are explained with plain analogies, but the reader must already know YAML quoting (04-04), inventory layers (04-05) and `--check`/`--diff` (04-06). Read those first.
Nebius rounds served: R2 (primary: variables, facts, templates, debugging a wrong value), R4 (secrets handling, config generation for a fleet), R1 (Python-like data handling and `ansible_facts` for host checks)

Hands-on to do:
- `python3 code/part04/ansible_variables_facts_lab.py` from the handbook root (the folder exists there).
- `ansible gpu001 -m ansible.builtin.setup -a 'filter=ansible_default_ipv4'`, then the same with `gather_subset=!all,!min,network,hardware`.
- Reproduce the `--limit` bug: render a `/etc/hosts` for the whole group, run it with `--limit` on one host, read the error or the blank addresses, then fix it with a gather-facts play for the group first.
- Reproduce the skipped-register bug: a `when:` skips a `command` on one host, then the next task reads `stdout_lines[0]`. Fix it with `drv is not skipped`.
- Create an executable `/etc/ansible/facts.d/gpu.fact` that prints `{"count": N}`, then read `ansible_local.gpu.count` in a debug task.
- Reproduce the boolean-as-string bug with `"False"` and fix it with `| bool`. Then use `ansible-inventory --host <host> --yaml` and `grep -rn` to find the layer that set a value.

4. How would you speed up fact gathering on a 500-node cluster, and how does a host publish its own facts?
5. How do you validate a rendered config before it replaces the live file, and how do you avoid a restart on every run?
6. How do you keep secrets out of logs and diffs?
