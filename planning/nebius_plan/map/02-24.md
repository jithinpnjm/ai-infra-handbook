Hands-on to do:
- Multi-homed fix on a disposable VM with two namespaces or two NICs: `ip rule show`, then add a table with `ip route add ... table storage` and `ip rule add from <addr> lookup storage`, then verify with `ip route get <dst> from <src> iif lo` (lab step 1, section 1.1).
- MTU ladder: set MTU 9000 on one side and 1500 on a middle hop, reproduce the hang, then confirm with `ping -M do -s 8972 -c 3 <peer>` and `tracepath -n <peer>` (lab step 5, section 4).
- Read the bond state: `cat /proc/net/bonding/bond0` on any bonded host, then check the aggregator ID and partner MAC (section 3).
- Queue health: `mpstat -P ALL 1`, `cat /proc/net/softnet_stat`, `ethtool -S eth0 | grep -i miss` during an `iperf3 -P 8` test (section 5.3, scenario 1).
- Write down the metric before any tuning change, then A/B one setting at a time (section 8).
