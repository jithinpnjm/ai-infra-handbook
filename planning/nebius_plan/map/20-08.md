# 20.8 The coding round: what to expect and how to perform
Words: 9640 | Read time: 64 | File: docs/part-20-nebius-sre-interview/08-the-coding-round-what-to-expect-and-how-to-perform.md
One-line purpose: Teaches the process the coding round grades (narrate, clarify, brute force, optimise, test by hand), plus the Python/Go tools and pitfalls that cost points in a plain editor.
Beginner friendly: partly. The process sections need no prior background, but the code, pitfalls and tool tables assume working Python. Refresh first: Part 3 `03-idiomatic-python-the-data-model-comprehensions-generators.md`, `14-functions-scopes-and-arguments-in-depth.md`, `12-objects-types-and-data-structures-in-depth.md`. Then 20.9 (patterns) and 20.11 (problems).
Nebius rounds served: R1 (coding task in the first technical interview, Python scripting and algorithms), R2 (scripting depth)
Chapter verdict: READ-SECTIONS (1, 2, 4, 5, 7, 11, 12, the "How to answer out loud" block, Scenario 2, Drill questions). SKIM section 9 table and section 13 for recall. SKIP the Go section 10 unless you plan to code in Go, and SKIP the Sources and Verification log. Reason: the grade is mostly process plus avoiding the listed traps, not the library tour.

Hands-on to do:
1. `cd code/part20 && python3 -m pytest -q test_c08_*.py` (expect 30 passed). Paths are in the book's code folder.
2. `python3 -c "from collections import Counter; print(Counter('abracadabra').most_common(2))"` and `python3 -c "import heapq; h=[5,1,4]; heapq.heapify(h); print(heapq.heappop(h))"`, then check each against the table in section 9.
3. Pitfall check: `python3 -c "def f(x, b=[]): b.append(x); return b; print(f(1), f(2))"`. Expect `[1, 2]` twice. Rewrite with `None` and confirm.
4. Retype `check()` from section 8 from memory, then run `check(compress, [("", ""), ("aaa", "a3"), ("abc", "abc")])` and add `("aa", "aa")`.
5. Timed drill: one problem from c20-11, 25 minutes, plain text editor, talk aloud, then count the bugs the harness finds that you missed by hand.

Likely interview questions from this chapter:
1. "Given a stream of request logs, return the k endpoints with the most errors. Write it so I can run it. What changes if the logs no longer fit in memory?"
2. "Compress a string by replacing runs with the character and its count. What do you do with a single letter, and what if the result is longer than the input?"
3. "Merge overlapping intervals. Do touching intervals merge? Why does sorting first help?"
4. "What is wrong with `def f(x, bucket=[])`?"
5. "What is the complexity of your top-k solution, and which step dominates?"
6. "You are stuck. Walk me through what you do next."
