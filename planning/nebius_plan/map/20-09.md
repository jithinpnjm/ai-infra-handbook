# 20.9 Algorithm patterns for SRE-flavoured problems
Words: 14117 | Read time: 94 | File: docs/part-20-nebius-sre-interview/09-algorithm-patterns-for-sre-flavoured-problems.md
One-line purpose: Sixteen algorithm patterns (hash maps, windows, heaps, intervals, rate limiters, LRU, hashing, retries, graphs, percentiles, concurrency), each framed as an operations situation with a tested Python template.
Beginner friendly: no for a reader who has not coded these before. Read first: 20.8 (the round process and the pitfalls list), then Part 3 `12-objects-types-and-data-structures-in-depth.md` and `03-idiomatic-python-the-data-model-comprehensions-generators.md`, and `14-functions-scopes-and-arguments-in-depth.md` (the templates use closures, default args and generators). For the retry and percentile sections, read 20.19 (SLIs and percentiles) and 20.21 (retry budgets) before the template.
Nebius rounds served: R1 (coding task), R2 (topological sort for start order and deploy ordering), R3 (consistent hashing, rate limiting, retry budgets, streaming percentiles, fan-out with timeouts)
Chapter verdict: READ-SECTIONS (1, 2, 4, 5, 6, 9, 10, 14, the "How to answer out loud" block, Scenarios 1 and 3, Common mistakes table). SHOULD-skim 7, 8, 11, 12, 13. OPTIONAL-skim 3, 15, 16 (read only the "Decide" line and the prose). Reason: the interview asks for recognising the pattern and naming the trap, not for typing all 16 templates; the full code is for practice.
