# 3.5 Errors, files, text and bytes, subprocess and system scripting
Words: ~18900 | Read time: ~125 min (full read) | File: docs/part-03-python/05-errors-files-text-and-bytes-subprocess-and-system-scripting.md
One-line purpose: The core operational-scripting chapter: exceptions and exit codes, logging, safe file writes and locking, text vs bytes and encodings, JSON/YAML/CSV parsing, `subprocess` without shell injection, signals and `/proc`, and a template for a safe drain-style script.
Beginner friendly: partly. Assumes 3.1, 3.3 and 3.4. The Learning Python and Fluent Python digests are dense; the Linux-facing parts (signals, `/proc`, `flock`, `subprocess` pipes) assume Linux familiarity the reader is still building, so read the Part 1 Linux material first for those.
Nebius rounds served: R1 (Python scripting, file/text handling, subprocess, error handling, console troubleshooting), R2 (scripting for Kubernetes and DevOps tasks, cron/systemd/container behaviour), R4 (own project: how the tool handles failure and partial failure)
Chapter verdict: READ-SECTIONS. This is the chapter a Senior SRE most needs to refresh. Skip the Learning Python prose and the exercises' deep material; read exceptions (mechanics, rules, error-strategy, exit codes), logging, atomic write and locking, the encoding rules, subprocess safety and deadlock, signals, the template and the interview list (about 45-55 min of the 125).
