# 3.2 Modules, packages, virtual environments and packaging
Words: ~15,100 | Read time: ~101 min (about 50 min if you read only the READ-SECTIONS rows) | File: docs/part-03-python/02-modules-packages-virtual-environments-and-packaging.md
One-line purpose: Explains how Python finds and caches code (sys.path, sys.modules, import vs from, packages, circular imports), then how to isolate, lock, build and ship Python tools with venvs, pip-tools or uv, pyproject.toml, wheels and containers, including the GPU packaging traps.
Beginner friendly: partly. Read 3.1 first. Packaging terms (wheel, sdist, lockfile, venv) are introduced from zero, but the import-system sections assume you already know what a module is.
Nebius rounds served: R1 (Python scripting: import errors, venvs, running scripts from cron), R2 (DevOps tooling: packaging, lockfiles, containers, systemd, GPU node dependency drift), R3 (reproducible deploys across fleets), R4 (how you ship your own project).
Chapter verdict: READ-SECTIONS (section 1 import mechanics and `__name__` guard, circular imports, 3 virtual environments, 4 "Declaring dependencies", 5 wheels and tags, 7 GPU driver and CUDA checks, 8 containers, 9 troubleshooting table, 11, 12). The import-system mechanics and the troubleshooting table are the parts most likely to come up in a scripting or DevOps round. The reloader, namespace-package and entry-point details are niche, so skim or skip them.

Hands-on to do:
- `python3 code/part03/python_modules_packaging_lab.py` (the chapter's self-check lab; confirm the file exists in the repo first).
- `python3 -c 'import sys; print("\n".join(sys.path))'` and `python3 -m site`, then `python3 -X importtime -c 'import json'` to see import cost.
- Build the import cycle from section 2 (`recur1.py` and `recur2.py`). Run `python3 -c "import recur1"` to see the `partially initialized module` error, then `python3 recur1.py` and compare.
- `python3 -m venv .venv && .venv/bin/python -c 'import sys; print(sys.prefix, sys.base_prefix)'`, then install with `.venv/bin/python -m pip install requests` without activating.
- `python -m build` on a small `pyproject.toml` project, then `unzip -l dist/*.whl` to inspect the wheel contents and the `entry_points.txt`.
