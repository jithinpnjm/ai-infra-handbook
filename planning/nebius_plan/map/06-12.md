Hands-on to do:
- Run `python code/part06/fake_srun.py 2 2 python code/part06/ddp_toy.py` twice in a CPU-only venv. Confirm `start_step` goes from 0 to 1 on the second run (the chapter's glue test).
- Run `python3 code/part06/slurm_dist_init_lab.py` (if the code folder is present). Check `dist_env()` maps SLURM_JOB_ID=4242 to MASTER_PORT=14242.
- On 2 nodes: `srun -N 2 --ntasks-per-node=1 bash -c 'echo $(hostname) $(taskset -pc $$)'` to see cores per rank, then `nvidia-smi topo -m` on one node.
- Save a healthy baseline: run with `NCCL_DEBUG=INFO` and grep the transport lines (expect `NET/IB`, not `NET/Socket`). Then set `NCCL_IB_DISABLE=1` once and compare the speed.
- Run `srun -N 2 all_reduce_perf -b 8 -e 8G -f 2 -g 1` (nccl-tests) on the same allocation, to separate fabric from application problems.
