Hands-on to do:
- Run the plan loop on a local-only config: `terraform init && terraform plan -out=tfplan && terraform apply tfplan`, then `terraform plan` again and confirm "No changes" (section 9).
- Change one variable so a resource shows `-/+` in `terraform plan`, and read the "forces replacement" line (section 4).
- Simulate drift: edit the generated file by hand, then run `terraform plan` and `terraform plan -refresh-only` and compare the two outputs (section 5.1).
- Practise `terraform state list`, `terraform state show <addr>`, and `terraform graph` on the same small config (section 4 and 3.3).
