# Migrating everything else from nvidia-devops (so the repo can be archived)

Docs are tracked file by file in `MIGRATION_MAP.md` (452 files, about 1.22M words, generated by `tools/migration/inventory.py`). This file covers everything that is not a document. Source repo: `~/Documents/GitHub/nvidia-devops`.

## Principle
The content is the author's own, so it is reused directly, not merely referenced. For each handbook chapter: read every mapped nvidia-devops file, keep what is correct and good (text, tables, Mermaid diagrams, labs, interview Q&A, troubleshooting runbooks), rewrite for one consistent voice and the book's template, remove duplicates across volumes, fix errors (the repo already contains several self-corrections, for example the `slurmctld -c` behaviour), and raise depth to the level of the best sources. Then add `Migrated from nvidia-devops: <file names>` (or `(partial: sections ...)`) to the chapter's Sources section and rerun the inventory.

## Archive checklist (do in this order)

3. Every image referenced by a migrated chapter is in `static/img/migrated/` and renders.
4. Phase 2 decisions made for each interactive feature (ported or dropped).
5. The handbook builds with zero broken links and has been read by the author.
6. Add a README to nvidia-devops pointing to the handbook, tag a final release, then archive the GitHub repository.
