| **Prefill (Compute-Bound GEMM) vs. Decode (Bandwidth-Bound GEMV) & Roofline Math** | **Arithmetic Intensity (`I`):** `I = FLOPs / Bytes_Moved`. **Hardware Ridge Point (`I_ridge`):** `Peak_Compute_FLOPS / Peak_HBM_Bandwidth_Bytes_per_sec`. For square matrices (`M=N=K`): `64 -> 21.33 FLOPs/B`, `512 -> 170.67 FLOPs/B`, `4096 -> 1365.33 FLOPs/B`. **LLM Linear Layer (`K = N = h = 4096`, batch `B = 1`):** `I(s, h) = (s * h^2) / (2*s*h + h^2)`. During **Decode** (`M = 1` token): `I(1, 4096) = 4096 / 4098 = 0.9995 ≈ 1.0 FLOPs/B` (**deeply memory-bandwidth-bound**). With batch size `B` in decode (`M = B`), `I(B, h) ≈ B` for `B << h`. **The Memory-Bandwidth Wall (`V12` Ch. 1 & `AIE` Ch. 9):** Generating `1` decode token for a `70B` FP16 model (`140 GB` weights) on `1` H100 (`3,350 GB/s` HBM3) requires `140 GB / 3,350 GB/s = 41.79 ms` (`~41.7 ms`) minimum weight-load time = **`23.93 tok/s` (`~24 tok/s`) hardware ceiling** at `B = 1`. **Model Bandwidth Utilization (`MBU`):** `MBU = (Params * Bytes_per_param * Tokens_per_sec) / Peak_HBM_Bandwidth`. | `V12` Ch. 1; `HLS` Ch. 5; `AIE` Ch. 9 |

| **Tokenization, Logit Sampling, Stop Conditions, and Ecosystem Stack** | **Tokenization (`V12` Ch. 2, `HLS` Ch. 2):** Byte-Pair Encoding (`BPE`) / `tiktoken` / Rust `tokenizers` converts UTF-8 text into `int64` token IDs and appends chat template control tokens (`<|begin_of_text|>`, `<|start_header_id|>`, `<|eot_id|>`). **Logit Processing & Sampling (`V12` Ch. 2, `HLS` Ch. 2):** Final hidden state `[B, 1, d_model]` multiplies with LM Head `[d_model, V_vocab]` (`V_vocab = 128,256` Llama-3 or `151,936` Qwen2.5) to yield raw logits `z`.
