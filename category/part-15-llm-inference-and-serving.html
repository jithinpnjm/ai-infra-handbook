Part 15: LLM inference and serving

18 chapters. Default priority tier 1.

📄️15.1 The anatomy of an inference request

First-principles anatomy of a production LLM inference request: the nine-stage end-to-end data path. Prefill GEMM vs Decode GEMV execution mechanics, TTFT/ITL/TPOT/E2E latency budgets and Goodput SLOs. Roofline ridge points, the HBM bandwidth wall, KV cache sizing, PagedAttention/Chunked Prefill guardrails, BPE tokenization, GPU logit sampling, and stopping criteria.

📄️15.2 Batching, the KV cache and quantization fundamentals

Mathematical and systems foundations of LLM inference optimization: prefill versus decode Roofline arithmetic intensity, static versus dynamic versus iteration-level continuous batching and chunked prefill, MHA/GQA/MQA/MLA KV cache memory math and PagedAttention capacity planning, and PTQ/QAT quantization across FP8, INT8 SmoothQuant, INT4 AWQ/GPTQ, NVFP4, and quantized KV caches.

📄️15.3 vLLM in depth

Architectural deep dive into vLLM: PagedAttention virtual memory block tables, zero-padding attention kernels, Copy-on-Write beam search and parallel sampling, Automatic Prefix Caching (APC) vs RadixAttention, continuous batching, chunked prefill, Swap vs Recompute preemption, vLLM V1 dual-process architecture, TP/PP/DP/EP distributed parallelism, and Punica/S-LoRA multi-LoRA serving.

📄️15.4 SGLang and cross-request optimisation

SGLang and cross-request inference optimisation: RadixAttention prefix tree KV cache reuse, leaf-first LRU eviction, cache-aware scheduling, XGrammar and Outlines compressed finite-state machine structured output decoding, jump-forward decoding, FlashInfer and zero-overhead CPU scheduling, SGLang Model Gateway routing, session affinity, prefill-decode disaggregation, and Data-Parallel Attention.

📄️15.5 TensorRT and TensorRT-LLM

TensorRT and TensorRT-LLM engine compilation, kernel fusion, ModelOpt quantization, and runtime serving.

📄️15.6 Triton Inference Server

Production architecture of NVIDIA Triton Inference Server. Covers model repositories, config.pbtxt, dynamic and sequence batching, decoupled LLM backends, instance groups, Ensembles, Business Logic Scripting, shared memory, and Model Analyzer.

📄️15.7 NVIDIA NIM and the NIM Operator

Production architecture of NVIDIA NIM and the Kubernetes NIM Operator. Covers NIM container anatomy, hardware-aware TensorRT-LLM and vLLM model profile selection, air-gapped caching, Multi-LoRA serving, NIMCache, NIMService, NIMPipeline, NeMo Microservices CRDs, and queue-depth autoscaling.

📄️15.8 NVIDIA Dynamo, llm-d and disaggregated serving

Disaggregated prefill and decode serving with NVIDIA Dynamo, Smart Router KV-cache-aware routing, GPU Planner SLO-driven worker scaling, NIXL asynchronous transfers, 4-tier KV cache offloading, and Kubernetes llm-d Gateway API Inference Extension.

📄️15.9 Multinode inference: parallelism, decoding and routing

Multi-node LLM inference architecture: 5D parallelism (Tensor, Pipeline, Expert, Data, and Context/Helix Parallelism), why cross-node TP breaks Inter-Token Latency via 2*(N-1) AllReduces, wide Expert Parallelism on DeepSeek-R1 671B and GB200 NVL72, dynamic MoE routing and EPLB, speculative decoding (draft-verify math, Medusa, EAGLE, Multi-Token Prediction MTP, Lookahead), Kubernetes LeaderWorkerSet (LWS) serving, and prefix-aware routing.

📄️15.10 Prefill and decode disaggregation

First-principles architecture of prefill and decode disaggregation: colocated continuous batching interference and DistServe goodput math, Splitwise, TetriInfer, Arrow, Mooncake, SGLang, and NVIDIA Dynamo architectures, prefill-to-decode worker ratio sizing, KV cache transfer bandwidth math across MHA, GQA, MQA, and MLA, RDMA and NVLink NIXL transfer latency, and heterogeneous GPU pairing.

📄️15.11 Advanced prefill-decode and KV cache tuning

Low-level decode attention megakernels (FlashDecoding, FlashInfer, XQA, FlashMLA, ThunderMLA, FlexDecoding, POD-Attention), chunked prefill token-budget tuning, FP8/INT4 KV cache quantization and eviction (Sliding Window Attention, StreamingLLM, H2O, SnapKV), zero-copy NIXL/LMCache RDMA page collation and [TP_p]-to-[TP_d] KV transpose, hierarchical KV offloading across HBM, Grace LPDDR5X via NVLink-C2C, DDR5, and NVMe/GDS, and SLO-aware schedulers (Splitwise, HexGen-2, TetriInfer, Arrow, Mooncake).

📄️15.12 Dynamic and adaptive inference engine optimisations

Dynamic and adaptive inference engine optimizations: CUDA Graphs for decode batch padding buckets and time-series prewarming, TorchCompile and custom OpenAI Triton fused kernels for RMSNorm, RoPE, SwiGLU, and AllReduce, dynamic speculative decoding draft-length adaptation, early exit and layer skipping, adaptive parallelism and semantic model cascades, and test-time compute scaling budgets.

📄️15.13 Profiling, debugging and tuning inference at scale

End-to-end profiling, debugging, and full-stack tuning of LLM inference clusters at scale: the three-layer profiling funnel across DCGM, Prometheus, Nsight Systems, PyTorch Profiler, Nsight Compute, and Linux perf, NVTX CUPTI GPU projection, diagnosing TTFT spikes versus ITL stalls, host CPU and GIL bottlenecks, KV cache thrashing and allocator fragmentation, multi-GPU NCCL tail latency and XID faults, and real-time quantization and application-level tuning.

📄️15.14 Benchmarking: genai-perf, latency percentiles and goodput

Rigorous LLM inference benchmarking with NVIDIA GenAI-Perf, Perf Analyzer, AIPerf, vLLM benchmark_serving, and genai-bench: TTFT and ITL/TPOT percentile distributions, Little's Law, open-loop Poisson arrivals vs closed-loop concurrency sweeps, Goodput Pareto frontiers, MLPerf Inference Server vs Offline scenarios, and production failure remediation.

📄️15.15 Autoscaling inference: HPA, KEDA and scale-to-zero

Production autoscaling architecture for LLM inference on Kubernetes: why CPU, memory, and GPU SM utilization fail under continuous batching, scaling on Prometheus custom metrics, HPA stabilization windows and asymmetric policies, KEDA ScaledObject scale-to-zero and Knative queue-proxy concurrency, and cold-start optimization with local NVMe, OCI image volumes, Run:ai Model Streamer, and GPUDirect Storage.

📄️15.16 Production serving stack and reliability

End-to-end production LLM serving stack and site reliability engineering: Envoy AI Gateways and the Kubernetes Gateway API Inference Extension, dual token-bucket rate limiting and tenant quotas, semantic caching and NeMo Guardrails, canary and blue-green model rollouts with SSE connection draining, Kubernetes health probes and XID 62 zombie pod remediation, circuit breakers and fallback cascades, and OpenTelemetry and Prometheus observability.

📄️15.17 Lab: serve and benchmark on GKE and Nebius

End-to-end production deployment and benchmarking lab for vLLM, SGLang, and TensorRT-LLM / NIM on Google Kubernetes Engine (GKE) and Nebius Managed Kubernetes (MK8s): GPU node pools, PVC/GCS Fuse/Nebius shared filesystem weight caching, Gateway API Inference Extension routing, Prometheus + DCGM Exporter scraping, ShareGPT and GenAI-Perf concurrency sweeps, KEDA autoscaling verification, and cloud teardown checklists.

📄️15.18 Inference cost, capacity and cost per token

Production LLM inference economics and capacity engineering: cost per 1M input and output tokens, Goodput-adjusted cost under P99 TTFT and ITL SLOs, KV cache and weight VRAM concurrency sizing across FP16/BF16, FP8, and INT4, fleet sizing for peak RPS and diurnal curves, L4/L40S/A100/H100/H200/B200/GB200 NVL72 hardware economics, quantization/prefix-caching/speculative/disaggregated multipliers, and self-hosted versus managed API break-even utilization.
