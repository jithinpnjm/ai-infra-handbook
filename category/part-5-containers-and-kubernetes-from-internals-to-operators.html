Part 5: Containers and Kubernetes, from internals to operators

35 chapters. Default priority tier 0.

📄️5.1 Containers from first principles: images, layers, registries

What a container is (processes with namespaces, cgroups and a root filesystem), the OCI image and runtime specs, layers and content addressing, Dockerfile and BuildKit practice, registries and distribution, rootless containers, image security, and GPU-enabled images

📄️5.2 Container runtimes: containerd, runc, CRI and OCI

The runtime stack under Kubernetes: kubelet, the CRI, containerd and CRI-O, shims, OCI runtimes (runc, crun, kata, gVisor), snapshotters, configuration, cgroup drivers, image management, RuntimeClass, GPU runtime configuration, and debugging with crictl and ctr

📄️5.3 Kubernetes architecture overview: components and what talks to what

The Kubernetes control plane and node components, the declarative API model, who talks to whom, high availability, add-ons, extension points, and the architecture of GPU/AI clusters

📄️5.4 Bare-metal Kubernetes from scratch with kubeadm (lab)

Build a multi-node Kubernetes cluster by hand with kubeadm: node preparation (kernel, swap, sysctls, runtime), control plane bootstrap, CNI, joining workers, HA control plane, verifying, kubectl usage, adding a GPU worker, and a catalogue of installation failures

📄️5.5 The API server and etcd: how a request becomes cluster state

Inside kube-apiserver and etcd: the request pipeline, API groups and versioning, resourceVersion and optimistic concurrency, list/watch and the watch cache, server-side apply, admission and audit, API Priority and Fairness, etcd Raft/MVCC/compaction/defrag, performance, scaling, backup and diagnostics

📄️5.6 Controllers and the reconcile loop: how Kubernetes thinks

The controller pattern: level-triggered reconciliation, informers, work queues and shared caches, the built-in controllers (Deployment, ReplicaSet, StatefulSet, DaemonSet, Job, node lifecycle, endpoints, garbage collection), owner references and finalizers, leader election, failure modes and observability

📄️5.7 Pods and workloads: Deployments, StatefulSets, DaemonSets and Jobs

The pod as the unit of deployment: spec anatomy, containers, init and sidecar containers, resources and QoS, volumes, environment, security context, lifecycle and termination, restart policies, probes overview, and the workload controllers with practical patterns for GPU training, inference and batch

📄️5.8 The life of a pod end to end, including what the kernel does

A complete trace of a pod from kubectl apply to running process and back: API, scheduling, kubelet sync loop, volume setup, CRI sandbox creation, CNI, image pull, runc, namespaces and cgroups, probes, termination, plus the kernel-level artefacts you can inspect at every step

📄️5.9 The kubelet and the node: CRI, cgroups, QoS classes, probes and eviction

The node agent in depth: KubeletConfiguration, resource managers (CPU, memory, topology, device), reservations, cgroup hierarchy and QoS, probes, node pressure eviction, image and log GC, graceful node shutdown, node status and leases, static pods, kubelet security and tuning for GPU nodes

📄️5.10 Services, endpoints and kube-proxy: the life of a Service

Kubernetes Services in depth: ClusterIP, NodePort, LoadBalancer, headless and ExternalName; EndpointSlices; kube-proxy modes (iptables, IPVS, nftables) and eBPF replacements; packet path, conntrack and NAT; session affinity, traffic policies, topology-aware routing, dual-stack; debugging and scale limits

📄️5.11 DNS and service discovery with CoreDNS

How cluster DNS works: records for Services and Pods, resolv.conf and ndots, CoreDNS architecture and Corefile plugins, scaling and caching, NodeLocal DNSCache, stub domains and external resolvers, DNS-based discovery for StatefulSets and distributed training, performance pitfalls and debugging

📄️5.12 Ingress, load balancers and the Gateway API

Getting traffic into a cluster: L4 and L7 load balancing, Ingress resources and controllers, the Gateway API (GatewayClass, Gateway, HTTPRoute, GRPCRoute), TLS and cert-manager, bare-metal load balancers, timeouts/streaming for LLM traffic, rate limiting, auth, and operating the edge for inference services

📄️5.13 Pod networking under the hood: veth, bridges, routes and CNI plugins

The Kubernetes network model and how a CNI plugin implements it: network namespaces, veth pairs, bridges and routed designs, IPAM, the CNI specification and plugin chaining, Multus and secondary networks, SR-IOV/RDMA for AI, MTU, and hands-on inspection and debugging

📄️5.14 Overlay versus routed pod networking: VXLAN, BGP with Calico, eBPF with Cilium

Comparing Kubernetes data planes: VXLAN/Geneve/IPIP overlays, routed BGP designs with Calico and kube-router, eBPF datapaths with Cilium (native routing, kube-proxy replacement, host routing, Hubble, ClusterMesh), underlay integration with leaf-spine fabrics, performance, scale, and selection criteria for GPU clusters

📄️5.15 NetworkPolicy and the kernel: netfilter, conntrack and eBPF

Network policy in Kubernetes: the NetworkPolicy API and its semantics, default-deny patterns, policy design for multi-tenant AI platforms, how CNIs enforce policy (iptables/ipsets, nftables, eBPF), conntrack interaction, extended policy (Calico, Cilium, admin and baseline policies), testing, and troubleshooting

📄️5.16 Configuration, secrets and RBAC

Managing configuration and secrets in Kubernetes (ConfigMaps, Secrets, projected volumes, immutability, rotation, external secret stores, encryption at rest) and access control (authentication, ServiceAccounts and tokens, RBAC roles, aggregation, least-privilege design, auditing) with AI-platform patterns

📄️5.17 Storage internals: volumes, PV and PVC, CSI and mounts

How Kubernetes storage works: volume types, PersistentVolumes/Claims/StorageClasses, binding and provisioning, the CSI architecture (controller and node plugins, sidecars, stage/publish), topology, snapshots/clones/expansion, access modes, local and shared filesystems for AI datasets and checkpoints, mount mechanics, performance and troubleshooting

📄️5.18 Scheduling in depth: kube-scheduler, affinity, taints, priority and preemption

How Kubernetes places pods: the scheduling framework (queues, filter/score, bind), node and pod affinity, taints and tolerations, topology spread, priority and preemption, resource fit and extended resources, topology/NUMA awareness, gang scheduling and queueing (Kueue, Volcano), DRA, scheduler tuning and scale, and GPU-cluster scheduling patterns with troubleshooting

📄️5.19 Cluster deployment models and day-2 operations

Choosing and operating Kubernetes cluster models: managed vs self-managed, single vs multi-cluster, node pools and lifecycle (join, cordon, drain, replace), maintenance windows, capacity and quota management, add-on lifecycle, configuration management, drift and compliance, runbooks, SLOs and on-call for GPU platforms

📄️5.20 Upgrades, etcd backup and restore, and disaster recovery

Planning and executing Kubernetes upgrades (version skew, kubeadm, node pools, add-ons, API deprecations), etcd backup/restore procedures, control-plane and cluster disaster recovery, application/PV backup with Velero and snapshots, DR strategies (active/passive, active/active, rebuild-from-Git), RPO/RTO and game days for GPU platforms

📄️5.21 Certificates, identity, admission control and policy

Kubernetes PKI and certificate lifecycle, TLS bootstrapping, CSR API, OIDC identity, admission control (built-in plugins, webhooks, ValidatingAdmissionPolicy), Pod Security Standards, policy engines (Kyverno, Gatekeeper), image/supply-chain admission, and guardrails for GPU multi-tenant platforms

📄️5.22 Multitenancy and platform services

Designing a multi-tenant Kubernetes platform for AI teams: tenancy models and isolation levels, namespaces, quotas and LimitRanges, RBAC/network/policy/storage/GPU isolation, hierarchical namespaces and vCluster/virtual clusters, self-service, platform services (ingress, registries, CI, observability, notebooks, queueing), cost allocation and the platform-as-a-product model

📄️5.23 Autoscaling: HPA, VPA, KEDA and the cluster autoscaler

Scaling workloads and nodes in Kubernetes: HPA algorithm and metrics (resource, custom, external), VPA, KEDA event-driven scaling, cluster autoscaler and Karpenter, GPU-specific autoscaling for inference (queue depth, KV-cache, tokens/s), scale-to-zero, warm pools, limits and pitfalls

📄️5.24 Observability for Kubernetes

Metrics, logs, traces and events for Kubernetes and GPU platforms: Prometheus architecture and operator, kube-state-metrics, cAdvisor, node-exporter, DCGM, alerting design (SLOs, burn rates), Alertmanager, log pipelines (Fluent Bit, Loki), OpenTelemetry tracing, dashboards, multi-tenant and long-term storage, cardinality and cost control

📄️5.25 Troubleshooting Kubernetes from the node: crictl, nsenter, tcpdump and ip

A systematic troubleshooting method and toolkit for Kubernetes: top-down and bottom-up approaches, kubectl diagnostics, node-level tools (crictl, nsenter, tcpdump, ip, ss, conntrack, strace, perf, bpftrace), debugging pods (ephemeral containers, kubectl debug), networking/storage/scheduling/GPU failure playbooks, evidence collection and post-incident practice

📄️5.26 How Kubernetes uses the Linux kernel: a complete map

A synthesis of every Linux kernel facility Kubernetes depends on: namespaces, cgroups v2, capabilities, seccomp and LSMs, overlayfs and mounts, netfilter/conntrack/eBPF/tc, virtual devices, the CPU scheduler, memory management (OOM, hugepages, NUMA, swap), block and filesystem layers, devices (GPU, RDMA), time, entropy, and the kernel parameters, versions and failure modes that matter

📄️5.27 Software supply chain security

Securing the path from source to running container and model: threat model, SLSA and provenance, reproducible and hermetic builds, SBOMs, vulnerability scanning, signing and verification (Sigstore/cosign, Notary), registries and admission enforcement, dependency hygiene for Python/CUDA stacks, model and dataset supply chain, runtime protections and incident response

📄️5.28 Service mesh

What a service mesh provides (mTLS, traffic management, observability, policy), data-plane models (sidecar, ambient, eBPF), Istio, Linkerd and Cilium Service Mesh, traffic shifting and resilience, security and identity, performance costs, gRPC/LLM traffic considerations, and when not to use a mesh

📄️5.29 Extending Kubernetes: CRDs and operators

How to extend Kubernetes with CustomResourceDefinitions and controllers: CRD schema, validation (OpenAPI, CEL), defaulting, versions and conversion, subresources, finalizers, owner references, status conditions, the operator pattern and maturity model, Helm/Ansible/Go operator options, OLM, packaging, RBAC and upgrade strategy, and the AI-platform operators you will meet

📄️5.30 Go for Kubernetes engineers

The Go you need to read and write Kubernetes tooling: toolchain and modules, types, structs, interfaces, errors, slices/maps, goroutines/channels/context, generics, testing, JSON/YAML, building CLIs, and using client-go (clientsets, dynamic client, informers, listers, work queues, patching, watching) with idioms and pitfalls

📄️5.31 Operators in Go: controller-runtime and kubebuilder

Writing Kubernetes operators in Go with controller-runtime and kubebuilder: CRD types and markers, the manager, reconcile loop design, caching client, watches and predicates, field indexes, finalizers, owner references, status conditions, events, RBAC, leader election, envtest testing and production hardening

📄️5.32 Project A: GPU node health operator

A worked project: a safe GPU node remediation operator in Go. A cluster-scoped GPUHealthPolicy CRD, a pure decision core, a budgeted cordon (and optional drain) reconciler with ownership marks, finalizer, status conditions and events, tested with envtest. Includes design rationale, failure modes, what the tests prove and what they do not

📄️5.33 Reading the GPU Operator and Network Operator source

A guided tour of the NVIDIA GPU Operator and the NVIDIA (Mellanox) Network Operator source: repo maps, the ClusterPolicy and NicClusterPolicy controllers, ordered states and operands, node-label gating, validation files, readiness checks, driver upgrade flow, and a method for debugging operators from source

📄️5.34 GKE for GPU workloads: setup, node pools and quotas

Running GPU workloads on Google Kubernetes Engine: Standard vs Autopilot, GPU machine families, node pool creation with driver installation, taints and scheduling, quotas and reservations, Spot and flex-start, compact placement, GPU sharing and MIG, high-performance networking, monitoring with managed DCGM, cost controls and a verified-flags command reference

📄️5.35 Multicluster and fleet management

Running many Kubernetes clusters for AI: why and when, cluster lifecycle (Cluster API, managed services, Terraform), GitOps fleet delivery (Argo CD ApplicationSet, Flux), job placement across clusters (Kueue MultiKueue, Karmada, OCM), cross-cluster networking and identity, policy, observability, wave-based upgrades, and failure-domain design
