📄️3.12 Objects, types and data structures in depth

Numbers, strings, lists, dictionaries, tuples and files, and how Python's dynamic typing really works, taught from first principles for infrastructure scripting.

📄️3.13 Statements, iteration and control flow in depth

📄️3.14 Functions, scopes and arguments in depth

📄️3.16 Classes and object-oriented programming in depth
