# Snippets: API usage for libraries that are not installed here

Files in this directory show how a third-party library is called (Flyte, DeepSpeed,
Weights & Biases, DataHub, NeMo Guardrails, TensorFlow Privacy, torchrun). They
are syntax-checked only. They have NOT been run: the libraries, GPUs and services
they need are not available in the test environment. Names such as `args`,
`model` or `emitter` come from the surrounding script in the chapter.
